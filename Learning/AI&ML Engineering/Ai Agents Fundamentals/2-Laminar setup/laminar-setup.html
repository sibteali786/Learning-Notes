OBSERVABILITY SETUP

Laminar + OTEL Tracing

Instrument your agent once → see every span, prompt, output, and tool call.
💡 Tracing is to agents what console.log on steroids is to regular code — every step, every span, in one dashboard.
Goes hand-in-hand with evals: run an eval → follow its trace → pinpoint exactly where to improve.
WHAT GETS TRACED
📡
Span
One unit of work — e.g. AI generateText or doGenerate. Has input, output, attributes, events.
🔗
Trace
The full tree of spans for one agent run. Simple now (1 call), complex later (multi-turn + tools).
🧑‍⚖️
Dashboard
Laminar UI shows traces, eval scores, avg scores over time. View evals and traces in one place.
SETUP — 3 STEPS
1
Install & Import
Add @lmnr-ai/lmnr and pull in Laminar + getTracer
2
Initialize at app top
Call Laminar.initialize({ projectApiKey: process.env.LMNR_PROJECT_API_KEY }) — that's it.
3
Enable telemetry on AI SDK
Pass experimental_telemetry: { isEnabled: true, tracer: getTracer() } to your generateText call.
CODE — run.ts 
// 1. Import
import { Laminar, getTracer } from '@lmnr-ai/lmnr';

// 2. Initialize (top of file)
Laminar.initialize({
  projectApiKey: process.env.LMNR_PROJECT_API_KEY
});

// 3. Enable telemetry on your AI SDK call
const result = await generateText({
  model,
  messages,
  tools,
  experimental_telemetry: {
    isEnabled: true,
    tracer: getTracer()   // wires up OTEL spans automatically
  }
});
⚠️ Traces not showing up? → Call await Laminar.flush() before your process exits.
Laminar (like all analytics tools) batches events and sends on an interval. If your process ends first, those events never ship. flush() forces an immediate send — classic race condition fix.
