Neural Network Layer

Lesson 3 · How a single layer of neurons computes its output

Big Picture

A neural network is built from layers. Each layer is just a bunch of logistic regression units (neurons) stacked side by side, each with its own parameters w and b. A layer takes a vector of numbers in, and outputs a new vector of numbers.

Example used throughout: predicting whether a t‑shirt will be a top seller, from 4 input features (price, shipping cost, marketing, material).

Layer 1 — The Hidden Layer

Input x (4 features) is fed to all 3 neurons in layer 1. Each neuron is an independent little logistic regression unit:

a1[1] = g( w1[1] · x + b1[1] ) = 0.3
a2[1] = g( w2[1] · x + b2[1] ) = 0.7
a3[1] = g( w3[1] · x + b3[1] ) = 0.2

where g(z) = 1 / (1 + e-z) — the sigmoid/logistic function, and z = w·x + b (the familiar term from logistic regression).

🎯 Real-world reading

Each hidden neuron can be thought of as learning its own "concept" from the raw features — e.g. neuron 1 → probability of "affordability" (0.3), neuron 2 → probability of "awareness" (0.7), neuron 3 → probability of "perceived quality" (0.2). The network isn't told these labels — it discovers useful intermediate features on its own during training.

Layer 2 — The Output Layer

Layer 2 has just one neuron. Its input isn't the raw x anymore — it's a[1], the output vector from layer 1:

a1[2] = g( w1[2] · a[1] + b1[2] ) = 0.84
a[1] = [0.3, 0.7, 0.2]
→
0.84
Layer 2
(output)
→
a[2] = 0.84
(scalar, not a vector)

Because this layer has only 1 neuron, its output is a single number (scalar), not a vector.

Optional Final Step — Thresholding

If you want a hard yes/no prediction instead of a probability, threshold a[2] at 0.5:

is a[2] ≥ 0.5 ?
a[2] = 0.84 ≥ 0.5
→
ŷ = 1
"Yes, top seller"

Same thresholding rule used in plain logistic regression — nothing new here.

Putting It Together

1Layer inputs a vector of numbers.

2Each neuron in that layer runs its own logistic regression: g(w·input + b).

3All neuron outputs combine into a new vector — the layer's activation vector a[l].

4That vector becomes the input to the next layer. Repeat until the final (output) layer.

5Optionally threshold the final output to get a 0/1 prediction.

Key takeaway: A "layer" is nothing exotic — it's a set of logistic regression units run in parallel on the same input, whose outputs get bundled into a vector and passed forward. Stack enough of these and you get a deep neural network.
