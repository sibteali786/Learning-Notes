Matrix Multiplication in NumPy → Vectorized Dense Layer

Lesson 14 (optional, final of the week) · Tying matmul back to the full vectorized neural network

Matrix Multiplication in Code

A = np.array([[1, -1, 0.1],
              [2, -2, 0.2]])

# Two ways to get the transpose:
AT = np.array([[1, 2],
               [-1, -2],
               [0.1, 0.2]])   # manually written out
AT = A.T                      # or: NumPy's built-in transpose — much easier

W = np.array([[3, 5, 7, 9],
              [4, 6, 8, 0]])

Z = np.matmul(AT, W)      # preferred in this course
# or equivalently:
Z = AT @ W                 # same thing, different syntax

A.T is the easy way to transpose — no need to manually retype the matrix with rows/columns swapped. np.matmul(...) and @ do the exact same matrix multiplication; the course sticks with np.matmul for clarity, but you'll see @ in other people's code.

Result:

Z = [[11, 17, 23, 9],
     [-11, -17, -23, -9],
     [1.1, 1.7, 2.3, 0.9]]

Applying This to a Real Dense Layer (Coffee Example)

Input: temp=200°C, duration=17 min. Layer 1 has 3 neurons.

AT = np.array([[200, 17]])              # 1×2 — the input, as a row
W  = np.array([[1, -3, 5],
               [-2, 4, -6]])            # 2×3 — columns = w1, w2, w3
B  = np.array([[-1, 1, 2]])             # 1×3 — biases

Z = AT @ W + B    # or np.matmul(AT, W) + B
NeuronComputationz value
Neuron 1200×1 + 17×(-2) + (-1)165
Neuron 2200×(-3) + 17×4 + 1-531
Neuron 3200×5 + 17×(-6) + 2900

Then apply sigmoid element-wise to Z = [165, -531, 900]:

A = g(Z) ≈ [1, 0, 1]

sigmoid(165) rounds to 1, sigmoid(-531) rounds to 0, sigmoid(900) rounds to 1 — these z-values are so extreme that sigmoid saturates completely.

The Full Vectorized dense() Function

def dense(AT, W, b):
    z = np.matmul(AT, W) + b
    a_out = g(z)
    return a_out

# → [[1, 0, 1]]

Three lines. No loop. This is the complete vectorized replacement for the earlier loop-based version.

One Naming Difference: AT vs A_in

Compared to an earlier lesson's code, this slide's AT plays the same role as A_in did before — same thing, different variable name.

⚠️ TensorFlow's actual convention

TensorFlow lays individual training examples out as rows of the input matrix X (not XT). That's exactly why earlier TensorFlow examples used X = np.array([[200, 17]]) directly, rather than needing to manually transpose anything — the "row = one example" convention is built in from the start.

🎯 Why this matters

This handful of lines is the entire computational core of a neural network layer — everything else (Sequential, compile, fit) is orchestration around this matrix multiply. Modern hardware (CPUs and especially GPUs) is extraordinarily optimized for exactly this operation, which is the real reason deep learning became computationally practical at scale.
