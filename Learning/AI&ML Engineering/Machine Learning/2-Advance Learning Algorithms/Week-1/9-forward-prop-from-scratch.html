Forward Propagation from Scratch (Plain Python)

Lesson 9 · Implementing a single layer's forward pass with no TensorFlow — pure NumPy

Purpose

Goal: build intuition for what TensorFlow/PyTorch actually do internally by hand-coding one layer of forward propagation using nothing but np.array, np.dot, and a sigmoid function.

This is explicitly a learning exercise, not something done in real projects — but understanding it means you can reason about what's going wrong if something ever breaks in a real framework.

Key Convention Shift: 1D Arrays, Not 2D

Unlike the TensorFlow examples (which used double brackets → 2D matrices), this from-scratch code uses 1D arrays — single square brackets — for every vector and parameter:

x = np.array([200, 17])          # 1D array, not [[200, 17]]

This matches Course 1's convention rather than TensorFlow's — since this is manual math, not a Keras call, there's no requirement to keep the batch dimension.

Notation Used in Code

Math notationCode variableMeaning
w1[1]w1_1Weights, layer 1, neuron 1 (subscript after underscore)
b1[1]b1_1Bias, layer 1, neuron 1
w1[2]w2_1Weights, layer 2, neuron 1

Reading convention: the number right after the underscore is the subscript (neuron index); the layer number is baked into the variable name itself (w1_ = layer 1, w2_ = layer 2).

Layer 1: Computing a1_1, a1_2, a1_3 by Hand

aj[1] = g( wj[1] · x + bj[1] )
x = np.array([200, 17])

# Neuron 1
w1_1 = np.array([1, 2]);   b1_1 = np.array([-1])
z1_1 = np.dot(w1_1, x) + b1_1
a1_1 = sigmoid(z1_1)

# Neuron 2
w1_2 = np.array([-3, 4]);  b1_2 = np.array([1])
z1_2 = np.dot(w1_2, x) + b1_2
a1_2 = sigmoid(z1_2)

# Neuron 3
w1_3 = np.array([5, -6]);  b1_3 = np.array([2])
z1_3 = np.dot(w1_3, x) + b1_3
a1_3 = sigmoid(z1_3)

# Collect into layer 1's output vector
a1 = np.array([a1_1, a1_2, a1_3])

1Each neuron computes its own z = np.dot(w, x) + b

2Then applies sigmoid: a = sigmoid(z)

3All three outputs get bundled into one array — a1 — which becomes the input to layer 2

Layer 2: Computing a2_1

a1[2] = g( w1[2] · a[1] + b1[2] )
w2_1 = np.array([-7, 8, 9])   # 3 weights — matches a1's 3 elements
b2_1 = np.array([3])

z2_1 = np.dot(w2_1, a1) + b2_1
a2_1 = sigmoid(z2_1)

Notice the key difference: layer 2's dot product uses a1 (layer 1's output) as its input — not the original x. This is the same "l−1" input rule from the general activation formula, just written out concretely.

⚠️ Why this is tedious

Notice every neuron needed its own hardcoded w1_1, b1_1, z1_1, a1_1 variables — this doesn't scale. A layer with 25 neurons would need 25 sets of these lines written out by hand. The next lesson fixes this by generalizing into a loop-based, reusable function that works for any layer size.

🎯 Real-world reading

This is essentially what a "from-scratch" mini deep learning library looks like at its core: a bunch of dot products, additions, and activation functions chained together. Every framework — TensorFlow, PyTorch, even hand-rolled research code — boils down to exactly this, just wrapped in far more efficient, vectorized, GPU-accelerated machinery.
