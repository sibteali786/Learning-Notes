NumPy Broadcasting (Section 2.8)

1The problem it solves: Z = XW + b, where XW comes out as shape (m, j2) — one row of z-values per training example — but b is only shape (1, j2) (or even 1D). Shapes don't match, yet + still works.

2What broadcasting does: NumPy automatically "stretches" the smaller array by replicating it, so b conceptually gets copied to all m rows before the addition — without you writing that copy loop yourself.

Compatibility rule (checked from the rightmost dimension going left): two dimensions are compatible if they're equal, or one of them is 1. If neither, NumPy throws a shape error.

Worked Examples from the Notebook

a = np.array([1,2,3]).reshape(-1,1)   # shape (3,1)
b = 5                                  # scalar
a + b   # → shape (3,1); the scalar 5 is broadcast to all 3 rows
a = np.array([1,2,3,4]).reshape(-1,1)  # shape (4,1)
b = np.array([1,2,3]).reshape(1,-1)    # shape (1,3)
a + b   # → shape (4,3)! Both dimensions stretch — a's single column
        #   repeats across 3 columns, b's single row repeats across 4 rows

This last example is the general case: a (4,1) and a (1,3) array combine into a full (4,3) grid — each gets stretched along the dimension where it's size 1.

Why This Matters for the Dense Layer

This is exactly the scenario in my_dense_v(): XW is shape (m, j2) and b is shape (1, j2) (a 1D vector conceptually). Broadcasting is what silently makes XW + b valid — it stretches the single bias row to apply to every one of the m training examples' z-values, without you writing a loop or manually tiling b.

🎯 Connects back to

This is the same instinct as np.tile from the Coffee Roasting lab — both are ways NumPy/TensorFlow avoid manually duplicating data — but broadcasting does it implicitly and automatically during arithmetic, whereas np.tile is an explicit, deliberate duplication you call yourself.

⚠️ Bias convention note (from the notebook)

The bias vector b can technically be represented as either 1D (n,) or 2D (1,n) — mathematically equivalent for broadcasting purposes. TensorFlow itself uses the 1D convention, and this assignment follows that same choice for consistency.

Big picture: Every reshape in this notebook serves one of three purposes — (1) adding a batch dimension for Keras, (2) un-flattening a pixel vector for display, or (3) matching the row/column convention needed for a particular matmul. Broadcasting then quietly handles the shape mismatch between a matrix of z-values and a single bias vector, which is why the bias addition in your dense layer "just works" despite the shapes not technically matching.
