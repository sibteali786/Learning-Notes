Neural Network Layers, from Logistic Regression to Hidden Layers

How a single logistic-regression "neuron" becomes a layer, why the middle layer is called hidden, and why a network doesn't need you to hand-craft features like x₁·x₂ anymore.

The T-shirt demand prediction network

Four raw inputs feed a hidden layer of three neurons (affordability, awareness, perceived quality), which feed one output neuron: the probability this T-shirt becomes a top seller.

x⃗ → hidden layer → a⃗ (affordability, awareness, perceived quality) → output layer → a (probability)

Core vocabulary

TermMeaning
NeuronA tiny logistic-regression unit — takes in a few numbers, applies 1/(1+e−(w·x+b)), outputs one number. Loosely modeled on a biological neuron, but far simpler.
Activation (a)The output value a neuron sends downstream — e.g. "affordability = 0.83". Term borrowed from neuroscience.
LayerA group of neurons that take the same input vector and each output one activation value, together forming an output vector.
Input layerThe raw feature vector x⃗ (here: price, shipping cost, marketing, material — 4 numbers).
Output layerThe final layer; its activation is the network's prediction.
Hidden layerAny layer between input and output. See below for why it's called "hidden".
Fully connectedIn practice, every neuron in a layer sees every value from the previous layer — the network learns via its weights which inputs to pay attention to, rather than a human wiring specific inputs to specific neurons.
ArchitectureThe choice of how many hidden layers, and how many neurons per layer.
Multilayer perceptronLiterature term for a neural network with this layered structure.

Why is the hidden layer called "hidden"?

Your training set gives you pairs (x, y) — the input features and the true label. It tells you the price, shipping cost, marketing spend, material, and whether the T-shirt actually became a top seller. What it does not tell you is the "correct" value of affordability, awareness, or perceived quality for each example — there's no column for those in your dataset.

Those intermediate values are never directly observed. They exist only inside the network, computed from the input layer and consumed by the output layer — invisible from the outside, which is exactly what "hidden" refers to: not secret or mysterious, just not present in the training data. The network invents its own internal representation to solve the problem, and you never have to label it.

A useful reframe: cover the input side of the diagram and look only at the hidden layer's outputs feeding the final neuron. That remaining piece is just logistic regression — but run on better, learned features instead of the raw ones.

Hidden layers learn features — you don't engineer them

Logistic / linear regression

Manual feature engineering

  • You look at raw inputs (e.g. lot frontage x₁, lot depth x₂) and hand-design a better feature: x₁·x₂ = lot area.
  • Requires domain insight — you decide which combinations matter.
  • Doesn't scale: for many raw features, hand-crafting combinations becomes impractical.
VS

Neural network hidden layer

Learned feature engineering

  • The hidden layer is fed all raw inputs and learns, via its weights, its own intermediate features (affordability, awareness, perceived quality) that make the final prediction easier.
  • No one tells it "affordability = price + shipping" — training data and gradient descent discover that combination.
  • Scales to many features and many layers — this is a large part of why deep learning is so powerful.

Worked example: the lot-area feature, revisited

From the housing price example

In linear regression, predicting house price from frontage x₁ and depth x₂, you'd manually engineer x₁·x₂ as a new "lot area" feature because you, the human, recognized that area (not frontage or depth alone) drives price.

A neural network handed the same raw x₁, x₂ in its input layer doesn't need that insight supplied: a hidden-layer neuron, through training, can learn a weighted combination that approximates "area" (or something even more useful) on its own — because it has access to both raw values and the freedom to combine them via its weights and bias.

Stacking multiple hidden layers

A network isn't limited to one hidden layer. Each layer just inputs a vector and outputs a vector:

x⃗ → [hidden layer 1: 4 neurons] → a⃗₁ → [hidden layer 2: 3 neurons] → a⃗₂ → [output layer: 1 neuron] → a

Choosing the number of hidden layers and neurons per layer is called the network's architecture — it materially affects performance and is covered later in the course.
