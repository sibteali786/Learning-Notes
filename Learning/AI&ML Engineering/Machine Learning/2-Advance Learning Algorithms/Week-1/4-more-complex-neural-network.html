Building a More Complex Neural Network

Lesson 4 · General notation for activations across any layer

The Example Network

A network with 4 layers (by convention: hidden + output layers are counted, input layer is not).

xLayer 0 (input)
→
4 neuronsLayer 1 (hidden)
→
5 neuronsLayer 2 (hidden)
→
3 neuronsLayer 3 (hidden)
→
1 neuronLayer 4 (output)

"A 4-layer neural network" = 3 hidden layers + 1 output layer. The input layer is never counted.

Zooming into Layer 3

Layer 3 takes a[2] (the vector output by layer 2) as input, and has 3 neurons/units, so it outputs a new vector a[3]:

a1[3] = g( w1[3] · a[2] + b1[3] )
a2[3] = g( w2[3] · a[2] + b2[3] )
a3[3] = g( w3[3] · a[2] + b3[3] )

Output of layer 3 → a[3] = [a1[3], a2[3], a3[3]], which then becomes the input to layer 4.

Quick Self-Check (from the video)

Fill in the missing sub/superscripts for the 2nd neuron in layer 3:

a2[3] = g( w2[3] · ? + b2[3] )
✅ a[2] — correct: input is the output vector of the previous layer (layer 2)
❌ a[3] — wrong layer; that's this layer's own output, not its input
❌ a2[2] — wrong; this is a single number, but the input must be the full vector a[2]

Rule of thumb: parameters (w, b) carry the current layer's superscript; the input vector carries the previous layer's superscript.

The General Formula

aj[l] = g( wj[l] · a[l−1] + bj[l] )
SymbolMeaning
lCurrent layer number
jUnit / neuron number within that layer
aj[l]Activation of unit j in layer l (this neuron's output)
wj[l], bj[l]Parameters of unit j in layer l
a[l−1]Output vector of the previous layer = input to this layer
gThe activation function (so far, sigmoid — later, other functions too)
⚠️ Easy mistake to avoid

The input term uses l − 1, not l. You're dot-producting with the previous layer's output, even though the weights/bias use the current layer's index.

One Notation Trick: x = a⁰

To make the formula work uniformly for every layer including the first one, the input features x are renamed a[0]:

a[1] = g( w[1] · a[0] + b[1] ) where a[0] = x

Now the same general equation applies whether l = 1 (using raw input) or l = 4 (using output of layer 3) — no special-casing needed.

🎯 Real-world reading

Think of it like an assembly line: each layer takes the "product" (vector) handed off by the previous station, applies its own set of workers (neurons) with their own tools (weights/bias), and passes a new product forward. Layer 1 is the only station that receives raw material (x) instead of a half-finished product from another station — which is exactly why we relabel x as a[0], so every station follows the identical rule.

Recap

1Layer count = hidden layers + output layer (input layer, "layer 0", is never counted).

2Every neuron's activation: aj[l] = g(wj[l] · a[l−1] + bj[l]).

3Weights/bias superscript = current layer; input vector superscript = previous layer.

4x = a[0] makes the formula consistent from layer 1 all the way to the output layer.
