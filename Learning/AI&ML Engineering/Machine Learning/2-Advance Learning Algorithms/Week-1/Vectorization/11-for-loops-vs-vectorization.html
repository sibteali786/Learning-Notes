For Loops vs. Vectorization

Lesson 11 · Replacing the neuron loop with a single matrix multiplication

Why This Matters

One of the biggest reasons deep learning scaled to huge networks over the past decade: neural network computations can be vectorized — expressed as matrix multiplications instead of loops. GPUs (and even some CPU instructions) are extremely good at large matrix multiplications, running them far faster and in parallel compared to a Python for-loop.

Without this, today's large-scale deep learning simply wouldn't be computationally feasible.

Loop-Based vs Vectorized dense()

Loop-based (previous lesson)
x = np.array([200, 17])
W = np.array([[1, -3, 5],
              [-2, 4, -6]])
b = np.array([-1, 1, 2])

def dense(a_in, W, b):
    units = W.shape[1]
    a_out = np.zeros(units)
    for j in range(units):
        w = W[:, j]
        z = np.dot(w, a_in) + b[j]
        a_out[j] = g(z)
    return a_out

# → [1, 0, 1]
Vectorized (this lesson)
X = np.array([[200, 17]])     # 2D! (1,2)
W = np.array([[1, -3, 5],
              [-2, 4, -6]])    # same as before
B = np.array([[-1, 1, 2]])    # 2D! (1,3)

def dense(A_in, W, B):
    Z = np.matmul(A_in, W) + B
    A_out = g(Z)
    return A_out

The entire for j in range(units) loop collapses into one line: np.matmul(A_in, W).

What Changed — Everything Becomes 2D

VariableLoop versionVectorized version
x / X1D: [200, 17]2D: [[200, 17]] — matches TensorFlow's convention
W2D matrixSame — unchanged
b / B1D: [-1, 1, 2]2D: [[-1, 1, 2]] — a 1×3 matrix
z / ZScalar per neuron2D matrix — the whole layer's z-values at once
a_out / A_out1D array2D matrix

Every quantity — input, weights, bias, z, output — is now a matrix. This uniformity is exactly what lets np.matmul do the whole layer's computation in one call.

What np.matmul Is Doing

Z = np.matmul(A_in, W) + B      # matrix multiplication, then add bias matrix
A_out = g(Z)                    # sigmoid applied element-wise to the whole matrix

1np.matmul(A_in, W) multiplies the input matrix by the weight matrix — this single operation computes all three neurons' weighted sums at once, replacing the loop entirely.

2+ B adds all three biases in one step (matrix addition).

3g(Z) applies sigmoid element-wise across the whole matrix — every entry gets sigmoid'd independently, still in one call.

The mechanics of matrix multiplication itself (why this actually computes the right dot products) are covered in the next two optional videos — skippable if you already know linear algebra.

🎯 Real-world reading

This is exactly why frameworks like TensorFlow insist on 2D arrays everywhere, even for a single example — it's not arbitrary convention, it's what makes the underlying vectorized matrix-multiply implementation possible. A GPU processing one big matrix multiplication is dramatically faster than looping over neurons in Python, and this speedup compounds massively as networks grow to millions/billions of parameters.

Recap

1Loop-based dense(): correct, but slow — computes one neuron at a time.

2Vectorized dense(): same math, but the whole layer computed in one np.matmul call.

3Requires everything (X, W, B, Z, A_out) to be 2D matrices — no more 1D arrays.

4Vectorization is a core reason deep learning can scale to today's massive models.
