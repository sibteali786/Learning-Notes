General Forward Propagation in NumPy

Lesson 10 · Replacing per-neuron hardcoding with a reusable dense() function

The Problem This Solves

Last lesson hardcoded a separate w1_1, w1_2, w1_3 ... for every single neuron. That doesn't scale — a 25-unit layer would need 25 copy-pasted blocks. This lesson writes one general dense() function that works for a layer of any size.

Step 1: Stack Parameters into a Matrix

Instead of separate w1_1, w1_2, w1_3 vectors, stack them as columns of one matrix W:

1  -3  5
2   4  -6
W = np.array([
    [1, -3, 5],
    [2,  4, -6]
])          # 2×3 matrix — column j = weights for neuron j

b = np.array([-1, 1, 2])   # one bias per neuron, stacked in a 1D array

a_in = np.array([-2, 4])   # activation from previous layer (or x if layer 1)
SymbolShapeMeaning
W(n_inputs, n_units)Column j = weight vector for neuron j
b(n_units,)One bias per neuron
a_in(n_inputs,)Output of the previous layer (or x, if this is layer 1)

Convention: capital W = matrix, lowercase a, b, x = vectors/scalars — standard linear algebra notation.

Step 2: The Generic dense() Function

def dense(a_in, W, b):
    units = W.shape[1]              # number of neurons = number of columns in W
    a_out = np.zeros(units)         # e.g. [0, 0, 0]
    for j in range(units):          # j = 0, 1, 2, ...
        w = W[:, j]                 # pull out column j → weights for neuron j
        z = np.dot(w, a_in) + b[j]
        a_out[j] = g(z)             # g = sigmoid, defined outside dense()
    return a_out

1W.shape[1] reads off the number of units directly from the matrix's column count — no hardcoding.

2a_out = np.zeros(units) pre-allocates an empty output array.

3The loop computes each neuron's z and a using W[:, j] (column-slicing syntax) — same math as before, just driven by a loop instead of copy-paste.

Note: g() (sigmoid) is assumed to already be defined elsewhere — it's not redefined inside dense().

Step 3: Chaining Layers with sequential()

def sequential(x):
    a1 = dense(x,  W1, b1)
    a2 = dense(a1, W2, b2)
    a3 = dense(a2, W3, b3)
    a4 = dense(a3, W4, b4)
    f_x = a4
    return f_x

This is the from-scratch equivalent of Keras's Sequential([...]) — each layer's output feeds directly into the next call to dense(). For a 4-layer network, the final activation a4 is returned as f(x), the network's prediction.

🎯 Real-world reading

This dense() + sequential() pair is genuinely the conceptual skeleton every deep learning framework builds on — Keras's Dense layer and Sequential model are doing essentially this, just vectorized (matrix multiply instead of a Python for-loop) and GPU-accelerated for speed.

⚠️ Why this matters for debugging

The instructor stresses: even when using TensorFlow day-to-day, understanding this manual implementation makes you far more effective at debugging — when a model behaves strangely or trains slowly, knowing what's happening under the hood (matrix shapes, dot products, activation functions) lets you reason about the actual cause instead of guessing.
