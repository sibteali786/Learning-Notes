🚀 Boosted Trees & XGBoost

Advanced Learning Algorithms · The most widely-used tree ensemble algorithm today

The One Change From Bagging

Same loop as bagged trees (for b = 1 to B: sample with replacement, train a tree) — except from the 2nd iteration onward:

Instead of picking each of the m training examples with equal (1/m) probability, make it more likely to pick examples the previous trees are still getting wrong.

🎹 The "Deliberate Practice" Analogy

Learning a 5-minute piano piece: replaying the whole piece over and over is slow. Instead, identify the parts you keep messing up and drill just those repeatedly — you improve much faster.

Boosting applies the same idea to trees: focus each new tree's training data on the examples the ensemble-so-far is still misclassifying.

How It Works, Step by Step

1Train tree #1 on a normal sampled-with-replacement dataset.
2Run tree #1 on the original 10 training examples — mark which ones it gets right ✅ / wrong ❌.
3Build the next sampled dataset, but give the misclassified examples a higher chance of being picked.
4Train tree #2 on this "harder examples emphasized" dataset.
5Repeat: for tree b, look at what the ensemble of trees 1 through b−1 is still getting wrong, and bias sampling toward those.
6Do this for a total of B trees, then vote as usual.
Exact math for how much to upweight misclassified examples is complex — but you don't need it to use boosted-tree libraries effectively.

🏆 XGBoost — eXtreme Gradient Boosting

⚡ Fast, efficient open-source implementation
🎯 Good default splitting & stopping criteria out of the box
🛡️ Built-in regularization to prevent overfitting
🥇 Highly competitive — dominant on Kaggle alongside deep learning
🔧 Technical difference: XGBoost doesn't actually generate new resampled datasets each round — instead it assigns different weights to different training examples directly. Same underlying intuition (focus on hard examples), but more computationally efficient since it skips the repeated resampling step.

Using XGBoost in Practice

Classification

from xgboost import XGBClassifier
model = XGBClassifier()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

Regression

from xgboost import XGBRegressor
model = XGBRegressor()
model.fit(X_train, y_train)
y_pred = model.predict(X_test)
That's the whole API — same shape as scikit-learn, just swap the class name for regression vs classification.
