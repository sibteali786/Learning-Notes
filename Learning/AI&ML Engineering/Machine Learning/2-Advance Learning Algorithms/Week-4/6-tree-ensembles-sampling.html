🗳️ Tree Ensembles — Voting Beats a Single Tree

Advanced Learning Algorithms · Setting up the case for Random Forest

The Weakness: One Tree Is Fragile

Change just one of the 10 training examples (one cat's ear shape flips from pointy→floppy, whiskers absent→present) and the highest information-gain feature at the root flips from Ear shape to Whiskers.

Since the root split determines everything below it, one changed example cascades into a completely different tree. That instability is the core problem — a single tree isn't robust.

The Fix: Build Many Trees, Let Them Vote

A tree ensemble = a collection of multiple different decision trees, each a plausible way to classify the same data. For a new example, run it through every tree and take the majority vote.

💡 Any single tree only gets one vote out of many — so one tree's quirky mistake gets outvoted rather than becoming the final answer. That's what makes the ensemble more robust.

Building Block: Sampling With Replacement

To get multiple different trees, you first need multiple different but related training sets. That's what sampling with replacement gives you.

The token demo: 4 tokens (red, yellow, green, blue) in a bag. Pick one, note it, then put it back, shake, pick again — 4 times.

Result: Green, Yellow, Blue, Blue — blue appears twice, red not at all
🔑 The "with replacement" part is essential — without putting the token back, you'd just get the same 4 tokens shuffled every time (no diversity). Replacing lets duplicates and omissions happen, which is exactly what creates variety.

Applying This to the Cat Dataset

📦 Put all 10 training examples in a theoretical "bag."
🎲 Randomly pick one, note it down, put it back, repeat 10 times.
📋 End up with a new set of 10 examples — some repeated, some original ones missing entirely.
This new training set is similar to but meaningfully different from the original — the exact "slightly different data" needed to grow a different tree.

Why This Sets Up Random Forest

Repeat the sampling-with-replacement process B times → get B different resampled training sets → train a tree on each → you now have an ensemble ready to vote. (Random Forest, covered next, adds one more twist: randomizing which features each split is even allowed to consider.)
