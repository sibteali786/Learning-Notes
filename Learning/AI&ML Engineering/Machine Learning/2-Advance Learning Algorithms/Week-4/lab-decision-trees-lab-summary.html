1. Entropy Function

def entropy(p):
    if p == 0 or p == 1:
        return 0
    else:
        return -p * np.log2(p) - (1-p)*np.log2(1-p)
Direct translation of H(p₁) = −p·log₂(p) − (1−p)·log₂(1−p), with the 0·log(0)=0 convention handled explicitly via the if check (avoids a math error).

❓ 3. Why sum(y[left_indices])/len(...) for p_left?

def weighted_entropy(X, y, left_indices, right_indices):
    w_left  = len(left_indices)/len(X)
    w_right = len(right_indices)/len(X)
    p_left  = sum(y[left_indices]) / len(left_indices)
    p_right = sum(y[right_indices]) / len(right_indices)
    return w_left*entropy(p_left) + w_right*entropy(p_right)
y[left_indices]
Pulls out labels of only the animals in the left branch. Since labels are 1 (cat) or 0 (not cat)...
sum(...)
...summing them literally counts cats (zeros contribute nothing, ones count).
📐 sum(y[left]) / len(left) = (cats in branch) / (total in branch) = p₁left exactly as defined in the lecture. This "sum of a 0/1 array = count of positives" trick works because labels are binary — no loop needed.

❓ 4. Why the Same Pattern for p_node?

def information_gain(X, y, left_indices, right_indices):
    p_node = sum(y) / len(y)
    h_node = entropy(p_node)
    w_entropy = weighted_entropy(X, y, left_indices, right_indices)
    return h_node - w_entropy

Identical logic, applied to the whole node instead of one branch: y here is every label currently at that node (before splitting). sum(y)/len(y) = fraction of cats in the whole node = p₁node, fed into entropy() to get H(p_node) — the "before split" baseline subtracted in information gain.

💡 Key Pattern to Remember

sum(binary_array) / len(binary_array) is a reusable NumPy idiom for "fraction of positives" — same trick applies anywhere you need a proportion from 0/1-encoded data (accuracy calculations, class balance checks, etc.), not just decision trees.
