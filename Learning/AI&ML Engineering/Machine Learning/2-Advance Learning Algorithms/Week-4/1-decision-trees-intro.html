Anatomy of a Decision Tree

Root node — topmost node, first feature checked.
Decision node — oval; checks a feature, sends example left/right.
Leaf node — rectangle at the bottom; outputs the final prediction.
Branch label — value of the feature that routes left vs right.
🌱 Why roots on top? Think of it like an indoor hanging plant — roots up top, leaves fall to the bottom. Not a biological tree.

Many Possible Trees, Same Data

For a given dataset, there are many valid decision trees you could build — they differ in which feature gets checked first, and how deep the tree goes.

Tree A: Ear shape → Whiskers → leaf
Tree B: Ear shape → Face shape → leaf
Tree C: Face shape only → leaf (simplest)
Tree D: Face shape → Ear shape → Whiskers → leaf (deepest)

Some trees fit the training set better; some generalize better to cross-validation/test data. The learning algorithm's job: search over possible trees and pick one that does well on both.
