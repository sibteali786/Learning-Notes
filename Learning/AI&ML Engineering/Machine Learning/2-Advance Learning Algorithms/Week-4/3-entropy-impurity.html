📐 Entropy — Measuring Impurity

Advanced Learning Algorithms · Formalizing "how mixed is this set?"

The Problem This Solves

We already knew "all cats" or "all dogs" = pure, and "50/50 mix" = impure. Entropy gives a precise number for anything in between — so different candidate splits can be compared objectively.

Definitions

p₁ = fraction of examples that are cats (label = 1)
p₀ = fraction that are not cats = 1 − p₁
H(p₁) = −p₁·log₂(p₁) − p₀·log₂(p₀)
= −p₁·log₂(p₁) − (1−p₁)·log₂(1−p₁)
📌 Log base 2 (not natural log) — chosen purely so the peak of the curve lands exactly at 1, a clean round number. Base-e would work too, just rescaled.
⚠️ Edge case: 0·log₂(0) is mathematically undefined (technically −∞), but by convention we define it as 0 — so a perfectly pure set correctly gives entropy = 0.

The Entropy Curve — Shape & Intuition

Shape: starts at 0 (p₁=0), rises to peak of 1 at p₁=0.5, symmetric, falls back to 0 at p₁=1. It's symmetric — 2/6 cats (0.92) is more impure than 5/6 cats (0.65) because 2/6 is closer to the 50/50 midpoint.

Real-World Intuition

Think of entropy as "how surprised would you be, guessing randomly?" A jar of 3 red and 3 blue marbles (p=0.5) — you genuinely can't guess which color comes out next, maximum uncertainty. A jar of 6 red marbles — you already know the answer before you look, zero uncertainty. Entropy quantifies exactly that uncertainty/surprise.

Alternative: Gini Impurity

Open-source packages (like scikit-learn) also offer the Gini criterion — a similarly-shaped 0→1→0 curve, computed differently.

Entropy
Used in this course; standard, information-theory grounded; the formula used going forward for decision trees here.
Gini impurity
Faster to compute (no logarithms); scikit-learn's default; produces very similar trees in practice.
Pros/cons: for learning purposes, entropy is more standard and interpretable (ties to information theory). Gini is marginally cheaper computationally since it avoids log operations — a minor speed edge for very large datasets, but rarely a deciding factor.
