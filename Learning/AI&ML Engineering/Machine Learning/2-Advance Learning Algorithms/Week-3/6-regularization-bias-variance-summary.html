Lesson 6 — Regularization and Bias/Variance

How the choice of λ moves a model along the exact same bias↔variance spectrum as polynomial degree did — and how to pick a good λ with cross-validation.

1 Same Model, Different λ — Three Outcomes

Fix the model shape (4th-order polynomial) and vary only the regularization strength λ:

J(w,b) = 1/2m·Σ(f(x⁽ⁱ⁾)−y⁽ⁱ⁾)² + λ/2m·Σwj²
High Bias (underfit)
λ = 10,000

w₁≈0, w₂≈0... → f(x) ≈ b (nearly flat)

J_train LARGE
Intermediate λ
λ = "just right"

Balances fit vs. small weights

J_train small
J_cv small
High Variance (overfit)
λ = 0

No regularization → free wiggly fit

J_train small
J_cv large

Very large λ forces nearly all weights toward zero — the algorithm is so heavily penalized for having non-zero weights that f(x) ≈ b, a near-constant line. λ = 0 removes the penalty entirely, letting the model overfit freely, same as the unregularized 4th-order curve from Lesson 5.

2 Choosing λ with Cross-Validation

Same recipe as choosing polynomial degree — just swap out the thing being varied:

1
Try a range of λ values, doubling each time: 0, 0.01, 0.02, 0.04, 0.08, ... up to ≈10.
2
For each λ, minimize J(w,b) on the training set to get parameters.
3
Evaluate each set of parameters on the cross-validation set, computing J_cv for each λ.
4
Pick the λ with the lowest J_cv, then report generalization error using the test set on that final model — same as before, never touch test until the very end.
λ = 0w⁽¹⁾,b⁽¹⁾J_cv(w⁽¹⁾,b⁽¹⁾)
λ = 0.01w⁽²⁾,b⁽²⁾J_cv(w⁽²⁾,b⁽²⁾)
λ = 0.02w⁽³⁾,b⁽³⁾J_cv(w⁽³⁾,b⁽³⁾)
λ = 0.04w⁽⁴⁾,b⁽⁴⁾J_cv(w⁽⁴⁾,b⁽⁴⁾)
λ = 0.08w⁽⁵⁾,b⁽⁵⁾J_cv lowest ✓ → pick this
⋮⋮⋮
λ ≈ 10w⁽¹²⁾,b⁽¹²⁾J_cv(w⁽¹²⁾,b⁽¹²⁾)

Final answer: report J_test(w⁵,b⁵) as the generalization estimate for the chosen λ = 0.08 model.

3 J_train and J_cv as Functions of λ

J_train rises steadily as λ grows — more penalty on weights means less freedom to fit training data well. J_cv dips then rises — same U-shape as before, minimum marks the best λ.

Why J_train increases with λ: the more weight the cost function gives to keeping w small, the less attention it pays to minimizing actual prediction error — so training fit gets steadily worse as λ grows, unlike the polynomial-degree case where more flexibility always helped J_train.

4 Mirror Image of the Polynomial-Degree Curve

vs. Polynomial Degree (Lesson 5)

Left (low d) = underfit = high bias.
Right (high d) = overfit = high variance.

vs. Regularization λ (this lesson)

Left (low λ) = overfit = high variance.
Right (high λ) = underfit = high bias.

The two curves are effectively mirror images — not mathematically identical, but conceptually: whichever axis you're varying, the same underlying U-shaped J_cv curve appears, with high bias on one end and high variance on the other. Cross-validation is the tool that finds the sweet spot on either axis.

5 Key Takeaway

The Pattern Generalizes

Whether you're choosing polynomial degree, regularization strength, or (as seen earlier) neural network architecture — the procedure is identical: sweep candidate values, fit on train, evaluate on CV, pick the lowest J_cv, and report the honest generalization estimate using J_test only once, at the very end.
