Lesson 15 — Transfer Learning

Borrowing strength from an unrelated task when your own dataset is too small to train from scratch.

1 The Core Idea

Goal: recognize handwritten digits 0–9, but with very little labeled digit data. Instead of training from scratch, start from a network already trained on a completely different task with abundant data.

Layers 1-4 (edges, corners, shapes) are copied over as a starting point. Only the output layer is replaced — its dimensions don't match (1000 classes vs. 10), so it must be trained fresh.

2 Two Ways to Fine-Tune

Option 1 — Train only the output layer

Freeze W¹,b¹ through W⁴,b⁴ exactly as copied. Only train the new W⁵,b⁵ using your small digit dataset. Best when your dataset is very small.

Option 2 — Train all parameters

Start all layers from the copied values, but let gradient descent update every layer, not just the output. Best when your dataset is somewhat larger.

The rule of thumb: the smaller your target dataset, the more you rely on the pre-trained layers as-is (Option 1); as your dataset grows, it becomes worth letting the earlier layers adapt too (Option 2).

3 Two-Step Vocabulary

1
Supervised pre-training — training the original network on a large, not-quite-related dataset (e.g. 1M images across 1,000 classes: cats, dogs, cars, people).
2
Fine-tuning — taking those pre-trained parameters as a starting point and running gradient descent further on your specific, smaller dataset (e.g. digit images).

4 Why This Works — What Early Layers Actually Learn

Layer 1
Detects edges — low-level, generic visual features
Layer 2
Groups edges into corners
Layer 3
Groups corners into curves / basic shapes

These early-layer features — edges, corners, curves — are generic to almost any visual recognition task, not specific to cats or dogs. That's why they transfer usefully to a completely different visual task like digit recognition: the network isn't "remembering cats," it's remembering how to see structure in images at all.

The one hard constraint

The input type must match between pre-training and fine-tuning. A network pre-trained on images can transfer to another image task, but not to audio or text — you need a network pre-trained on the same modality as your actual application (image → image, audio → audio, text → text).

5 You Usually Don't Need to Pre-Train Yourself

Many researchers have already trained large networks and posted the weights publicly, free to download and fine-tune. Practically, this means:

1
Download a network pre-trained on a large dataset with the same input type as your application (or train your own, if nothing suitable exists).
2
Fine-tune it on your own, much smaller dataset.
1,000,000
images used for pre-training
1,000
images to fine-tune well
~50
images — sometimes enough

This isn't a guarantee for every application, but when it applies, it can dramatically cut down how much labeled data you actually need to get a good result.

6 Real-World Examples

GPT-3, BERT, and networks pre-trained on ImageNet are all well-known examples of this exact pattern: massive pre-training on one large dataset, followed by fine-tuning on a specific downstream task.

7 Key Takeaway

Transfer learning is community-powered

Freely-shared pre-trained models are one of the clearest examples of the ML community building on each other's work — researchers who spend weeks pre-training a large network and release it let anyone else fine-tune a strong model on as little as tens of examples. When your dataset is small and a matching pre-trained model exists, this is often far more effective than trying to collect enough data to train from scratch.
