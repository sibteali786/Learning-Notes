❓ Why Do We Need Activation Functions?

🚨 The Big Claim

If every neuron in a neural network uses the linear activation function g(z) = z, the whole network collapses into being exactly equivalent to plain linear regression — no matter how many layers or units you stack. This defeats the entire purpose of building a neural network.

🔬 Proof With a Simple Example

Take the simplest possible network: input x is a single number, one hidden unit (w[1], b[1]) outputs a[1], and one output unit (w[2], b[2]) outputs a[2] = f(x). Use g(z) = z everywhere.

g
→ a[1] →
g
→ a[2]
1️⃣   a[1] = g(w1[1]x + b1[1]) = w1[1]x + b1[1]  (since g(z)=z)
↓ substitute into next layer
2️⃣   a[2] = w1[2]·a[1] + b1[2] = w1[2](w1[1]x + b1[1]) + b1[2]
↓ expand and group terms
3️⃣   a[2] = (w1[2]w1[1])·x  +  (w1[2]b1[1] + b1[2])
↓ let w = w1[2]w1[1], b = w1[2]b1[1] + b1[2]
4️⃣   a[2] = w·x + b
a two-layer "neural network" with linear activations = just linear regression, f(x) = wx + b

📐 Linear algebra intuition: a linear function of a linear function is still just a linear function. Stacking layers adds no new expressive power if every g(z) = z.

📊 The General Case (4-Layer Network)

All layers linear (incl. output)

a[4] = w1[4]·a[3] + b1[4]

≡ Linear Regression

Hidden layers linear, output = sigmoid

a[4] = 1 / (1 + e−(w1[4]·a[3] + b1[4]))

≡ Logistic Regression

Either way — even with 3 hidden layers full of neurons — the network can't compute anything a single logistic/linear regression model couldn't already do. All the "depth" is wasted.

🎯 Back to Demand Prediction

If every neuron (affordability, awareness, perceived quality → top seller) used a linear g(z), the whole pipeline reduces to:

f(x) = w⃗ · x⃗ + b

...exactly what plain linear regression on price, shipping cost, marketing, and material would give you directly — the hidden layer adds nothing.

✅ The Rule of Thumb

  • Never use the linear activation function in hidden layers.
  • ReLU is the safe, effective default for hidden layers (as covered in the previous lesson).
  • Linear activation is fine only at the output layer, for regression problems where y can be negative or positive.

🌍 Real-World Analogy

Imagine a relay race where each runner (layer) is supposed to add something new — speed, strategy, terrain-handling. If every runner just hands the baton over unchanged (a linear pass-through), it doesn't matter how many runners you add to the team — the final result is identical to having just one runner do the whole race alone.

Activation functions like ReLU are what let each "runner" actually transform the baton — bending, reshaping, and combining signals in non-linear ways — which is what lets multi-layer networks learn things a single-layer model never could (like complex image or speech patterns).
