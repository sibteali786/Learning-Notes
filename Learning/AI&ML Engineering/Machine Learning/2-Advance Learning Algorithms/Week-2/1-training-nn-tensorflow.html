💻 The Full Code

import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

# Step 1 — specify the model (architecture)
model = Sequential([
    Dense(units=25, activation='sigmoid'),
    Dense(units=15, activation='sigmoid'),
    Dense(units=1,  activation='sigmoid'),
])

from tensorflow.keras.losses import BinaryCrossentropy

# Step 2 — compile the model (specify the loss function)
model.compile(loss=BinaryCrossentropy())

# Step 3 — train the model (fit to data)
model.fit(X, Y, epochs=100)

Nothing new in the architecture part (Sequential + Dense layers) — that's exactly what you built last week for inference. What's new this week is compile and fit.

🔢 The 3 Steps to Train a Neural Network

1

Specify the Model

Tell TensorFlow the architecture — how to string layers together to compute inference (forward propagation).

model = Sequential([...])

2

Compile the Model

Specify the loss function — here, BinaryCrossentropy(), since this is a binary classification problem (0 or 1).

model.compile(loss=...)

3

Fit / Train the Model

Actually train on data X, Y using the loss from Step 2, running gradient descent for a set number of epochs.

model.fit(X, Y, epochs=100)

⏱️ What is an "Epoch"?

Epoch = the technical term for how many steps of gradient descent to run — same idea as "how long to run gradient descent" from Course 1.

🌍 Real-World Analogy

Think of training a neural network like teaching a student to recognize handwriting:

  • Step 1 (Specify model): Decide the structure of the "student's brain" — how many layers of reasoning, how many neurons at each stage.
  • Step 2 (Compile): Decide how you'll grade the student's mistakes — the loss function measures "how wrong" a prediction is.
  • Step 3 (Fit): Actually run the practice sessions — the student sees examples, gets graded, adjusts, and repeats for epochs rounds until it improves.
