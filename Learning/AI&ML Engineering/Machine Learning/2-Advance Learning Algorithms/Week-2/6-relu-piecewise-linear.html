🧩 ReLU: Stitching Linear Segments Together

🎯 The Goal

Build a piecewise-linear target curve using 3 ReLU units, each contributing one segment, added together at the output:

output = a0 + a1 + a2   where each  aᵢ = max(0, wᵢ·x + bᵢ)

🔑 The Core Idea

  • Weight (w) → controls how steep a unit's contribution is once switched on
  • Bias (b) → controls where (at what x) the unit switches on/off
  • ReLU → forces the unit's contribution to be exactly 0 before its threshold, so it doesn't interfere with earlier segments

💡 Each unit only needs to add its extra slope on top of whatever the previous units already contribute — not the full target slope.

⚙️ Worked Example — 3 Units, 3 Segments

0

Unit 0 — Segment 1 (slope 1)

z0 = 1·x + 0
a0 = max(0, x)

Active from x=0 onward, slope 1. Its line keeps rising after x=1 too — that's fine, later units correct for it.

1

Unit 1 — Segment 2 (slope 2)

z1 = 1·x − 1
a1 = max(0, x − 1)

OFF for x<1 (z1 negative → clipped to 0)
ON for x≥1, adds +1 slope → total becomes 1+1=2 ✅

2

Unit 2 — Segment 3 (slope 3)

z2 = 1·x − 2
a2 = max(0, x − 2)

OFF for x<2
ON for x≥2, adds +1 slope → total becomes 2+1=3 ✅

🌍 Real-World Analogy — Income Tax Brackets

  • Bracket 1: first $10k taxed at 10% — always active from $0.
  • Bracket 2: +20% on income above $10k — "off" (contributes $0 extra tax) until income crosses $10k, exactly like ReLU clipping.
  • Bracket 3: +30% on income above $40k — stays off until that threshold, then switches on.

The threshold ($10k, $40k) = the bias. The rate (10%, 20%, 30%) = the weight. Summing all brackets' contributions gives the same kind of piecewise-linear curve as the ReLU units — each bracket dormant until its turn, just like each ReLU unit.

✅ Takeaway

The ReLU's "off until threshold" behavior is exactly what makes it non-linear and useful: it lets each hidden unit stay silent until its segment begins, so multiple simple straight-line units can be stitched together into one complex, curved (piecewise-linear) function.
