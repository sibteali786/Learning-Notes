Derivatives — The Intuition Behind Backpropagation

Course 2 · Improving Deep Neural Networks · Optional Calculus Deep-Dive

CORE IDEA What a Derivative Actually Means

Nudge w by a tiny amount ε. Watch how much J(w) moves in response. The ratio between "how much J moved" and "how much w moved" is the derivative.

If w ↑ ε causes J(w) ↑ k·ε, then the derivative ∂J(w)/∂w = k

The smaller ε is, the more exact this ratio becomes — true derivatives use an infinitesimally small ε.

WORKED EXAMPLE J(w) = w², nudging by ε

Slope of the tangent line at each point = the derivative there. J(w)=w² → derivative = 2w

Same function J(w)=w², but the derivative changes depending on the current value of w — that's why gradient descent's step size naturally adapts as w moves.

WHY IT MATTERS Connection to Gradient Descent

repeat {
  wj = wj − α · ∂J(w,b)/∂wj  // α = learning rate
}
  • Small derivative → changing w barely affects J → take a small step.
  • Large derivative → changing w strongly affects J → take a big step, since it pays off in bringing J down faster.

NOTATION d vs ∂ — Which One This Course Uses

CaseSymbolWritten as
J is a function of one variable (w)dd/dw · J(w)
J is a function of multiple variables (w₁…wₙ)∂ ("partial derivative")∂J/∂wi

Andrew Ng's teaching choice: since J almost always depends on multiple parameters in practice, this course consistently uses the ∂ (partial derivative) notation everywhere — even in single-variable toy examples — to keep things uniform, even though strict calculus convention would use d for the single-variable case.

Real-world scenario: Training a neural network on house-price prediction, if the derivative of the cost function with respect to one weight (say, "number of bedrooms" weight) is huge, that means small tweaks to that weight swing predictions a lot — gradient descent should adjust it aggressively. If the derivative w.r.t. another weight (say, "house was painted last year") is tiny, that weight barely matters to the current loss, so gradient descent barely touches it. Backpropagation is exactly the algorithm that computes all these per-parameter derivatives efficiently across every layer.
