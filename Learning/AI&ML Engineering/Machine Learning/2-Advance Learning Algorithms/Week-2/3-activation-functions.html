🎛️ Activation Functions: Sigmoid, ReLU & Linear

🤔 Why Not Just Use Sigmoid Everywhere?

So far every neuron used sigmoid — because neural networks were built by chaining together logistic regression units. But sigmoid forces the output between 0 and 1, which isn't always the right shape for what a neuron represents.

The problem: "awareness" isn't really binary (aware / not aware). It can be a little aware, somewhat aware, extremely aware, or completely viral — i.e. it should be able to take any non-negative value, not be squashed into [0, 1].

a2[1] = g(w⃗2[1] · x⃗ + b2[1])  where  z = w⃗2[1] · x⃗ + b2[1]

Swapping in a different g(z) lets this neuron's activation grow as large as needed — this is exactly what ReLU was designed for.

📈 The 3 Most Common Activation Functions

Sigmoid

g(z) = 1 / (1 + e−z)
Output always between 0 and 1

ReLU (Rectified Linear Unit)

g(z) = max(0, z)
If z < 0 → g(z) = 0
If z ≥ 0 → g(z) = z

Linear ("no activation")

g(z) = z
a = g(z) = w⃗·x⃗ + b — as if g wasn't there at all

📝 Note on terminology: if a neuron uses the linear activation, people often say "no activation function" — because a = g(z) = z just equals the raw w⃗·x⃗ + b. In this course Andrew still calls it "using the linear activation function" for precision, but know both terms mean the same thing.

🌍 Real-World Analogy

Think of activation functions like different types of gauges/meters:

  • Sigmoid = a percentage dial (0%–100%) — perfect for "probability someone is aware," but useless for "how many people saw this ad," which has no upper cap.
  • ReLU = a car's speedometer that starts at 0 and goes up — it can't show negative speed, but has no upper limit either. Great for "awareness level," "viral reach," anything that's naturally ≥ 0.
  • Linear = a plain thermometer — the reading passes straight through with no clamping at all, positive or negative. Good for regression outputs like predicting temperature or price.

Picking the right activation function is like picking the right gauge for what you're actually measuring.
