Convolutional Layer & Convolutional Neural Networks

Course 2 · Improving Deep Neural Networks · Alternative Layer Types

CONCEPT Dense vs Convolutional

In a dense layer, every neuron sees every activation from the previous layer. In a convolutional layer, each neuron only looks at a small window/region of the previous layer's outputs — not the whole thing.

Convolutional layer — colored boxes = the region each neuron "sees"

WHY Benefits of Restricting the Field of View

  • Faster computation — fewer connections per neuron than a fully dense layer.
  • Needs less training data / less prone to overfitting — fewer parameters to learn per neuron.

Popularized by researcher Yann LeCun, who worked out the practical details that made convolutional layers effective.

EXAMPLE 1D Convolution — EKG Signal Classification

Input: an EKG (electrocardiogram) signal as 100 numbers (x₁…x₁₀₀), each the voltage/height at a point in time. Task: classify presence/absence of heart disease.

Layer 1: 9 units, each sees a 20-wide window of x. Layer 2: 3 units, each sees a 5-wide window of layer-1 activations. Output: sigmoid over all 3.
Layer Units What each unit sees
Hidden layer 1 (conv) 9 Sliding 20-wide windows of raw input, e.g. x1–x20, x11–x30, x21–x40 … x81–x100
Hidden layer 2 (conv) 3 Sliding 5-wide windows of layer-1 activations, e.g. a1–a5, a3–a7, a5–a9
Output 1 Sigmoid over all 3 activations from layer 2 → binary classification

DESIGN Architectural Choices

  • Window size — how many inputs each neuron looks at (e.g. 20-wide, then 5-wide).
  • Number of neurons per layer — determines how the windows overlap/slide across the signal.
  • Stacking multiple convolutional layers → a Convolutional Neural Network (CNN).

Not required for this course's homework — this is intuition-building only. Modern architectures (transformers, LSTMs, attention models) follow the same theme: researchers designing new layer types as building blocks.

Real-world scenario: A hospital wants to flag arrhythmia from a wearable EKG monitor's continuous 1D voltage stream. Instead of a dense layer connecting every timestep to every neuron (huge parameter count, prone to overfitting on limited patient data), a 1D convolutional layer lets each neuron specialize in local wave patterns (like a P-wave or QRS complex) within a short time window — mirroring the Stanford EKG research described in this lesson.
