🖧 Neural Network with a Softmax Output Layer

🏗️ From 2-Class to 10-Class Architecture

Previously (binary digit recognition: 0 vs 1), the output layer had 1 unit. For full MNIST (all 10 digits), swap the output layer to 10 units with a softmax activation.

⋮
25 units
(ReLU)
→ a[1] →
15 units
(ReLU)
→ a[2] →
⋮
10 units
(Softmax)
→ a[3]

Hidden layers unchanged (ReLU, computed exactly as before). Only the output layer changes.

🧮 Forward Propagation Through the Softmax Layer

z1[3] = w⃗1[3]·a⃗[2] + b1[3]    ⋯    z10[3] = w⃗10[3]·a⃗[2] + b10[3]
a1[3] = ez₁⁽³⁾ / (ez₁⁽³⁾+⋯+ez₁₀⁽³⁾) = P(y=1|x⃗)
⋮
a10[3] = ez₁₀⁽³⁾ / (ez₁⁽³⁾+⋯+ez₁₀⁽³⁾) = P(y=10|x⃗)

Same z-computation pattern you already know (weighted sum + bias), just now producing 10 z-values that feed into one softmax formula together.

⚡ Softmax's Unique Trait

Sigmoid / ReLU / Linear

a₁ depends only on z₁. a₂ depends only on z₂. Applied element-wise.

a1 = g(z1),   a2 = g(z2)

Softmax

a₁ depends on all of z₁ through z₁₀ simultaneously (because of the shared denominator).

a⃗[3] = (a₁,...,a₁₀) = g(z₁,...,z₁₀)

🔍 This is why softmax is often called a "layer-wide" activation rather than a per-neuron one — you can't compute any single aⱼ without knowing every zₖ.

💻 TensorFlow Implementation

import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

# Step 1 — specify the model
model = Sequential([
    Dense(units=25, activation='relu'),
    Dense(units=15, activation='relu'),
    Dense(units=10, activation='softmax')   # 10 classes
])

from tensorflow.keras.losses import SparseCategoricalCrossentropy

# Step 2 — specify loss and cost
model.compile(loss=SparseCategoricalCrossentropy())

# Step 3 — train on data to minimize J(W,B)
model.fit(X, Y, epochs=100)

🏷️ Why "Sparse Categorical Crossentropy"?

WordMeaning
Categoricaly falls into categories — here, values 1 through 10 (like the "cross-entropy" loss from softmax regression)
SparseEach example belongs to exactly one category at a time — a digit image is never simultaneously a "2" and a "7"

↔️ Compare: logistic regression (binary) used BinaryCrossentropy. Softmax regression (multiclass, one label per example) uses SparseCategoricalCrossentropy.

🌍 Real-World Analogy

Think of the softmax output layer like a panel of 10 judges scoring one contestant in a singing competition, where the contestant can only truly belong to one "genre" (jazz, pop, rock, etc.). Each judge gives a raw compatibility score (z), but the judges must then collectively normalize their scores into a single 100%-sum probability distribution — no judge can score in isolation, because the final percentages depend on how every other judge scored too. That's exactly why softmax activations are computed jointly, unlike ReLU/sigmoid where each neuron minds its own business.
