🔢 Multiclass Classification

📌 What's New

Until now, classification meant binary — Y is 0 or 1. Multiclass classification is still a classification problem (Y takes a small number of discrete categories), but now Y can take on more than 2 possible values.

Reading digits on an envelope — 10 possible classes (0–9).

Classifying a patient into one of 3–5 possible diseases.

💊 Visual Defect Inspection

Classifying a manufactured pill as having a scratch, discoloration, or chip defect.

📊 Binary vs Multiclass — Decision Boundaries

Binary Classification (2 classes)

One line divides the space into 2 regions: "class 1" vs "not 1"

Multiclass Classification (4 classes)

Multiple boundaries divide the space into 4 regions — one per class

🎲 From "Probability of 1" to "Probability of Each Class"

Binary (logistic regression): estimate a single probability

P(y = 1 | x⃗)

Multiclass: estimate a probability for each possible class

P(y=1|x⃗),   P(y=2|x⃗),   P(y=3|x⃗),   P(y=4|x⃗),   ...

📈 Each region in the 4-class plot corresponds to where one of these probabilities is highest — the model picks whichever class has the greatest P(y=k | x⃗).

🌍 Real-World Analogy

Binary classification is like a yes/no bouncer at a club door — "are you on the list or not?" Multiclass classification is like a mail sorting machine at a post office: instead of just "domestic vs international," it has to sort every letter into one of many bins — by zip code digit, by region, by class of mail — picking exactly one bin out of many possible ones for each letter.
