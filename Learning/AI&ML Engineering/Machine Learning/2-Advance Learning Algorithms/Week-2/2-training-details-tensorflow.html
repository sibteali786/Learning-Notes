⚙️ Training Details — What TensorFlow Is Actually Doing

🔁 The Same 3 Steps as Logistic Regression

Training a neural network in TensorFlow follows exactly the same 3-step recipe you used for logistic regression in Course 1 — just applied to a bigger, layered function.

① Logistic Regression

z = np.dot(w,x) + b

f_x = 1/(1+np.exp(-z))

fw,b(x) = ?

① Neural Network

model = Sequential([
  Dense(...),
  Dense(...),
  Dense(...),
])

② Logistic Loss

loss = -y*log(f_x)
   -(1-y)*log(1-f_x)

② Binary Cross-Entropy

model.compile(
  loss=BinaryCrossentropy())

③ Gradient Descent

w = w - alpha*dj_dw

b = b - alpha*dj_db

③ model.fit

model.fit(X, y, epochs=100)

💡 Same underlying math (loss → cost → gradient descent) — TensorFlow just handles the derivatives and updates for you across every layer instead of a single w, b.

1️⃣ Create the Model — Specify f(x)

The Sequential([...]) code snippet fully specifies the network's architecture — and by doing so, tells TensorFlow exactly what parameters exist at each layer: W[1], b[1], W[2], b[2], W[3], b[3].

import tensorflow as tf
from tensorflow.keras import Sequential
from tensorflow.keras.layers import Dense

model = Sequential([
    Dense(units=25, activation='sigmoid'),
    Dense(units=15, activation='sigmoid'),
    Dense(units=1,  activation='sigmoid'),
])

2️⃣ Loss and Cost Functions

For binary classification (0 vs 1), the loss is the same logistic loss from Course 1 — just applied to the neural network's output f(x) instead of logistic regression's output:

L(f(x), y) = −y·log(f(x)) − (1−y)·log(1−f(x))

In TensorFlow, this is called Binary Cross-Entropy ("cross-entropy" from statistics, "binary" because each label is 0 or 1).

Averaging the loss over all m training examples gives the cost function — now a function of all parameters in the network:

J(W, B) = (1/m) · Σᵢ L(f(x⁽ⁱ⁾), y⁽ⁱ⁾)

where W = {W[1], W[2], W[3]} and B = {b[1], b[2], b[3]}

from tensorflow.keras.losses import BinaryCrossentropy
model.compile(loss=BinaryCrossentropy())

Regression instead of classification?

Swap the loss for Mean Squared Error:

from tensorflow.keras.losses import MeanSquaredError
model.compile(loss=MeanSquaredError())

3️⃣ Gradient Descent — Minimizing the Cost

Same gradient descent update rule as before, but now applied to every parameter in every layer:

repeat {
  wj[l] = wj[l] − α · ∂J(W,B)/∂wj[l]
  bj[l] = bj[l] − α · ∂J(W,B)/∂bj[l]
}

The hard part is computing all those partial derivative terms. TensorFlow does this using an algorithm called backpropagation — and it's all bundled inside fit():

model.fit(X, y, epochs=100)

✨ Bonus: TensorFlow can also use algorithms slightly faster than plain gradient descent (more on that later this week — hint: Adam optimizer).

🗺️ Full Picture — 3 Steps Side by Side

1

Define f(x)

Specify architecture → TensorFlow infers all W's and b's needed.

2

Define Loss → Cost

Loss = error on 1 example. Cost J(W,B) = average loss over all m examples.

3

Minimize Cost

Gradient descent + backpropagation (computed automatically by fit).

🌍 Real-World Analogy

Think of it like coaching a sports team across multiple positions (layers) instead of just one player (logistic regression):

  • Step 1 (architecture): You decide how many players are on each line — defense (25), midfield (15), striker (1) — and how each position passes the ball forward.
  • Step 2 (loss/cost): After each match, you score how badly the team's overall result (win/loss prediction) missed the actual outcome — averaged across the whole season (all training examples).
  • Step 3 (gradient descent + backprop): You adjust every player's technique, working backward from the striker's miss through midfield to defense, tiny step by tiny step, over 100 practice sessions (epochs) — this backward-adjustment process is exactly what backpropagation does.
