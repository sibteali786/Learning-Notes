Machine Learning · Concepts

Hyperparameters

Settings you choose before training that control how the model learns — not the numbers the model learns itself.

1 Parameter vs. Hyperparameter

Parameter

Learned automatically by the training algorithm. You never set these by hand.

  • w, b in linear/logistic regression
  • Weights inside a neural network
  • Found via gradient descent minimizing J(w,b)
Hyperparameter

Chosen by you before/around training. Controls how learning happens.

  • Polynomial degree d
  • Regularization strength λ
  • Learning rate α, layers, units, epochs

4 The Golden Rule

Best Practice

Choose hyperparameters using only train and cross-validation data. Never touch the test set during selection — evaluate on test exactly once, after the model is locked in, to get an unbiased estimate of generalization.

Train 60%
CV 20%
Test 20%

Hyperparameter tuning happens across Train + CV only — Test stays untouched until the very end.
