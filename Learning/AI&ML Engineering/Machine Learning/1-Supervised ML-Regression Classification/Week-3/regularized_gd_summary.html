Machine Learning · Regularization, Part 2

Making gradient descent shrink the weights

The regularized cost function only changes one thing about gradient descent: the update for each wj picks up an extra term. b's update doesn't change at all — we never penalize b.

01 · What Changes, What Doesn't

Same algorithm, one new term

Gradient descent for regularized linear regression looks exactly like the version you already know — repeatedly nudge wj and b downhill — except the gradient with respect to wj now carries the regularization term along with it.

repeat { wj = wj − α [ (1/m) ∑i=1..m (f(x⃗ⁱ) − yⁱ)·xj(i) + λ/m·wj ] b = b − α (1/m) ∑i=1..m (f(x⃗ⁱ) − yⁱ) } simultaneous update, j = 1..n

wj update

Gains + λ/m·wj — this is the whole effect of regularization on the gradient.

b update

Completely unchanged. We never regularize b, so its gradient has no new term.

02 · The Intuition

Regularization = shrink a little, every single step

Rearrange the wj update by pulling the new term to the front:

wj = wj·(1 − αλ/m) − α·(1/m) ∑i=1..m (f(x⃗ⁱ) − yⁱ)·xj(i) ↑ ↑ shrink wj first usual gradient-descent update

The second piece is exactly the ordinary linear-regression update. The first piece is new: before applying that usual update, wj is multiplied by a number just under 1.

Worked example — α = 0.01, λ = 1, m = 50

α·λ/m0.01 × 1/50 = 0.0002
1 − αλ/m0.9998
wj becomeswj × 0.9998
Every single iteration, before the usual gradient step even runs, wj is shrunk by a hair. Do that thousands of times and small-but-unhelpful weights get squeezed toward 0.
Key idea

Regularization doesn't add a separate "shrinking phase" — it's baked directly into every gradient descent step as a small multiplicative decay on each wj.

03 · Where the Derivative Comes From (optional)

Differentiating the regularized cost

Start from the full cost function and differentiate term by term with respect to wj:

J(w⃗,b) = (1/2m) ∑i=1..m (f(x⃗ⁱ) − yⁱ)² + λ/2m ∑j=1..n wj²
1
∂J/∂wj = (1/2m)∑(f(x⃗ⁱ)−yⁱ)·2xj(i) + (λ/2m)·2wj
2
the 2's cancel → (1/m)∑(f(x⃗ⁱ)−yⁱ)·xj(i) + (λ/m)·wj
3
note: the regularization term has no ∑j=1..n left — you differentiated with respect to one specific wj, so only that term survives

b's derivative is untouched because b never appears in the regularization term — differentiating a constant with respect to b gives 0.

Takeaways

wj += λ/m·wj term b unchanged wj × (1−αλ/m) each step simultaneous update
  • Regularized gradient descent is identical to plain gradient descent, except each wj's gradient gains a +λ/m·wj term.
  • b's gradient is unchanged — consistent with the convention of not regularizing b.
  • Rewriting the update shows wj is shrunk by a factor (1 − αλ/m), slightly less than 1, before the usual squared-error update is applied.
  • The derivative comes from differentiating the MSE term (as before) plus the regularization term, where the summation over j collapses to a single wj once you differentiate with respect to that one weight.
