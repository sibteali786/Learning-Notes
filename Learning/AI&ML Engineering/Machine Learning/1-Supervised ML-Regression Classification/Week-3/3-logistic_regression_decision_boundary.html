1. The Logistic Regression Model recap

x (features)
→
z = w·x + b
→
g(z) = sigmoid
→
f(x) ∈ (0,1)
fw,b(x) = g(w·x + b) = 1 / (1 + e−(w·x+b)) = P(y=1 | x; w, b)

The output is interpreted as a probability that y = 1 given x. E.g. f(x) = 0.7 means a 70% chance y=1; f(x)=0.3 means 30% chance y=1 (70% chance y=0).

2. Turning Probability into a 0/1 Prediction threshold = 0.5

g(z) ≥ 0.5 exactly when z ≥ 0
ConditionDecision
f(x) ≥ 0.5 → g(z) ≥ 0.5 → z ≥ 0 → w·x + b ≥ 0ŷ = 1
f(x) < 0.5 → g(z) < 0.5 → z < 0 → w·x + b < 0ŷ = 0
Chain of logic: f(x)≥0.5 ⟺ g(z)≥0.5 ⟺ z≥0 ⟺ w·x+b≥0. This is why the sign of w·x+b alone decides the class.

3. Linear Decision Boundary 2 features example

With two features x₁, x₂: z = w₁x₁ + w₂x₂ + b. Example parameters: w₁=1, w₂=1, b=−3

Decision boundary: z = 0 → x₁ + x₂ − 3 = 0 → x₁ + x₂ = 3
Right/above the purple line → predict 1. Left/below → predict 0.

General rule: with only linear terms (x₁, x₂, x₃, …, no powers/products), the decision boundary is always a straight line (or hyperplane).

4. Non-linear Boundaries via Polynomial Features circle example

Add squared terms: z = w₁x₁² + w₂x₂² + b, with w₁=1, w₂=1, b=−1

Boundary: x₁² + x₂² − 1 = 0 → x₁² + x₂² = 1 (a unit circle)
RegionConditionPrediction
Outside circlex₁² + x₂² ≥ 1ŷ = 1
Inside circlex₁² + x₂² < 1ŷ = 0

5. Even More Complex Boundaries higher-order polynomials

z = w₁x₁ + w₂x₂ + w₃x₁² + w₄x₁x₂ + w₅x₂² + w₆x₁³ + ⋯ + b
  • With quadratic cross-terms → boundary can become an ellipse.
  • With cubic/higher terms → boundary can become an arbitrary wiggly closed shape (as shown in lecture with the kidney-bean-like curve).
  • The model always predicts 1 inside the shape and 0 outside (or vice versa, depending on sign conventions).
Real-life analogy: Think of classifying "is this tumor malignant?" from two measurements (size, texture). A straight-line boundary can only separate simple cases. If malignant tumors form a cluster surrounded by benign ones on a scatter plot, only a curved (polynomial) boundary — like the circle/ellipse above — can correctly wrap around that cluster.
Key takeaway: logistic regression itself is linear in z, but by feeding it engineered polynomial features (x², x₁x₂, x³, …) it can represent highly non-linear boundaries — the same trick used in polynomial linear regression.

Dataset (6 examples, 2 features)

X = np.array([[0.5, 1.5], [1,1], [1.5, 0.5], [3, 0.5], [2, 2], [1, 2.5]]) y = np.array([0, 0, 0, 1, 1, 1]).reshape(-1,1)

Plotted with red ✕ for y=1, blue ○ for y=0 (using helper plot_data).

Trained model

f(x) = g(x₀ + x₁ − 3), with b=−3, w₀=1, w₁=1

Step 1 — Confirm sigmoid threshold at z=0

z = np.arange(-10,11) fig,ax = plt.subplots(1,1,figsize=(5,3)) ax.plot(z, sigmoid(z), c="b") ax.set_title("Sigmoid function") ax.set_ylabel('sigmoid(z)') ax.set_xlabel('z') draw_vthresh(ax,0) # marks g(z)=0.5 at z=0

Step 2 — Plot the decision boundary line

x0 = np.arange(0,6) x1 = 3 - x0 # from x0 + x1 - 3 = 0 fig,ax = plt.subplots(1,1,figsize=(5,4)) ax.plot(x0, x1, c="b") # the boundary line ax.axis([0, 4, 0, 3.5]) ax.fill_between(x0, x1, alpha=0.2) # shade region where prediction = 0 plot_data(X, y, ax) # overlay the training points ax.set_ylabel(r'$x_1$') ax.set_xlabel(r'$x_0$') plt.show()
Reading the plot: the blue line x₀+x₁=3 crosses the x₁-axis at 3 and the x₀-axis at 3. The shaded region below/left of the line is where −3+x₀+x₁ < 0 → model predicts y=0. Everything on or above the line (unshaded) has −3+x₀+x₁ ≥ 0 → model predicts y=1. All 6 training points fall on the correct side, confirming the fitted line separates the classes.
Notebook also notes: using higher-order polynomial terms, e.g. f(x) = g(x₀² + x₁ − 1), lets logistic regression produce non-linear boundaries — same idea as sections 4–5 above.
