📈 Logistic Regression & the Sigmoid Function

Week 3 · Lecture + Optional Lab (C1_W3_Lab02_Sigmoid_function)

1. Why We Need a New Function

Linear regression outputs any real number and produced an unstable decision boundary (see previous summary). Logistic regression fixes this by squashing the linear output through a curve that's always between 0 and 1.

The "S-shaped" sigmoid curve — the heart of logistic regression

2. The Sigmoid Function Formula

g(z) = 1 / (1 + e−z)

Also called the logistic function. It maps any real number z (positive or negative, huge or tiny) into a value strictly between 0 and 1.

z = -100 (very negative)
e-z = huge number
g(z) ≈ 1/(huge) ≈ 0
z = 0
e0 = 1
g(z) = 1/(1+1) = 0.5
z = +100 (very positive)
e-z ≈ tiny number
g(z) ≈ 1/(1+tiny) ≈ 1
💡 This is exactly why the curve is pinned at 0.5 when z=0, approaches 0 on the far left, and approaches 1 on the far right — but never quite reaches 0 or 1.

This combined formula is called logistic regression.

4. Interpreting the Output — It's a Probability!

fw,b(x) = P(y = 1 | x; w, b)

Read as: "the probability that y=1, given input x, with parameters w and b."

InputModel Output f(x)Interpretation
Tumor size x0.770% chance tumor is malignant (y=1)
—1 − 0.7 = 0.330% chance it's benign (y=0)
Since y can only be 0 or 1: P(y=0) + P(y=1) = 1 — always. Knowing one tells you the other.
Real-world scenarioA radiologist enters a tumor's size into the model and gets f(x) = 0.85. Rather than a hard "yes/it's cancer," this tells the doctor "85% likelihood of malignancy" — useful for triage: high-probability cases get prioritized for biopsy, while borderline (~50%) cases might warrant more tests before deciding.

Notation note: f(x) = P(y=1|x;w,b) — the semicolon just separates "given inputs" from "given parameters." Not required to memorize this notation for the course.

5. Threshold & Decision Boundary Preview

From the annotated slide: with threshold = 0.5 (or any chosen cutoff, e.g. 0.7 shown in the notes), you convert probability → hard classification:

if f(x) ≥ threshold → ŷ = 1 (malignant)
if f(x) <  threshold → ŷ = 0 (not malignant)
✅ Unlike linear regression, adding new data points far to the right does not distort logistic regression's S-curve or shift the decision boundary unpredictably — the sigmoid naturally saturates near 0 and 1 instead of tilting a straight line.

np.exp() works on both arrays and single numbers — needed since sigmoid must handle one training example (scalar z) or many (vector z).

Implementing sigmoid

def sigmoid(z):
    """
    Compute the sigmoid of z
    Args:
        z (ndarray): A scalar, numpy array of any size.
    Returns:
        g (ndarray): sigmoid(z), with the same shape as z
    """
    g = 1/(1+np.exp(-z))
    return g

Verifying the range

z_tmp = np.arange(-10,11)
y = sigmoid(z_tmp)
# z=-10 → 4.54e-05   (≈0)
# z=  0 → 0.5
# z= 10 → 1.000      (≈1)

Confirms: input ranges over all real numbers (-10 to 10 here), output is squashed into (0, 1).
