Logistic Regression — Simplified Loss & Cost Function

Collapsing the piecewise loss into one line, why this cost function was chosen, and the coding lab

1. Simplifying the Loss Function one equation instead of two

Previous (piecewise) form:

L(fw,b(x⁽ⁱ⁾), y⁽ⁱ⁾) =
  −log(fw,b(x⁽ⁱ⁾))    if y⁽ⁱ⁾ = 1
  −log(1 − fw,b(x⁽ⁱ⁾))  if y⁽ⁱ⁾ = 0

Because y is binary (only 0 or 1), both cases collapse into a single formula:

L(fw,b(x⁽ⁱ⁾), y⁽ⁱ⁾) = −y⁽ⁱ⁾·log(fw,b(x⁽ⁱ⁾)) − (1 − y⁽ⁱ⁾)·log(1 − fw,b(x⁽ⁱ⁾))

This single-line form is algebraically identical to the piecewise version — just easier to implement in code (no if/else needed).

2. Why the Collapse Works plug in y=1 and y=0

CaseSubstitutionResult
y = 1 −(1)·log(f) − (1−1)·log(1−f) = −log(f) − 0·(…) −log(fw,b(x⁽ⁱ⁾)) ✓ matches top case
y = 0 −(0)·log(f) − (1−0)·log(1−f) = 0·(…) − log(1−f) −log(1 − fw,b(x⁽ⁱ⁾)) ✓ matches bottom case
Trick: y and (1−y) act as on/off switches — whichever term doesn't apply gets multiplied by 0 and disappears, leaving exactly the piecewise formula from before.

3. Simplified Cost Function average loss over all m examples

cost: J(w,b) = (1/m) Σᵢ₌₁ᵐ [ L(fw,b(x⁽ⁱ⁾), y⁽ⁱ⁾) ]

Substituting the simplified loss and pulling the negative signs out front:

J(w,b) = −(1/m) Σᵢ₌₁ᵐ [ y⁽ⁱ⁾·log(fw,b(x⁽ⁱ⁾)) + (1 − y⁽ⁱ⁾)·log(1 − fw,b(x⁽ⁱ⁾)) ]

This is the cost function almost everyone uses to train logistic regression.

4. Why This Particular Cost Function? maximum likelihood estimation

  • It isn't arbitrary — it's derived from a statistical principle called Maximum Likelihood Estimation (MLE), a standard method for efficiently finding parameters of a model.
  • Deep MLE details are beyond the scope of this course, but the key payoff is: this cost function is convex.
  • Convexity ⇒ gradient descent is guaranteed to converge to the global minimum (no local-minima traps, unlike squared error with a sigmoid).
Takeaway: Many cost functions could technically be invented, but this log-loss form is the one with solid statistical justification (MLE) AND the convenient convex shape needed for gradient descent to work reliably.

Plotted with red ✕ = y=1, blue ○ = y=0 via plot_data.

Cost function formula being implemented

J(w,b) = (1/m) Σᵢ loss(fw,b(x⁽ⁱ⁾), y⁽ⁱ⁾),   where fw,b(x⁽ⁱ⁾)=g(z⁽ⁱ⁾), z⁽ⁱ⁾=w·x⁽ⁱ⁾+b, g(z)=1/(1+e⁻ᶻ)

Code: compute_cost_logistic

def compute_cost_logistic(X, y, w, b): """ Computes cost Args: X (ndarray (m,n)): Data, m examples with n features y (ndarray (m,)) : target values w (ndarray (n,)) : model parameters b (scalar) : model parameter Returns: cost (scalar): cost """ m = X.shape[0] cost = 0.0 for i in range(m): z_i = np.dot(X[i], w) + b f_wb_i = sigmoid(z_i) cost += -y[i]*np.log(f_wb_i) - (1-y[i])*np.log(1-f_wb_i) cost = cost / m return cost

Loops over all m examples, accumulates each example's loss (single-line formula from Section 1), then divides by m to average.
