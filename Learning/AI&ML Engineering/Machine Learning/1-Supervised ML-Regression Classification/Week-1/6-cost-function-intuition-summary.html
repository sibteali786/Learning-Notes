Cost Function Intuition: Finding the Best w DeepLearning.AI notes

Goal of this video: Build intuition for what J(w) is actually computing, by walking through one worked example — and show that minimizing J(w) is exactly how linear regression picks the best-fitting line.

1. Simplified Model (b = 0)

To make the plots easy to visualize, drop the intercept term:

fw(x) = w·x   (instead of fw,b(x) = wx + b)
J(w) = (1 / 2m) · Σi=1m ( fw(x(i)) − y(i) )²
Now f is a function of x (for a fixed w), but J is a function of w (with x, y fixed as the training data). Two different plots: f(x) vs. x on the left, J(w) vs. w on the right.

m = 3 examples. Since y = x exactly, the perfect fit is the line f(x) = x, i.e. w = 1.

3. Trying Different Values of w

w = 1 → f(x) = x. Every prediction matches exactly: (1,1), (2,2), (3,3) all have error 0.
J(1) = (1/6)·(0² + 0² + 0²) = 0
w = 0.5 → f(x) = 0.5x. Predictions: f(1)=0.5, f(2)=1, f(3)=1.5. Errors vs. actual y=1,2,3:
J(0.5) = (1/6)·[(0.5−1)² + (1−2)² + (1.5−3)²] = (1/6)·3.5 ≈ 0.58
w = 0 → f(x) = 0 (flat line on the x-axis). Errors = full distance to each point (1, 2, 3):
J(0) = (1/6)·(1² + 2² + 3²) = (1/6)·14 ≈ 2.33
w = −0.5 → downward-sloping line, errors get even bigger:
J(−0.5) ≈ 5.25

4. Tracing Out J(w)

Plotting these (w, J(w)) points traces out a bowl-shaped curve. Each point on the right corresponds to one entire line f(x)=wx on the left.

5. The Key Insight

Minimizing J(w) = finding the best-fitting line. The value of w that makes J(w) smallest (here, w=1, J=0) is exactly the line that fits the training data best. This is the core mechanism of linear regression:
minimizew,b   J(w, b)

Real-World Framing

Example: Think of w as a dial you can turn — each position gives a different line (different price predictions per sq ft). J(w) is like a "wrongness meter" that tells you how bad that dial setting is. Linear regression's job is to find the dial position where the wrongness meter reads the lowest.
