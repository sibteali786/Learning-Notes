Supervised Learning

Classification

Predicting categories instead of numbers

🩺 Problem Statement

You're building a diagnostic tool: given a tumor's features (size, age, thickness, cell uniformity...), predict whether it's benign (0) or malignant (1).

Unlike regression (predict house price — infinite possible numbers), classification predicts one of a small, finite set of categories.

📊 How It Works — 1 Input (Tumor Size)

🟢 Circles = benign (0)    ❌ Crosses = malignant (1). The model must decide which side the new point falls on.

📈 How It Works — 2 Inputs (Age + Tumor Size)

The algorithm learns a boundary separating classes. More real inputs (clump thickness, cell shape uniformity, etc.) are used in practice.

⚖️ Key Distinction: Classification vs Regression

RegressionClassification
Output typeNumber (infinite possibilities)Category (small, finite set)
Example output$452,300benign / malignant
Values in between?Yes — 0.5, 1.7, etc. validNo — only discrete classes (0, 1, 2...)
Use casePredicting house pricesDetecting cancer type, spam vs not-spam

💡 Key Takeaways

Categories ≠ numeric order. "0/1/2" are labels, not measurable quantities like regression outputs.
"Class" and "category" are used interchangeably for outputs.
More inputs (features) → algorithm draws boundaries in higher-dimensional space, not just a line.

🎯 Quick Recap

Supervised learning = learn X → Y from labeled "right answers."

Regression → predict a number (infinite outputs). Classification → predict a category (finite outputs).
