2. Example: A Bad Fit

w = 0.06, b = 50 → f(x) = 0.06x + 50. On the housing price training set, this line consistently underestimates prices — a poor fit, so J(w,b) will be large at this point.

3. The 3D Surface Plot

Axes: horizontal plane = w and b, vertical axis = J(w,b).
Any point (w, b) → height of the surface above it = J(w, b)
The surface is bowl-shaped (like a soup bowl, a curved dinner plate, or a hammock) — the exact same idea as the 2D U-curve from before, just extended into 3D because there are now two parameters instead of one.
Example: at w = −10, b = −15, the height of the surface at that point is J(−10, −15) — likely a large value, since that's a poor line.

4. The Contour Plot (2D Alternative)

A contour plot is the same J(w,b) function, sliced horizontally — like a topographic map of a mountain (e.g. Mount Fuji), where each line traces points of equal elevation.
  • Axes: w (horizontal), b (vertical)
  • Each oval/ellipse = the set of (w, b) points that share the same J value (same "height" on the 3D bowl)
  • Think of it as looking straight down at the 3D bowl from above
  • The center of the smallest, innermost oval = the minimum of J(w,b) — the best-fitting (w, b)

5. Key Insight: Same Cost, Different Lines

Three different points sitting on the same contour ellipse all have the same J value — even though each corresponds to a different (w, b), and therefore a different straight line f(x). In this video's example, all three of these lines were poor fits to the housing data (same "badness," different specific line).

Comparison Summary

3D Surface Plot
Shows J(w,b) as literal height above the (w,b) plane. Intuitive but harder to read exact minimum from a static image.
Contour Plot
Same function, viewed top-down as elevation rings. Easier to pinpoint the minimum: it's the center of the innermost ellipse.

Real-World Framing

Example: Think of J(w,b) like a hilly landscape where elevation = prediction error. A contour map (like ones used for hiking trails) lets you spot the lowest valley at a glance — that valley floor is the (w, b) pair giving the best-fitting line for house prices.
