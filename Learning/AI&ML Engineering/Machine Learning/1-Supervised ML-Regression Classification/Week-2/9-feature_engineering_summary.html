🏠 Feature Engineering

Using intuition to design new features by transforming or combining the original ones.

1 Starting model — raw features

Predicting house price from two raw features: frontage (x₁) — the width of the lot, and depth (x₂) — how far back the lot goes.

fw,b(x) = w₁x₁ + w₂x₂ + b
x₁ = frontage
🏡
x₂ = depth

This works okay, but treats width and depth as independent — it doesn't capture the idea of total land area.

2 The insight — area matters more

Intuition: area (a combination of frontage and depth) may be more predictive of price than the two dimensions taken separately.

area = frontage × depth

3 Engineered model — richer features

Add the new feature x₃ into the model. The learning algorithm now decides — via the parameters — whether frontage, depth, or area matters most.

fw,b(x) = w₁x₁ + w₂x₂ + w₃x₃ + b

💡 Definition

Feature engineering: using domain knowledge or intuition about a problem to design new features — usually by transforming or combining original features — so the learning algorithm can make more accurate predictions.

Real-life analogy: Imagine estimating a pizza's price from just "diameter" alone feels off — a wide-but-thin pizza isn't the same value as a wide-but-thick one. If you also had "thickness," you might engineer a new feature volume = π·r²·thickness, which could be a much better price predictor than either raw measurement alone.

➡️ What's next

This same idea — creating new features like x₃ = x₁x₂ — is also the trick that lets linear regression fit curves, not just straight lines, by engineering polynomial features (e.g. x², x³) from a single input.
