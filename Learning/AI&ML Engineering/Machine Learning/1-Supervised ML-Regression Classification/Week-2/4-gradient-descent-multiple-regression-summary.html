🎯 Gradient Descent for Multiple Linear Regression

Combining multiple linear regression + vector notation + vectorization to implement gradient descent when you have n ≥ 2 features.

1️⃣ Notation: Scalars → Vectors

Previous notation

Parameters: w₁, ..., wₙ (separate numbers), and b

fw,b(x) = w₁x₁ + ... + wₙxₙ + b
J(w₁, ..., wₙ, b)
Vector notation

w⃗ = [w₁ ... wₙ] — a vector of length n. b stays a single number.

fw⃗,b(x⃗) = w⃗ · x⃗ + b
J(w⃗, b)
🔹 J now takes a vector w⃗ and a number b as input, and returns a number — same idea, more compact notation.

2️⃣ Gradient Descent: One Feature vs. n Features

One feature (univariate) 
repeat {
  w = w - α (1/m) Σᵢ (f(x⁽ⁱ⁾) - y⁽ⁱ⁾) x⁽ⁱ⁾
  b = b - α (1/m) Σᵢ (f(x⁽ⁱ⁾) - y⁽ⁱ⁾)
}  // simultaneously update w, b
n features (n ≥ 2) 
repeat {
  w1 = w1 - α (1/m) Σᵢ (f(x⃗⁽ⁱ⁾) - y⁽ⁱ⁾) x1⁽ⁱ⁾
  ...
  wn = wn - α (1/m) Σᵢ (f(x⃗⁽ⁱ⁾) - y⁽ⁱ⁾) xn⁽ⁱ⁾
  b  = b  - α (1/m) Σᵢ (f(x⃗⁽ⁱ⁾) - y⁽ⁱ⁾)
}  // simultaneously update w1..wn and b

Key difference: the derivative term for wⱼ is nearly identical to the single-feature case — the error term (f(x⃗) − y) is unchanged, but it's now multiplied by xⱼ⁽ⁱ⁾ (the j-th feature of example i) instead of just x⁽ⁱ⁾. This repeats for every j = 1...n.

3️⃣ Alternative to Gradient Descent: The Normal Equation

Normal EquationDetails
What it doesSolves for w, b directly in one shot (no iterations) using linear algebra
Only works forLinear regression — nothing else in this course

Disadvantages

  • Doesn't generalize to other algorithms (logistic regression, neural networks, etc.)
  • Slow when number of features is large (> 10,000)
🔹 What to know: Some mature ML libraries may use the normal equation behind the scenes for plain linear regression. You likely won't implement it yourself — but the term might come up in an interview.
🔹 Recommendation: For most learning algorithms, including linear regression you implement yourself, gradient descent is the better approach.
