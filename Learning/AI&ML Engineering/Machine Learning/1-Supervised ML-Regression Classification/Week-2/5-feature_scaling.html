🎯 Feature Scaling for Gradient Descent

Lecture summary — why mismatched feature ranges slow down gradient descent, and how scaling fixes it

Core Idea

When features span very different ranges of values (e.g. house size 300–2,000 sq ft vs. bedrooms 0–5), a good model tends to pair a large-range feature with a small weight, and a small-range feature with a large weight. This imbalance stretches the cost function's contour plot into tall, skinny ellipses, and gradient descent ends up zig-zagging back and forth before reaching the minimum. Rescaling every feature to a comparable range (e.g. 0–1) makes the contours more circular, so gradient descent can take a direct path to the minimum instead.

📊 Feature Size and Gradient Descent

Features — Scatterplot
x₁ (size) spans a huge range; x₂ (bedrooms) barely moves — dots form a flat, narrow band.
Features — Rescaled (0–1)
Both x₁ and x₂ now range 0–1 — dots spread evenly, comparable scales.
Parameters — Contour Plot J(w,b)

🏠 Worked Example: House Price Prediction

price = w₁·x₁ + w₂·x₂ + b, where x₁ = size in feet² (range 300–2,000, large), x₂ = # bedrooms (range 0–5, small).
Training example: x₁ = 2000, x₂ = 5, true price = $500k.

w₁ = 50 (large), w₂ = 0.1 (small), b = 50
price = 50×2000 + 0.1×5 + 50
= 100,000K + 0.5K + 50K
= $100,050,500 ✗ way off
w₁ = 0.1 (small), w₂ = 50 (large), b = 50
price = 0.1×2000 + 50×5 + 50
= 200K + 250K + 50K
= $500,000 ✓ matches true price

Takeaway: a feature with a large range (size) naturally pairs with a small weight; a feature with a small range (bedrooms) naturally pairs with a large weight. This is exactly why their contour plot becomes stretched along one axis.

📝 Recap Steps

  1. Identify features with very different ranges of values (e.g. size in the hundreds/thousands vs. bedroom count 0–5).
  2. Transform the training data so every feature falls in a comparable range (e.g. 0 to 1).
  3. Run gradient descent on the rescaled data — the contour plot becomes more circular instead of tall and skinny.
  4. Gradient descent converges faster and takes a more direct path to the global minimum.
