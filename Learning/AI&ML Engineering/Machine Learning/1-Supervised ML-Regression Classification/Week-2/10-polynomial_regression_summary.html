📈 Polynomial Regression

Combining multiple linear regression + feature engineering to fit curves instead of straight lines.

1 The problem: a line doesn't fit

Housing data with feature x = size (sq ft) curves upward and levels off — a straight line underfits it.

2 Attempt 1 — Quadratic

fw,b(x) = w₁x + w₂x² + b

Fits the curve better — but a parabola eventually bends back down. That's unrealistic: bigger houses shouldn't get cheaper.

3 Attempt 2 — Cubic

fw,b(x) = w₁x + w₂x² + w₃x³ + b

Adding x³ lets the curve rise again for large x — more realistic for house prices. Features here: size, size², size³.

4 Attempt 3 — Square root

fw,b(x) = w₁x + w₂√x + b

√x rises more slowly as x grows, but never flattens out completely and never comes back down — another valid, well-behaved option.

⚠️ Why feature scaling matters here

Powers of x explode in range compared to x itself — gradient descent needs comparable ranges to converge well.

size (x)
1 – 1,000
size² (x²)
1 – 1,000,000
size³ (x³)
1 – 1,000,000,000
🔑 Rule of thumb: whenever you engineer polynomial features, apply feature scaling — otherwise gradient descent struggles because the features live on wildly different scales.

💡 Real-life analogy

Think of a car's stopping distance vs. speed. It's not linear — it grows roughly with speed². A model using just "speed" underfits; adding "speed²" as an engineered feature captures the real physics much better. Same logic as size → size² → size³ for house prices.
