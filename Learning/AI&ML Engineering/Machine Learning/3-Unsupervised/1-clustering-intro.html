🔍 What Is Clustering?

Unsupervised Learning · Intro to Clustering

Supervised vs. Unsupervised — Same Data, No Labels

With supervised learning, the training set has both inputs x and target labels y, so a model (logistic regression, a neural net) can learn a decision boundary separating classes.

Supervised: {(x⁽¹⁾,y⁽¹⁾),...,(x⁽ᵐ⁾,y⁽ᵐ⁾)}
Unsupervised: {x⁽¹⁾,...,x⁽ᵐ⁾} — no y, just dots
No labels means the algorithm can't be told the "right answer." Instead, it's asked to find interesting structure on its own.

What Is Clustering?

A clustering algorithm looks at unlabeled data points and automatically finds points that are related or similar to each other — grouping them into clusters.

Here the algorithm finds this dataset comprises two clusters — without ever being told what a cluster should look like.
