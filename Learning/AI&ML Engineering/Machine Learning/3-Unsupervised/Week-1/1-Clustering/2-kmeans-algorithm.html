🎯 The K-Means Algorithm

Unsupervised Learning · How K-means Clusters Data

Setup — 30 Unlabeled Points, K = 2

Given a training set {x⁽¹⁾, x⁽²⁾, ..., x⁽³⁰⁾} with no labels, K-means is asked to find 2 clusters. It starts by randomly guessing the location of 2 cluster centroids — shown as a red ✕ and a blue ✕. These first guesses are usually not good, but they're a starting point.

Random initial cluster centroids — not yet good guesses

The Two Repeating Steps

K-means repeatedly does two things until nothing changes:

Step 1
Assign each point to its closest centroid
⇄
Step 2
Move each centroid to the mean of its assigned points
1Assign points to centroids

For every example x⁽¹⁾...x⁽³⁰⁾, check: is it closer to the red centroid or the blue centroid? Color/label it accordingly.

2Recompute centroids

Take all points now colored red → average their location → move the red ✕ there. Do the same for blue.

Repeat step 1 → step 2 → step 1 → step 2 ... As centroids move, some points switch color because they're now closer to the other centroid.

Convergence

Each pass through the loop refines the centroid positions. Eventually, running the two steps again produces no further changes — no point switches color, and no centroid moves. At this point, K-means has converged.

Final state — stable assignment, stable centroids

💡 Key Takeaway

Init: random centroids Loop: assign → recompute mean Stop: no more changes = converged
