🔔 Gaussian (Normal) Distribution

Anomaly Detection · The building block for modeling p(x) · Single-feature case

Why We Need It

To apply anomaly detection we need a way to model p(x). The tool is the Gaussian distribution.

GaussianNormal distributionBell-shaped curve
All three names mean exactly the same thing. The "bell" name comes from the shape of classic bells (e.g. the Liberty Bell), wide at the bottom and rounded on top.

Definition

Say x is a number (a random variable, taking random values). If p(x) follows a Gaussian with mean μ and variance σ², the curve looks like a bell:

μ (mean)

  • Center / middle of the curve
  • Where the peak sits

σ (standard deviation)

  • Width of the curve
  • σ² = the variance
p(x) = 1 / (√(2π) · σ) · e −(x − μ)² / (2σ²) 
import numpy as np

def gaussian_pdf(x, mu, sigma):
    return (1 / (np.sqrt(2*np.pi) * sigma)) * np.exp(-(x - mu)**2 / (2 * sigma**2))
π ≈ 3.14159 (the ratio of a circle's circumference to its diameter). For any μ and σ, plotting this against x gives the bell centered at μ with width set by σ.

What Does p(x) Actually Mean?

Draw numbers from the distribution and plot a histogram:

100 samples

  • Roughly bell-shaped, but jagged

1,000 / a million…

  • Smoother and closer to the curve

≈ infinite samples, very fine bins

  • You get the smooth curve p(x)
The curve doesn't describe 100 or 1,000 examples. It describes what the histogram converges to with a practically infinite number of samples.

μ moves the curve left/right.
σ changes the width (and so the height).
Why skinnier means taller: probabilities must sum to 1, so the area under the curve is always 1. Squeeze the width and the height has to grow; widen it and the height drops.

Parameter Estimation: Fitting μ and σ² from Data

Given a dataset {x⁽¹⁾, …, x⁽ᵐ⁾} (here x is a single number, e.g. 11 training examples), pick the μ and σ² for which these points look like they came from the Gaussian.

MEAN
μ = (1/m) · Σi=1..m x⁽ⁱ⁾
= average of the training examples
VARIANCE
σ² = (1/m) · Σi=1..m (x⁽ⁱ⁾ − μ)²
= average squared difference from μ
def estimate_gaussian_1d(x):
    m = len(x)
    mu = np.sum(x) / m                      # same as x.mean()
    var = np.sum((x - mu)**2) / m           # same as x.var() (ddof=0)
    return mu, var

x = np.array([...])                          # your m training values
mu, var = estimate_gaussian_1d(x)

Maximum likelihood

  • These formulas are technically the maximum likelihood estimates of μ and σ²
  • Don't worry if you haven't taken advanced stats

1/m vs 1/(m−1)

  • Some stats classes use 1/(m−1)
  • In practice it makes very little difference
  • Andrew always uses 1/m
  • In NumPy: np.var(x) = 1/m, np.var(x, ddof=1) = 1/(m−1)
