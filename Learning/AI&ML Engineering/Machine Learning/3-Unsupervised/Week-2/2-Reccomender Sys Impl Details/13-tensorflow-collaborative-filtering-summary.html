Big Idea: TensorFlow Isn't Only for Neural Networks

It's a great tool for neural networks, but it can also implement other learning algorithms, like collaborative filtering. The key feature: automatic differentiation.

Without autodiff

  • Derive ∂J/∂w, ∂J/∂b, ∂J/∂x by hand
  • Needs calculus, easy to get wrong

With autodiff

  • Implement only the cost function J
  • TensorFlow computes the derivatives, with a few lines of code

Recap: Gradient Descent (Course 1)

w = w − α · ∂J(w,b)/∂w     b = b − α · ∂J(w,b)/∂b
  • α = learning rate; ∂J/∂w = the derivative (slope of J(w)).
  • In the slide's example b = 0, so f(x) = w·x and you skip the b update.
  • Repeat until convergence. Computing the derivative is the part that can be hard, and TensorFlow can do it for you.

Toy Example: A Custom Training Loop

Simplest cost: J = (w·x − 1)², with f(x) = w·x, target y = 1, x = 1. The best w is 1.

import tensorflow as tf

w = tf.Variable(3.0)          # tf.Variable = a parameter we want to OPTIMIZE
x = 1.0
y = 1.0                         # target value
alpha = 0.01

iterations = 30
for iter in range(iterations):
    # GradientTape records the steps used to compute the cost J → enables auto differentiation
    with tf.GradientTape() as tape:
        fwb   = w * x                  # f(x)
        costJ = (fwb - y) ** 2

    # replay the tape to get ∂J/∂w (w is in the list because we declared it a Variable)
    [dJdw] = tape.gradient(costJ, [w])

    # one gradient descent step; tf.Variables need a special function to modify
    w.assign_add(-alpha * dJdw)

tf.Variable

  • Tells TF "this is a parameter to optimize"

tf.GradientTape()

  • Records the sequence of operations used to compute J

tape.gradient(J, [w])

  • Derivative of J w.r.t. each listed variable
Why assign_add? A tf.Variable needs a special function to modify, so instead of w = w − α·dJdw you write w.assign_add(−alpha * dJdw). (The lecture says not to worry about this; the practice lab gives you the syntax.)
What you do: tell TensorFlow how to compute the cost J. The rest of the syntax makes it figure out the derivative. This is Auto Diff.

What the Tape Does (Under the Hood)

Forward pass (recorded): w → fwb = w·x → costJ = (fwb − y)².
Backward pass (tape.gradient): chain rule: ∂J/∂w = 2(fwb − y) · x. At w = 3, x = 1, y = 1 → 2·2·1 = 4.
Chain-rule detail: the backward formulas are my illustration of what autodiff computes; the lecture only says TensorFlow records the operations and derives the gradient.
Terminology: Auto Diff is the technically correct term. Auto Grad is actually the name of one specific software package, but people use it for the same concept. PyTorch also supports autodiff.

Collaborative Filtering in TensorFlow

Same loop, now the variables are X (movie features), W and b (user parameters), and the optimizer is Adam:

optimizer = keras.optimizers.Adam(learning_rate=1e-1)

iterations = 200
for iter in range(iterations):
    with tf.GradientTape() as tape:
        # forward pass is included in the cost; Ynorm = mean-normalized ratings
        cost_value = cofiCostFuncV(X, W, b, Ynorm, R, num_users, num_movies, lambda_)

    # derivatives of the cost w.r.t. ALL three sets of parameters, automatically
    grads = tape.gradient(cost_value, [X, W, b])

    # one optimizer step on all variables
    optimizer.apply_gradients(zip(grads, [X, W, b]))

Plain gradient descent

  • w = w − α ∂J/∂w
  • b = b − α ∂J/∂b
  • x = x − α ∂J/∂x
  • (repeat until convergence)

With autodiff you can swap in Adam

  • Once derivatives are automatic you're not limited to gradient descent
  • Use a more powerful optimizer, e.g. Adam
Notes (my additions): (1) lambda is a reserved word in Python, so real code names it lambda_. (2) X, W, b must be tf.Variables for the tape to track them. (3) Exact API details can differ across TensorFlow/Keras versions, so use the syntax given in the practice lab.

A vectorized cost function you could pass in (sketch)

def cofi_cost_func_v(X, W, b, Ynorm, R, lambda_):
    # X: (n_m, n)  W: (n_u, n)  b: (1, n_u)  Ynorm, R: (n_m, n_u)
    err = (tf.linalg.matmul(X, tf.transpose(W)) + b - Ynorm) * R     # R masks unrated entries
    return 0.5 * tf.reduce_sum(err**2) + (lambda_/2) * (tf.reduce_sum(X**2) + tf.reduce_sum(W**2))

# the slide's version also takes num_users and num_movies; a vectorized version doesn't need them

Why Not Dense Layers + model.compile / model.fit?

Standard recipe (works when…)

  • Your model is a sequence of Dense (or other supported) layers
  • model.compile() → model.fit()

Collaborative filtering

  • Its cost function doesn't neatly fit Dense or other standard layer types
  • So: write the cost yourself, then use TensorFlow's Auto Diff and Adam to optimize it
Even when the standard recipe doesn't apply, these tools give you an effective way to implement other learning algorithms as well.

💡 Key Takeaways

tf.Variable = parameters to learn GradientTape records the cost computation tape.gradient → derivatives for free apply_gradients(zip(grads, vars)) Adam instead of plain GD
Pros/cons of the custom-loop approach (beyond the lecture): it's flexible, with no hand-derived gradients and any optimizer. But you write and debug the loop, shapes and masking yourself, and a hand-written loop is slower than model.fit unless you wrap the step in tf.function. Frameworks like PyTorch use the same idea with a different API.
