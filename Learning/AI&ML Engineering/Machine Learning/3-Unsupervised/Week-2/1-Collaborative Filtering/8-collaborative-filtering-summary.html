🤝 Collaborative Filtering — Learning the Features

What if we don't have x₁, x₂? · Learn the movie features from user ratings · The cost J(w, b, x) · Gradient descent on w, b and x

The Problem

Last video: with movie features x₁ (romance), x₂ (action) we could use linear regression to predict ratings. But what if we don't have those features? Replace the feature columns with ? and learn them from the data.

The ratings are the same 4 users × 5 movies as before. Only the feature columns are now unknown.

Step 1: If You Already Had the User Parameters…

Just for illustration, assume the user parameters were already learned (and all b = 0, so b is ignored in this example). The prediction is still w⁽ʲ⁾ · x⁽ⁱ⁾ + b⁽ʲ⁾.

Assumed parameters

  • w⁽¹⁾ = [5, 0] (Alice)
  • w⁽²⁾ = [5, 0] (Bob)
  • w⁽³⁾ = [0, 5] (Carol)
  • w⁽⁴⁾ = [0, 5] (Dave)
  • all b⁽ʲ⁾ = 0

What x⁽¹⁾ (Love at last) must be

  • Alice rated 5 → w⁽¹⁾·x⁽¹⁾ ≈ 5
  • Bob rated 5 → w⁽²⁾·x⁽¹⁾ ≈ 5
  • Carol rated 0 → w⁽³⁾·x⁽¹⁾ ≈ 0
  • Dave rated 0 → w⁽⁴⁾·x⁽¹⁾ ≈ 0
A reasonable guess: x⁽¹⁾ = [1, 0] → [5,0]·[1,0] = 5 ✓   [5,0]·[1,0] = 5 ✓   [0,5]·[1,0] = 0 ✓   [0,5]·[1,0] = 0 ✓
Same trick for x⁽²⁾, x⁽³⁾ … x⁽ⁿᵐ⁾: choose each movie's feature vector so the predictions match the ratings that exist. (The lab below does this by optimization.)
Why this only works with several users: a single user's ratings can't pin down the features (that's why in Course 1 linear regression you can't invent x₁, x₂ from scratch). In collaborative filtering several users rated the same movie, which is what makes it possible to guess the features.

Step 2: Cost Function for Learning the Features

Given w⁽¹⁾,b⁽¹⁾ … w⁽ⁿᵘ⁾,b⁽ⁿᵘ⁾, to learn the features of one movie i:

J(x⁽ⁱ⁾) = ½ Σj : r(i,j)=1 ( w⁽ʲ⁾·x⁽ⁱ⁾ + b⁽ʲ⁾ − y⁽ⁱ'ʲ⁾ )²  +  λ/2 · Σk=1..n (xk⁽ⁱ⁾)²
  • Sum over all users j who rated movie i (r(i,j) = 1).
  • Squared difference between what your x⁽ⁱ⁾ predicts and the actual rating.
  • λ term regularizes the feature values.

To learn all movies' features x⁽¹⁾ … x⁽ⁿᵐ⁾, sum over movies:

J(x⁽¹⁾…x⁽ⁿᵐ⁾) = ½ Σi=1..n_m Σj : r(i,j)=1 ( w⁽ʲ⁾·x⁽ⁱ⁾ + b⁽ʲ⁾ − y⁽ⁱ'ʲ⁾ )²  +  λ/2 · Σi=1..n_m Σk=1..n (xk⁽ⁱ⁾)²
Remarkable: in most ML applications the features must be given externally. Here you can learn the features of a movie by minimizing this cost with gradient descent (or another optimizer).

Step 3: Put Them Together → Collaborative Filtering

Last video

  • Features x known → learn w, b

This video

  • w, b known → learn x

Both squared-error terms are exactly the same sum: over all (user, movie) pairs that have a rating. Merge them and keep both regularization terms:

J(w, b, x) = ½ Σ(i,j) : r(i,j)=1 ( w⁽ʲ⁾·x⁽ⁱ⁾ + b⁽ʲ⁾ − y⁽ⁱ'ʲ⁾ )²  +  λ/2 Σj=1..n_u Σk=1..n (wk⁽ʲ⁾)²  +  λ/2 Σi=1..n_m Σk=1..n (xk⁽ⁱ⁾)²
Minimize over w, b and x together and the algorithm works.

Gradient Descent: x Is Also a Parameter

Linear regression (Course 1)

repeat {
  w = w − α ∂J(w,b)/∂w
  b = b − α ∂J(w,b)/∂b
}

Collaborative filtering

repeat {
  w⁽ʲ⁾ᵢ = w⁽ʲ⁾ᵢ − α ∂J(w,b,x)/∂w⁽ʲ⁾ᵢ
  b⁽ʲ⁾  = b⁽ʲ⁾  − α ∂J(w,b,x)/∂b⁽ʲ⁾
  x⁽ⁱ⁾ₖ = x⁽ⁱ⁾ₖ − α ∂J(w,b,x)/∂x⁽ⁱ⁾ₖ
}
Key takeaway: the model's parameters are w, b and also x, so the cost is minimized as a function of all three.
import numpy as np

# X: (n_m, n)  W: (n_u, n)  b: (1, n_u)  Y, R: (n_m, n_u)   (R = 1 where rated, Y can hold 0 for '?')
def step(X, W, b, Y, R, lam, alpha):
    err = (X @ W.T + b - Y) * R                 # errors only on rated entries
    dX  = err @ W   + lam * X                   # ∂J/∂x
    dW  = err.T @ X + lam * W                   # ∂J/∂w
    db  = err.sum(axis=0, keepdims=True)        # ∂J/∂b
    return X - alpha*dX, W - alpha*dW, b - alpha*db

Why "Collaborative" Filtering?

1

Several users rate the same movie
→
2

Together their ratings reveal what the movie is like → guess its features
→
3

Use features to predict ratings of users who haven't rated it yet
Gathering data from multiple users, i.e. collaboration between users, helps predict ratings for other users in the future.
Real-life scenario: three viewers who all rated a new film 5 stars while also loving the same two thrillers tell the system the film is "thriller-like" even though nobody tagged it. A fourth viewer who loves those thrillers then gets it recommended.
