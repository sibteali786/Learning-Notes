📈 Checking If Gradient Descent Is Converging

Two ways to tell whether gradient descent found parameters close to the global minimum

Core Idea

Plot the cost J(w,b) (computed on the training set) against the number of iterations of gradient descent — this is called a learning curve. Note the horizontal axis is iterations, not a parameter like w or b, which is different from the contour/surface plots seen earlier. If gradient descent is working correctly, J should decrease after every single iteration. Once the curve flattens out and stops decreasing, gradient descent has likely converged — meaning the parameters found are close to the global minimum.

📉 The Learning Curve

Cost drops fast early on, then levels off. By ~400 iterations the curve is flat — gradient descent has more or less converged.

✅ How to Read It

J decreases every iteration✓ working correctly
J increases at any point✗ α too large, or a code bug
Curve flattens / barely moves✓ likely converged
⚠️ If J ever goes up after an iteration, that's a red flag — check your learning rate α first (usually too large), then check your code for bugs.

🎯 Automatic Convergence Test

Let ε ("epsilon") be a small number, e.g. 10⁻³ = 0.001.

Rule: If J(w,b) decreases by ≤ ε in one iteration → declare convergence (you've found parameters w, b close to the global minimum).

💡 Choosing the right ε threshold is often tricky in practice — most practitioners (including the instructor) prefer visually inspecting the learning curve plot over relying solely on this automatic test, since the plot can also warn you early if something's going wrong.

⏱️ Iterations Needed Varies Wildly

There's no way to know in advance how many iterations gradient descent needs to converge — it depends entirely on the application:

30 iterations1,000 iterations100,000 iterations

This unpredictability is exactly why plotting the learning curve is useful — it lets you empirically discover when to stop training rather than guessing.

📝 Recap Steps

  1. Plot J(w,b) vs. number of iterations after each parameter update — this is the learning curve.
  2. Confirm J decreases every iteration; if it increases, suspect α is too large or a bug exists.
  3. Watch for the curve to flatten out — that signals convergence near the global minimum.
  4. Optionally use an automatic test: if J drops by ≤ ε (e.g. 0.001) in one iteration, declare convergence — but visual inspection is usually more reliable.
  5. Next lecture: how to choose a good learning rate α.
