🎚️ Choosing a Good Learning Rate (α)

Diagnosing bad learning rates, spotting code bugs, and a systematic way to search for α

Core Idea

Learning rate α controls the size of each gradient descent step. Too small → converges correctly but painfully slowly. Too large → may overshoot the minimum and even fail to converge, with the cost bouncing up and down or increasing every iteration. Diagnosing this from the learning curve (J vs. iterations) tells you whether to shrink α or go hunting for a bug in your code.

🩺 Identifying the Problem

J bounces up & down each iteration → α too large (or a bug)
J consistently increases → α too large, OR a sign bug: check w = w − αd not w = w + αd
On a J(w₁) curve: big α → overshoots the minimum each step, zig-zagging away instead of converging

⚖️ Big α vs. Smaller α (parameter-space view)

SituationWhat happens
α too bigEach update overshoots the minimum, bouncing back and forth across the curve — may never converge
Smaller αSteps move steadily toward the minimum, decreasing J on every iteration — converges reliably
α too smallStill converges correctly, but takes a lot more iterations to get there — inefficient
✅ Debugging tip: with a small enough α, J should decrease on every single iteration. If you set α to a tiny value and J still increases sometimes, that's not a learning-rate problem — it's a bug in the code (e.g. a missing minus sign in the update rule).
⚠️ Common bug: w₁ = w₁ + α·d₁ (wrong — moves away from minimum) vs. the correct w₁ = w₁ − α·d₁ (uses a minus sign, moves toward the minimum).

≈3× increase between each value (0.001→0.003 is 3×, 0.003→0.01 is ≈3×, and so on).

Both decrease steadily — 0.01 decreases faster (still safe)
One α zig-zags (too big), one decreases fast and consistently (just right)

🎯 The Strategy

  1. Try a range of α values, each ~3× the last: 0.001, 0.003, 0.01, 0.03, 0.1, 0.3, 1…
  2. For each value, run gradient descent for just a few iterations and plot J vs. iterations.
  3. Find a value that's clearly too small (decreases very slowly) and one that's clearly too large (bounces/increases).
  4. Pick the largest α that still decreases J rapidly and consistently — often just slightly smaller than the largest reasonable value found.
