Linear Regression — Training Set & Notation

Fitting a straight line to predict house prices

🏠 Problem Statement

Predict a house's price from its size using a Portland, OR housing dataset. Client's house = 1,250 sq ft → model estimates ~$220,000.

Linear regression = fit a straight line through (size, price) data points, then read off the prediction for a new size.

📈 How It Works

✕ = actual sold houses (training data). Blue line = best fit. Green dashed = reading the prediction for the client's 1,250 sq ft house.

💡 Key Takeaways

"Training set" = data used to train the model (client's unsold house is not in it).
Linear regression is one type of regression model — the most widely used ML algorithm.
Same notation (x, y, m, training examples) applies across most models you'll see later in the specialization.

🎯 Quick Recap

Train on (x⁽ⁱ⁾, y⁽ⁱ⁾) pairs → fit a line → feed in new x → predict y.
