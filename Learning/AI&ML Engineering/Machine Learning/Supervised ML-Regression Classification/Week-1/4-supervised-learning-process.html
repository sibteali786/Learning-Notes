🔤 Key Terms

TermMeaning
fthe model / function (used to be called "hypothesis")
xinput feature (e.g. house size)
ŷ (y-hat)model's prediction / estimate of y
yactual true value from the training set (target)
🏠 Real example: true sale price y isn't known until the house sells. The model outputs ŷ — its estimate before that happens.

📐 The Linear Function

fw,b(x) = w·x + b   (often shortened to f(x) = wx + b)

w and b are numbers the algorithm chooses — they determine the line's slope and position, which determines the prediction ŷ.

📈 Why a Straight Line First?

Linear = simple, easy foundation. Nonlinear/curved models come later once the basics click.

🏷 Naming This Model

Linear Regressionfits a straight line to predict a number
Univariate Linear Regressionlinear regression with one input feature (uni = one, variate = variable)
Later: predicting price from size + bedrooms + other features → multiple features, not univariate.

💡 Key Takeaways

The model is just a function f that maps x → ŷ. Training = choosing good w and b.
ŷ ≠ y: prediction vs. actual truth — the whole point of the model is to make ŷ close to y.
Next: cost function — how to measure how good/bad a choice of w, b is (used across nearly all ML models, not just linear regression).
