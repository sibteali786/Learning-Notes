Unsupervised Learning

Clustering

Finding structure in data that has no labels

❓ Problem Statement

You have patient data — tumor size + age — but no label Y (no benign/malignant answer given). The algorithm isn't told what's "right." Instead: find structure on its own.

Supervised learning has answer keys (X → Y). Unsupervised learning gets only X, and must discover patterns itself.

🔎 How It Works

All points look the same (no O/✕ labels). The algorithm itself groups similar points into clusters — it isn't told what the groups mean.

⚖️ Key Distinction: Supervised vs Unsupervised

SupervisedUnsupervised
Labels (Y)?Yes — "right answers" givenNo labels at all

💡 Key Takeaways

"Unsupervised" = no one supervises the algorithm with correct answers; it discovers patterns on its own.
Clustering is one type of unsupervised learning — groups similar data points together automatically.
Scales where manual labeling is impossible (e.g., can't hand-tag every news article, every day).

🎯 Quick Recap

Unsupervised learning = data with no output labels Y → find structure/patterns automatically.

Clustering = group unlabeled data points into clusters based on similarity.
