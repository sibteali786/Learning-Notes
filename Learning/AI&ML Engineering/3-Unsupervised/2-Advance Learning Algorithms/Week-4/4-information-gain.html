📊 Information Gain — Choosing the Best Split

Advanced Learning Algorithms · Turning entropy into a decision rule

The Core Idea

Pick the feature that reduces entropy the most when you split on it. This reduction has a name: Information Gain.

Information Gain = Entropy(before split) − Weighted Entropy(after split)

Why Weight by Branch Size?

A branch with high entropy matters more if it holds many examples than if it holds just a few. So instead of comparing raw left/right entropy values directly, we take a weighted average, weighted by what fraction of examples went to each branch.

wleft = fraction of examples that went left  |  wright = fraction that went right

Comparing 3 Candidate Root Splits

Root node starts with 10 examples (5 cats / 5 dogs) → p₁ᵣₒₒₜ = 0.5 → H(0.5) = 1 (max impurity).

🟢 Ear shape

Leftp₁=4/5=0.8H=0.72
Rightp₁=1/5=0.2H=0.72
1 − (5/10·0.72 + 5/10·0.72)
= 0.28

Face shape

Leftp₁=4/7=0.57H=0.99
Rightp₁=1/3=0.33H=0.92
1 − (7/10·0.99 + 3/10·0.92)
= 0.03

Whiskers

Leftp₁=3/4=0.75H=0.81
Rightp₁=2/6=0.33H=0.92
1 − (4/10·0.81 + 6/10·0.92)
= 0.12
🏆 Ear shape wins with the highest information gain (0.28 > 0.12 > 0.03) → chosen as the root node split.

General Formula

Information Gain = H(p₁root) − ( wleft·H(p₁left) + wright·H(p₁right) )
SymbolMeaningEar-shape example
p₁rootFraction cats at current node (before split)5/10 = 0.5
p₁leftFraction cats in left branch (after split)4/5
p₁rightFraction cats in right branch (after split)1/5
wleftFraction of examples routed left5/10
wrightFraction of examples routed right5/10

Why Compute the Reduction (not just weighted entropy)?

Mathematically equivalent for ranking splits — but computing the reduction gives a directly useful number: it becomes one of the stopping criteria.

If information gain from the best available split is below a threshold, stop splitting — further splitting isn't buying meaningful purity and just risks overfitting.

Algorithm in One Line

At every node: compute information gain for every candidate feature → pick the feature with the highest information gain → split on it → repeat on each child node until a stopping criterion is hit.
