🔁 Building the Full Tree — Recursive Splitting

Advanced Learning Algorithms · Putting information gain to work across the whole tree

The Full Algorithm

1Start with all training examples at the root node.
2Compute information gain for every candidate feature → pick the one with the highest gain.
3Split the dataset on that feature → create left & right branches, route examples accordingly.
4Repeat steps 2–3 on each new branch — until a stopping criterion is met.
Stopping criteria (any one triggers a leaf node):
🟢 Node is 100% one class (entropy = 0)  |  📏 Splitting would exceed max depth  |  📉 Information gain below threshold  |  🔢 Too few examples in node

Worked Example — Full Tree on the Cat Dataset

Left branch (Pointy, 5 examples)
Splitting on ear shape again → IG = 0 (useless, already uniform). Face shape wins instead → both children turn out 100% pure → leaves created.
Right branch (Floppy, 5 examples)
Treated like training a brand-new tree on just these 5 examples. Whiskers gives the highest IG → both children 100% pure → leaves created.

💡 Key Insight — This Is Recursion

Building the left subtree = training a fresh decision tree on just those 5 examples. Same for the right subtree. A decision tree is built by building smaller decision trees inside it.

In CS terms: a recursive algorithm is one that calls itself on smaller sub-problems. You don't need to master this to use scikit-learn/XGBoost — but if you ever implement a tree from scratch, recursion is exactly how you'd structure the code.

Choosing Max Depth — Analogy to Familiar Concepts

📈 Larger max depth → bigger, more complex tree → similar to a higher-degree polynomial or a larger neural network → more expressive, but more prone to overfitting.
🎯 How to pick it → in theory, cross-validation (try several depths, pick the one that does best on the CV set). In practice, open-source libraries often ship good defaults.
Alternate stopping levers, with the same overfitting-control goal: minimum information-gain threshold, or minimum examples per node.

Using the Finished Tree

Once built, prediction is simple: take a new example, start at root, follow the feature-value branches down, and read off the leaf node's prediction — exactly the walkthrough from the very first video this week.
