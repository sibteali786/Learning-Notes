📈 Regression Trees — Predicting a Number

Advanced Learning Algorithms (Optional) · Generalizing decision trees beyond classification

What's Different Here

Classification tree
Target y = category (cat / not cat)
Regression tree
Target y = a number (animal's weight in lbs)

Same features as before (Ear shape, Face shape, Whiskers) — but now weight is the thing being predicted, not an input feature.

Making a Prediction: Average at the Leaf

📌 Prediction rule: follow branches down to a leaf, then predict the average of all training weights that landed in that leaf. Same tree structure logic as classification — just a different leaf output.

Splitting Criterion: Variance Instead of Entropy

Classification minimizes entropy (label impurity). Regression minimizes variance (how spread out the numeric values are).

Variance = how widely a set of numbers is spread out
Low variance = numbers clustered together = good, homogeneous split
