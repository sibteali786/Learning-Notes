Choosing Activation Functions (Output vs Hidden Layers)

1. Output Layer - Pick Based on What Y Is

-> a[1] ->
-> a[2] ->
a[3] = f(x) = a1[3] = g(z1[3])

Binary Classification

Y = 0 or 1

-> Sigmoid

Network learns P(Y=1) - a probability between 0 and 1, same as logistic regression.

Regression (+/-)

Y can be negative or positive - e.g. tomorrow's stock price change: -1.2, +1.5, -0.4

-> Linear

g(z) = z allows both positive and negative outputs.

Regression (non-negative)

Y ≥ 0 - e.g. house price: +150, +420, +230

-> ReLU

g(z) = max(0,z) - never gives negative predictions, matching a price that can't be negative.

2. Hidden Layers - Default to ReLU

Even though neural nets historically used sigmoid everywhere, modern practice almost always uses ReLU in hidden layers. Two reasons:

Reason 1 - Speed

ReLU is just max(0, z). Sigmoid needs an exponentiation + division - more expensive to compute.

Reason 2 - Flatness slows gradient descent

Sigmoid is flat on both sides (very negative and very positive z). ReLU is flat on only one side (z < 0).

Flat g(z) -> dJ(W,B)/dw is approx 0 -> gradient descent crawls

Since the cost function J(W,B) is built from these activations, more flat regions in g(z) means more flat regions in J - and gradient descent barely moves when the slope is near zero. ReLU's cost surface has fewer flat "dead zones," so training converges faster.

Note: still use sigmoid at the output layer for binary classification. ReLU is for hidden layers.

Real-World Analogy

Think of choosing the output layer activation like choosing the right measuring instrument for the job:

  • Sigmoid = a yes/no probability dial - perfect for "will this email be spam?"
  • Linear = an open-ended thermometer that reads above or below zero - perfect for "temperature change" or "stock move."
  • ReLU = a car odometer - can't go negative, only 0 or up - perfect for "distance traveled" or "house price."

For hidden layers, ReLU became the default the way a Phillips-head screwdriver became the default in most toolkits - not always technically the only option (tanh, leaky ReLU, swish exist for special cases), but reliable, fast, and good enough for the vast majority of jobs.

Other Activation Functions (Good to Know)

  • tanh - sigmoid-shaped but ranges (-1, 1) instead of (0, 1)
  • Leaky ReLU - like ReLU but with a small slope for z < 0 instead of a hard 0; Andrew mentions using it occasionally with small gains over ReLU
  • Swish - a smoother, more recent alternative researchers sometimes use
