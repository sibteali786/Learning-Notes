🏷️ Multi-label Classification

📌 What It Is

A multi-label problem: one input image gets several independent yes/no labels at once — e.g. for a self-driving car, given one photo: "Is there a car? Is there a bus? Is there a pedestrian?"

Image 1

Car? Yes  |  Bus? No  |  Pedestrian? Yes
y = [1, 0, 1]

Image 2

Car? No  |  Bus? No  |  Pedestrian? Yes
y = [0, 0, 1]

Image 3

Car? Yes  |  Bus? Yes  |  Pedestrian? No
y = [1, 1, 0]

📌 The target y is now a vector (multiple numbers), not a single number — that's the key structural difference from everything covered so far.

⚖️ Multi-class vs Multi-label — Don't Confuse Them!

Multi-class Classification

One label, many possible values.

Example: handwritten digit → y is a single number, but it can be 0, 1, 2, ..., or 9.

y = 7  (one value, from a set of 10)

Output layer: softmax — probabilities across classes sum to 1 (mutually exclusive; it's exactly one class).

Multi-label Classification

Many labels, each independently yes/no.

Example: driving scene → y is a vector of independent binary answers (car? bus? pedestrian?).

y = [1, 0, 1]  (multiple values, each 0 or 1)

Output layer: sigmoid per unit — each output is its own independent probability, they don't need to sum to 1 (car and bus can both be present).

🌍 Real-World Analogy

Think of multi-class like a single-choice exam question — "Which one of these is the capital of France?" Only one answer can be correct.

Think of multi-label like a checklist survey — "Check all that apply: Do you own a car? A bike? A bus pass?" You can check none, one, or all of them — they're independent yes/no questions, not competing options.
