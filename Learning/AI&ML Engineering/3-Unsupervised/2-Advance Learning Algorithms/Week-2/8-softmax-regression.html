🎲 Softmax Regression — Generalizing Logistic Regression

🔁 Reframing Logistic Regression as "Two Numbers"

Instead of thinking of logistic regression as computing just one probability, think of it as computing two numbers that add up to 1:

z = w⃗·x⃗ + b   →   a₁ = g(z) = P(y=1|x⃗)   and   a₂ = 1 − a₁ = P(y=0|x⃗)
Quiz: If P(y=1) = 0.71, what's P(y=0)?  →  0.29 (they must sum to 1)

🚀 Generalizing to N Classes — Softmax

Example with 4 possible outputs (y = 1, 2, 3, 4). Each class gets its own linear function first:

z₁ = w⃗₁·x⃗+b₁   z₂ = w⃗₂·x⃗+b₂   z₃ = w⃗₃·x⃗+b₃   z₄ = w⃗₄·x⃗+b₄

Then softmax converts all the z's into probabilities that sum to 1:

a₁ = ez₁ / (ez₁+ez₂+ez₃+ez₄) = P(y=1|x⃗)
a₂ = ez₂ / (same denominator) = P(y=2|x⃗)
a₃ = ez₃ / (same denominator) = P(y=3|x⃗)
a₄ = ez₄ / (same denominator) = P(y=4|x⃗)
Quiz: a₁=0.30, a₂=0.20, a₃=0.15 → what's a₄?  →  0.35  (1 − 0.30 − 0.20 − 0.15, since all aⱼ must sum to 1)

🌐 General Formula (N classes)

zj = w⃗j·x⃗ + bj,   j = 1,...,N

aj = ezj / Σk=1N ezk = P(y=j | x⃗)

Parameters: w₁,...,w_N and b₁,...,b_N. By construction, a₁ + a₂ + ... + a_N = 1 always.

🔗 Setting N = 2 in softmax regression reduces mathematically to logistic regression (with slightly different parameterization) — confirming softmax truly generalizes logistic regression.

💰 Cost Function — From Logistic Loss to Cross-Entropy

Logistic Regression Loss

loss = −y·log(a₁) − (1−y)·log(1−a₁)

Since a₂ = 1−a₁, this simplifies to:

If y=1: loss = −log(a₁)
If y=0: loss = −log(a₂)

Softmax Regression Loss

(Cross-entropy loss) — generalizes the same idea to N classes:

If y=1: loss = −log(a₁)
If y=2: loss = −log(a₂)
⋮
If y=N: loss = −log(aN)

In short: loss = −log(aj), where j is whatever the true label y actually was for that example.

As aj → 1 (confident & correct), loss → 0. As aj → 0 (confident & wrong), loss → ∞.

📌 Key detail: for each training example, only one term −log(aj) is computed — whichever class j the true label actually was. The other classes' probabilities don't directly enter the loss for that example (though they do affect aj through the softmax denominator).

🌍 Real-World Analogy

Think of softmax like a panel of judges scoring 4 contestants in a talent show, then converting raw scores into "chance of winning" percentages that must add up to 100%.

  • Each contestant gets a raw score z (like a judge's numeric score) — could be any real number, positive or negative.
  • Softmax exponentiates and normalizes all 4 scores into percentages — a — that sum to exactly 100%.
  • The loss (−log aj) is like a penalty: if the show's actual winner was given only a 5% predicted chance, the penalty is huge. If they were given 95%, the penalty is tiny.
