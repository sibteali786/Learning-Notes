Lesson 2 — Evaluating Your Model (Train/Test)

A systematic, numeric way to tell whether your model actually generalizes — instead of eyeballing a plot.

1 Why "Just Plot It" Doesn't Scale

With a single feature (house size), you can plot f(x) and visually spot a problem — like an overly wiggly 4th-order polynomial fit to 5 points that clearly won't generalize.

4th-order fit — wiggly, overfits the 5 training points, unlikely to generalize.

But real models rarely have one feature. With x₁=size, x₂=bedrooms, x₃=floors, x₄=age, f(x) is a function of 4+ dimensions — you can't plot that. You need a number, not a picture, to judge performance.

2 The Fix: Split Your Data into Train + Test

Instead of using 100% of your data to fit parameters, hold some out. A common split is 70/30 (or 80/20), with the larger share for training:

Training set notation

m_train = number of training examples = 7

Test set notation

(x_test⁽¹⁾, y_test⁽¹⁾) ... (x_test⁽m_test⁾, y_test⁽m_test⁾)
m_test = number of test examples = 3

3 Train/Test Procedure — Linear Regression (Squared Error)

1
Fit parameters by minimizing the full cost function J(w,b) — squared error plus regularization — on the training set only.
2
Compute J_test(w,b) = average squared error on the held-out test set.
3
Compute J_train(w,b) = average squared error on the training set.
J(w,b) = 1/(2m_train)·Σ(f(x⁽ⁱ⁾)−y⁽ⁱ⁾)² + λ/(2m_train)·Σwj² used to FIT the parameters — includes regularization
J_test(w,b) = 1/(2m_test)·Σ(f(x_test⁽ⁱ⁾)−y_test⁽ⁱ⁾)² no λ term evaluates generalization — regularization term dropped
J_train(w,b) = 1/(2m_train)·Σ(f(x⁽ⁱ⁾)−y⁽ⁱ⁾)² no λ term evaluates fit on training data — regularization term dropped

Key detail: the regularization penalty is part of what you minimize to find w,b — but it's excluded from both J_train and J_test when you're just measuring error. Those are meant to reflect actual prediction error, not the optimization objective.

J_train(w,b)
LOW

The wiggly 4th-order model fits training points almost exactly → training error ≈ 0.

J_test(w,b)
HIGH

On unseen test points, predictions are far from actual prices → large gap.

Real-World Signal

Low J_train + high J_test is the numeric fingerprint of a model that memorized the training data instead of learning the underlying pattern — exactly what the wiggly curve looked like visually, but now you can detect it in a system with 50 features where you can't plot anything.

4 Train/Test Procedure — Classification

Same idea, different loss. For logistic regression (e.g. classifying handwritten digits 0 vs 1):

J(w,b) = −1/m_train · Σ[y⁽ⁱ⁾log(f(x⁽ⁱ⁾)) + (1−y⁽ⁱ⁾)log(1−f(x⁽ⁱ⁾))] + λ/(2m_train)·Σwj² logistic loss + regularization, used to fit w, b

J_test and J_train use the same logistic loss formula, applied to the test set / training set respectively — again without the regularization term.

A more common alternative for classification: instead of reporting the logistic-loss value, report the misclassification fraction.
  • Predict ŷ = 1 if f(x) ≥ 0.5, else ŷ = 0
  • Count how often ŷ ≠ y
  • J_test = fraction of the test set misclassified
  • J_train = fraction of the training set misclassified

This is more interpretable than a raw loss number — "12% of test digits misclassified" is easier to reason about than a log-loss value.

5 Key Takeaway

Splitting data into train/test gives you two numbers — J_train and J_test — that replace "look at the plot" as your evaluation method, and they work in any number of dimensions. This is the foundation for the next step: using these numbers to automatically choose between candidate models (straight line vs. 2nd order vs. 3rd order polynomial, etc.) rather than picking one by eye.
