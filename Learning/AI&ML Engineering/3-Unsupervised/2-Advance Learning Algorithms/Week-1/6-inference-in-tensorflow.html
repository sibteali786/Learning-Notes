Framework Note

This specialization uses TensorFlow (Google, Keras interface). The other major framework is PyTorch — both are widely used in industry.

Example 1: Coffee Roasting Classification

Goal: given temperature and duration, predict if the resulting coffee is good (y=1) or bad (y=0).

Good coffee only happens in a narrow "triangle" of temp/duration combos — too low temp or too short duration → undercooked; too high temp or too long duration → overcooked/burnt.

RegionOutcome
Low temp / short durationUndercooked ❌
High temp / long durationOvercooked ❌
Middle "triangle"Good coffee ✅

Network: 2 inputs → 3-unit hidden layer → 1-unit output layer, both using sigmoid.

x = np.array([[200.0, 17.0]])                       # temp=200°C, duration=17 min

layer_1 = Dense(units=3, activation='sigmoid')
a1 = layer_1(x)                                       # e.g. [0.2, 0.7, 0.3]

layer_2 = Dense(units=1, activation='sigmoid')
a2 = layer_2(a1)                                      # e.g. [0.8]

if a2 >= 0.5:
    yhat = 1        # predicted good coffee
else:
    yhat = 0

In this example, a2 = 0.8 ≥ 0.5 → predicted ŷ = 1 ("good coffee"), even though the true label for that particular point was actually a red ✗ (bad) — illustrating the model can make an incorrect prediction, which is normal and part of why we train/evaluate models.

Example 2: Handwritten Digit Classification

Same pattern, bigger network — 64 pixel inputs → 25 units → 15 units → 1 unit, all sigmoid.

x = np.array([[0.0, ..., 245, ..., 240, ..., 0.0]])   # 64 pixel intensities

layer_1 = Dense(units=25, activation='sigmoid')
a1 = layer_1(x)

layer_2 = Dense(units=15, activation='sigmoid')
a2 = layer_2(a1)

layer_3 = Dense(units=1, activation='sigmoid')
a3 = layer_3(a2)

if a3 >= 0.5:
    yhat = 1
else:
    yhat = 0

🎯 Real-world reading

This coffee-roasting example is simplified, but ML-based coffee roast optimization is a real thing companies use — tuning roast profiles (temp/time curves) to hit a target flavor consistently. The same Dense → Dense → Dense pattern you're writing here scales directly to problems like the digit classifier, spam detection, or fraud detection — same code shape, different input features and layer sizes.

Heads Up: NumPy Array Shapes

Note both examples wrap inputs in double brackets: np.array([[200.0, 17.0]]), not np.array([200.0, 17.0]).

That's the same 2D-shape requirement covered earlier — TensorFlow expects (num_samples, num_features). Here it's 1 sample with 2 features, so shape (1, 2). The next lesson digs into this data-shape convention in more detail.
