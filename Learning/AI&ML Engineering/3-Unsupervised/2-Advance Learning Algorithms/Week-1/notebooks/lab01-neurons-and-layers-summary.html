Lab: Neurons and Layers

C2 W1 Lab01 · TensorFlow/Keras — mapping Course 1's linear & logistic regression onto a single neuron

What the Lab Does

1Linear neuron (no activation) — builds a Dense(units=1, activation='linear') layer and shows it computes exactly f(x) = w·x + b, same as Course 1's linear regression.

2Logistic neuron (sigmoid activation) — builds a Sequential model with one Dense(1, activation='sigmoid') layer, showing it computes f(x) = sigmoid(w·x + b), same as Course 1's logistic regression.

In both cases, the lab manually sets w and b to values already known from Course 1, then verifies the Keras layer's output matches a hand-written NumPy computation of the same formula — proving Keras isn't doing anything magical under the hood.

❓ Q1: Why get_weights() then set_weights() — how are values chosen?

?In case of both linear and logistic regression we first used get_weights() and then set weights ourselves — how do we choose them?

Answer: The values weren't invented — they're the values already known from Course 1, where these exact same regression problems were solved by hand or by gradient descent. This lab isn't training anything; it's verifying that a Keras neuron computes the identical formula.

set_w = np.array([[200]])
set_b = np.array([100])
linear_layer.set_weights([set_w, set_b])     # overwrite with known-correct values
🎯 Why this order matters

A Keras Dense layer doesn't know its input/output shapes until it sees actual data — so get_weights() right after creating the layer returns an empty list (no weights yet). Only after the first call (linear_layer(X_train[0]...)) does Keras allocate weight arrays with the correct shape and initialize them (small random w, b=0). Then you can call set_weights() to overwrite those random values with the ones you already know are correct — purely for demonstration purposes here, not because that's how real training works. In real training, you'd never hand-pick w, b like this — gradient descent finds them.

❓ Q2: How do we get the same result for different w, b?

?How do we get same result for different values of w and b?

Answer: This is a slight misread of the lab — the lab does not get the same result from different w/b. It does the opposite: it takes one fixed w, b and shows two different computation methods (the Keras layer, and a manual NumPy formula) produce the same output. That's the actual comparison being made.

a1 = linear_layer(X_train[0].reshape(1,1))                 # Method 1: Keras layer
print(a1)                                                    # → same w, b used internally

alin = np.dot(set_w, X_train[0].reshape(1,1)) + set_b        # Method 2: raw NumPy formula
print(alin)                                                  # w·x + b, computed by hand

# Both print the SAME number — proving Dense(activation='linear') == w·x + b

Same pattern repeats for the logistic neuron:

a1 = model.predict(X_train[0].reshape(1,1))                          # Keras sigmoid layer
alog = sigmoidnp(np.dot(set_w, X_train[0].reshape(1,1)) + set_b)     # manual sigmoid(w·x+b)
# again — identical values
🎯 Real-world takeaway

This is the core "aha" of the lab: a Keras Dense layer with 1 unit is literally the regression equation you already know from Course 1 — just wrapped in a framework built to scale up to hundreds of neurons and layers. Same w, same b, same math — just two different code paths (Keras's optimized internals vs. your own NumPy) arriving at the identical number.
