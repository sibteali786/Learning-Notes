Building a Neural Network in TensorFlow

Lesson 8 · The Sequential API — from manual layer-by-layer forward prop to model.compile / fit / predict

What You Did Before (Manual Forward Prop)

x = np.array([[200.0, 17.0]])
layer_1 = Dense(units=3, activation="sigmoid")
a1 = layer_1(x)

layer_2 = Dense(units=1, activation="sigmoid")
a2 = layer_2(a1)

You manually passed data into layer 1, took its output, and fed it into layer 2 yourself — explicit, step-by-step forward propagation.

The New Way: Sequential()

Instead of manually chaining layers yourself, tell TensorFlow to string the layers together into a model:

layer_1 = Dense(units=3, activation="sigmoid")
layer_2 = Dense(units=1, activation="sigmoid")

model = Sequential([layer_1, layer_2])

Now TensorFlow handles passing data from one layer to the next internally — you no longer call each layer by hand.

Train and Predict — Just 4 Lines

model.compile(...)      # configure the training process — details next week
model.fit(x, y)          # train the model on your data — details next week
model.predict(x_new)     # run forward propagation → get a prediction

1model.compile(...) — sets up how the model will learn (loss function, optimizer)

2model.fit(x, y) — actually trains the weights on your data

3model.predict(x_new) — runs forward propagation on new data and returns the output (replaces manually calling each layer)

compile/fit internals are covered next week — for now just know these are the two calls needed to train.

The Common Convention (Inline Layers)

In practice, you rarely see layers assigned to separate variables first. The idiomatic style inlines them directly inside Sequential([...]):

Explicit (what you learned first)
layer_1 = Dense(units=3, activation="sigmoid")
layer_2 = Dense(units=1, activation="sigmoid")
model = Sequential([layer_1, layer_2])
Idiomatic (what you'll see in real code)
model = Sequential([
    Dense(units=3, activation="sigmoid"),
    Dense(units=1, activation="sigmoid")
])

Functionally identical — just fewer named variables cluttering the code.

Same Pattern, Bigger Network: Digit Classification

    Dense(units=25, activation="sigmoid"),

model.compile(...)

x = np.array([[0..., 245, ..., 17], [0..., 200, ..., 184]])   # pixel data, multiple examples

model.fit(x, y)

Same 4-step recipe regardless of network size: define layers → Sequential() → compile → fit → predict.

The Full Recipe

1Define your layers: Dense(units=N, activation=...)

2String them together: model = Sequential([...])

3Configure training: model.compile(...)

4Train: model.fit(x, y)

5Predict on new data: model.predict(x_new)

⚠️ A note the instructor makes explicitly

It's easy to type these ~5 lines, get a working "state of the art" network, and not actually understand what's happening underneath. The point of this course isn't just to memorize the API — it's to understand forward propagation well enough that when something breaks, you can reason about it. That's why the next lesson implements forward propagation from scratch in plain Python/NumPy — no Keras — purely to build that intuition, even though in practice you'd almost always just use TensorFlow/PyTorch.

🎯 Real-world reading

This Sequential → compile → fit → predict pattern is the actual backbone of real Keras projects — image classifiers, recommendation systems, NLP models. What changes across projects is mostly the layer types/sizes and the data; the training loop shape stays this same.
