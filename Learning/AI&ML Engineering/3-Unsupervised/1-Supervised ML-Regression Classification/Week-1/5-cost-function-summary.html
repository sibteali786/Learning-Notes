Linear Regression: Building the Cost Function DeepLearning.AI notes

Goal: Define a function that tells us how well a line fits the training data — so we can improve it. This is the cost function.

1. The Model & Its Parameters

fw,b(x) = w·x + b
SymbolMeaning
x, yInput feature / output target from the training set
w, bParameters (also called weights/coefficients) — adjusted during training
wSlope of the line
by-intercept (where the line crosses the y-axis)
ŷ(i)Prediction for example i: ŷ(i) = fw,b(x(i))

2. How w and b Shape the Line

Case 1
w=0, b=1.5
f(x)=1.5 (constant, ŷ=b)
Case 2
w=0.5, b=0
f(x)=0.5x (slope only)
Case 3
w=0.5, b=1
f(x)=0.5x+1 (slope + intercept)

3. Building the Cost Function — Step by Step

  • Error: for each example i, compute ŷ(i) − y(i) (how far off the prediction is)
  • Square it: (ŷ(i) − y(i))² — penalizes larger errors more, keeps result positive
  • Sum over all training examples: Σ from i=1 to m
  • Average it (divide by m) so cost doesn't grow just because the dataset is bigger
  • Divide by 2 (convention) — makes later derivative calculations cleaner (does not change what "good" looks like)

4. The Cost Function (Squared Error Cost)

J(w,b) = (1 / 2m) · Σi=1m ( fw,b(x(i)) − y(i) )²
m = number of training examples (e.g. 47 in the video's housing dataset). This is called the squared error cost function — the most common cost function for linear regression and regression problems in general.

5. Real-World Framing

Example: Predicting house price (y) from size in sq ft (x). Each training house gives a real price y(i) and your model predicts ŷ(i). J(w,b) is essentially the average squared prediction error across all houses — small J means your line's price predictions are close to actual sale prices; large J means the line is a poor fit.
