Goal: Combine the linear regression model, the squared error cost function, and gradient descent into one complete learning algorithm — and clarify how "local minima" and "convex" relate to this specific cost function.

1. The Three Pieces Combined

PieceFormula
Modelfw,b(x) = wx + b
Cost functionJ(w,b) = (1/2m) Σ (fw,b(x(i)) − y(i))²
Gradient descentw := w − α·(d/dw)J(w,b),   b := b − α·(d/db)J(w,b) — simultaneously

2. The Derivative Terms (Plug These In)

d/dw J(w,b) = (1/m) · Σi=1m ( fw,b(x(i)) − y(i) ) · x(i)
d/db J(w,b) = (1/m) · Σi=1m ( fw,b(x(i)) − y(i) )

Same formula, except the w-derivative has an extra x(i) factor at the end.

3. Where These Come From (Optional Calculus)

Fully optional — skipping this does not affect your ability to implement gradient descent. Substituting fw,b(x(i)) = wx(i) + b into J(w,b) and differentiating with the chain rule causes the "2" from squaring to cancel with the "1/2" in front of the cost function — this is exactly why the 1/2 was included in the cost function's definition in the first place: purely to make this derivative come out clean.

4. Local Minima vs. Global Minimum — Two Different Cost Surfaces

Generic cost function (e.g. neural net)
Hilly, "outdoor park" surface — multiple local minima. Where gradient descent ends up depends on the starting point (w, b).
Squared error cost, linear regression
Bowl/hammock-shaped surface — convex: only ever one minimum, the global minimum. No other valleys exist to get stuck in.
Because J(w,b) for linear regression is always this bowl shape, gradient descent with a properly chosen α is guaranteed to converge to the global minimum — regardless of where w and b are initialized.

Your Question, Answered

Q: Are the squared error cost function and "the gradient cost function" different things — of course they are?
There's really only one cost function in play for linear regression: the squared error cost J(w,b). Gradient descent is not a separate cost function — it's the optimization algorithm that minimizes whatever cost function you hand it. There's no separate "gradient cost function"; gradient descent just uses the derivative of J(w,b) to decide which way to step.
Q: Then why does Andrew say gradient descent on a convex function only finds the global minimum, when the cost function has multiple minima?
The "multiple minima" surface was a different example J (the generic, hilly one used to illustrate local minima in general) — not the squared error cost function used for linear regression. The squared error cost function is always the bowl shape (convex), with exactly one minimum. So there's no contradiction: gradient descent applied to a non-convex J (hilly) can get stuck in a local minimum; the same algorithm applied to the convex J (bowl, squared error) always reaches the single global minimum. Same algorithm, two different cost landscapes.

Real-World Framing

Example: Predicting house prices from size. Because the squared error cost is convex, no matter what starting guess you pick for w and b (even w=0, b=0), gradient descent is guaranteed to walk downhill into the one true best-fit line — you'll never get unlucky and land on a "good but not best" line the way you could with a hilly, non-convex cost function.
