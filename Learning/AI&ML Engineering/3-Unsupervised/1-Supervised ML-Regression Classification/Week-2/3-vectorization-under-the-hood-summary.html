🔍 How Vectorization Works Under the Hood

Same algorithm, vectorized vs. not — why the vectorized version can be dramatically faster on real hardware.

1️⃣ For Loop: Sequential (Step-by-Step)

Without vectorization 
for j in range(16):
    f = f + w[j] * x[j]

Each iteration happens one after another — the hardware computes index 0, waits, then index 1, then index 2... all the way to index 15.

t0: j=0
t1: j=1
t2: j=2
...
t15: j=15

16 separate steps in time, done sequentially.

2️⃣ np.dot: Parallel (All at Once)

With vectorization 
f = np.dot(w, x) + b

Specialized hardware does two things efficiently:

Step 1: multiply ALL 16 pairs (w[i] × x[i]) simultaneously
↓
Step 2: add all 16 products together using efficient parallel-sum hardware

Instead of 16 sequential steps, the multiplications happen in one parallel step, and the summation uses dedicated hardware rather than 15 sequential additions.

3️⃣ Why It Matters More at Scale

ScenarioImpact
16 featuresSpeed difference exists but may be small
Thousands of features + large datasetsDifference between minutes and many hours
🔹 This is exactly why vectorization is a key technique for scaling ML algorithms to modern large datasets.

4️⃣ Concrete Example: Gradient Descent Update for Multiple Linear Regression

Setup: 16 features → 16 weights (w₁...w₁₆) + b. Derivatives d₁...d₁₆ already computed, stored as NumPy arrays w and d (b ignored for this example).

wⱼ = wⱼ − α · dⱼ   (α = learning rate, e.g. 0.1), for j = 1...16
Without vectorization 
w1 = w1 - 0.1 * d1
w2 = w2 - 0.1 * d2
...
w16 = w16 - 0.1 * d16

# or with a loop:
for j in range(0, 16):
    w[j] = w[j] - 0.1 * d[j]
With vectorization 
w = w - 0.1 * d

All 16 subtract-and-update operations happen in parallel, in one step, and are assigned back to w all at once.

5️⃣ Real-World Impact

Example scenario: Training a linear regression model with thousands of features on a large dataset.

  • Un-vectorized: could take many hours to finish training
  • Vectorized: the same computation could finish in one or two minutes
