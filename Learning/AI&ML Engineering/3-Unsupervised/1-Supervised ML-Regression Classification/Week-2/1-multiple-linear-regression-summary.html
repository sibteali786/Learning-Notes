📈 Week Overview: Multiple Linear Regression

Goal: extend linear regression from one feature to many features, making it faster and more powerful.

1️⃣ From One Feature to Many

Before Single feature (size of house) → predicts price

fw,b(x) = wx + b

Now Multiple features: size, #bedrooms, #floors, age

fw,b(x) = w₁x₁ + w₂x₂ + w₃x₃ + w₄x₄ + b

2️⃣ Notation

SymbolMeaning
xjj-th feature (j = 1..n)
ntotal number of features
x(i)feature vector of the i-th training example
xj(i)value of feature j in training example i
Example scenario: House #2 has features [1416, 3, 2, 40] → size, bedrooms, floors, age.
x(2) = [1416, 3, 2, 40]  → a row vector
x3(2) = 2 (the 3rd feature, floors, of the 2nd example)
🔹 The arrow (e.g. x⃗) is just an optional visual cue meaning "this is a vector," not a number.

3️⃣ General Model (n features)

fw,b(x) = w₁x₁ + w₂x₂ + ... + wₙxₙ + b
Real-world example — house pricing:
f(x) = 0.1·x₁ + 4·x₂ + 10·x₃ − 2·x₄ + 80 (price in $1000s)
TermFeatureInterpretation
b = 80—Base price ≈ $80,000 (no size/rooms/floors/age)
0.1size (x₁)+$100 per extra sq. ft.
4bedrooms (x₂)+$4,000 per extra bedroom
10floors (x₃)+$10,000 per extra floor
−2age (x₄)−$2,000 per year of age

4️⃣ Vector Notation & Dot Product

Define parameter vector w⃗ = [w₁, w₂, ..., wₙ] and feature vector x⃗ = [x₁, x₂, ..., xₙ]. b stays a single number.

fw,b(x) = w⃗ · x⃗ + b

Dot product = multiply corresponding elements, then sum:

w⃗ · x⃗ = w₁x₁ + w₂x₂ + ... + wₙxₙ
w⃗ · x⃗

+ b

same result as expanded sum, just more compact

5️⃣ Naming

  • Univariate regression — one feature
  • Multiple linear regression — many features (this week's topic)
  • ⚠️ Not called "multivariate regression" — that term means something different
