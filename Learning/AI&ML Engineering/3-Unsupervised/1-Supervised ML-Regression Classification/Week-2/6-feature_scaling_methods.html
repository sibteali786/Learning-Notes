📏 Feature Scaling Methods + Standard Deviation & Z-Score

How to actually implement feature scaling: divide-by-max, mean normalization, z-score normalization, and how to judge if scaling is needed

❓ Quick Answers First

ConceptExplanation
Standard deviation (σ) Measures how spread out data is from the mean. Steps: find distance of each value from the mean → square each distance → average the squares → take the square root. Small σ = values cluster near the mean; large σ = values are spread wide. In a normal (bell-curve) distribution, ~68% of values fall within 1σ of the mean.
Z-score z = (x − μ) / σ — "how many standard deviations away from average is this value?" It recenters a feature around 0 and rescales it by its typical spread, so features on very different scales become comparable.
🎓 Analogy: Exam scores. Class average (μ) = 70, σ = 10. You score 90 → z = (90−70)/10 = 2 (2 std devs above average — a strong result). Someone else scores 90 on a different test where the average was 88 and σ = 2 → z = (90−88)/2 = 1 (only 1 std dev above average). Same raw score, very different standing — z-score reveals the real difference. This is exactly what z-score normalization does to ML features: it strips away arbitrary raw scale so gradient descent treats each feature fairly.

⚙️ Three Ways to Implement Feature Scaling

Applied to x₁ = size in feet² (300–2000) and x₂ = # bedrooms (0–5):

1️⃣ Divide by Max

xscaled = x / max

x₁: 0.15 → 1
x₂: 0 → 1

Simplest method — just divide every value by the maximum in that feature's range.

2️⃣ Mean Normalization

xnorm = (x − μ) / (max − min)

μ₁=600 → x₁: −0.18 to 0.82
μ₂=2.3 → x₂: −0.46 to 0.54

Centers data around 0 — values become both negative and positive.

3️⃣ Z-score Normalization

x = (x − μ) / σ

μ₁=600, σ₁=450 → x₁: −0.67 to 3.1
μ₂=2.3, σ₂=1.4 → x₂: −1.6 to 1.9

Uses standard deviation instead of range — standard in most ML pipelines.

📐 Rule of Thumb: When Do You Need to Rescale?

Aim for roughly −1 ≤ x ≤ 1 per feature. Anything from −3 to 3 down to −0.3 to 0.3 is fine too.

Feature rangeVerdict
0 ≤ x₁ ≤ 3✓ Okay, no rescaling needed
−2 ≤ x₂ ≤ 0.5✓ Okay, no rescaling needed
−100 ≤ x₃ ≤ 100✗ Too large → rescale
−0.001 ≤ x₄ ≤ 0.001✗ Too small → rescale
98.6 ≤ x₅ ≤ 105 (body temp)✗ Too large (centered far from 0) → rescale

💡 There's almost never any harm in rescaling — when in doubt, just do it.

📝 Recap Steps

  1. Divide-by-max: quick and simple, scales to [0,1] but doesn't center around 0.
  2. Mean normalization: (x−μ)/(max−min) — centers around 0, both negative and positive values.
  3. Z-score normalization: (x−μ)/σ — uses standard deviation, the most common in practice.
  4. Check each feature's range against the −1 to 1 rule of thumb; rescale anything far outside it.
