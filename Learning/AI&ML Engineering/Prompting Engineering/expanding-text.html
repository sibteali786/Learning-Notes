📈 Expanding Text with LLMs

Turning short input (a review, a topic list) into longer generated output (an email, an essay) — plus controlling randomness with temperature.

What Is Expanding?

Taking a short input — instructions, a topic list, a customer review — and having the model generate a longer piece of text, e.g. an email or essay. Great as a brainstorming partner.

⚠️ Responsible use required — the same capability that drafts a helpful personalized email can be misused to mass-generate spam. Use only in ways that genuinely help people.

Temperature — Controlling Randomness

Temperature controls how "exploratory" the model's word choices are. Example: for "my favorite food is..." the model might rank pizza (most likely) > sushi > tacos (least likely, ~5%).

Temp 0 → always picks "pizza"
Temp 0.7 → varies each run
Temp 1+ → more "tacos"-like picks
TemperatureBehaviorBest for
0Deterministic — same input → same output every timeReliable, predictable production systems (used throughout this course)
0.7+Random — same input → different output each runCreative brainstorming, varied marketing copy, idea generation
🧪 Scenario: Generating 5 different variations of a marketing email to A/B test → run the same prompt at temperature 0.7 multiple times instead of manually rewriting.
💡 Interview/practical tip: Default to temperature 0 for anything requiring consistency (support replies, data extraction, structured output). Reserve higher temperature strictly for creative/exploratory tasks where variety is the goal, not a bug.
