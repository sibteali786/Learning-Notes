1 · Translation

Basic translation

English"Hi, I would like to order a blender"
→
Spanish"Hola, me gustaría ordenar una licuadora"

Also supports:

  • Language identification ("What language is this?")
  • Multiple languages at once (French + Spanish + "pirate English")
  • Formal vs. informal register ("Spanish formal and informal forms")
🧪 Scenario — Universal Translator: A multinational e-commerce support inbox gets IT issues in many languages. Loop over each message → detect language → translate to English (for support team) and Korean (for regional team). Built in minutes, no per-language rules.
2 · Tone Transformation

Slang → Business Letter

Slang"Dude, this is Joe, check out this spec on the standing lamp."
→
FormalProfessional letter proposing the standing lamp spec.
🧪 Scenario: Draft a casual internal Slack note, then auto-formalize it into a client-ready email — same content, audience-appropriate tone.
3 · Format Conversion

JSON → HTML Table

Translate the following Python dictionary from JSON to an HTML table with column headers and title.

Input: list of employees (name, email) as JSON → Output: a rendered HTML <table>.

🧪 Scenario: Replaces what used to be manual templating or regex-based format conversion — describe input + output format in plain English, model does the transformation.
4 · Spelling & Grammar Correction

Basic proofreading

Proofread and correct the following text.

Tip: add "If you don't find any errors, just say 'No errors found'" so it doesn't rewrite already-correct text unnecessarily.

Show the diff

Use the redlines Python package to visually diff the original vs. corrected text — see exactly what changed.

🧪 Scenario: Proofreading a product review before posting publicly — diff view shows precisely which words were fixed.

Combine correction + style upgrade

Proofread and correct this review. Make it more compelling. Ensure it follows APA style and targets an advanced reader. Output in markdown.

One prompt does grammar fix + tone upgrade + style guide compliance + format conversion simultaneously.

Quick Reference
TaskKey phrase to use
Translate"Translate the following text to [language]"
Detect language"Tell me what language this is"
Formal/informal"...in both the formal and informal forms"
Tone shift"Translate the following from [tone A] to [tone B]"
Format convert"Translate the following from [format A] to [format B]"
Proofread"Proofread and correct the following text"
💡 Interview/practical tip: Frame transformation tasks as "translate from X to Y" — this pattern works whether X/Y are languages, tones, or data formats (JSON→HTML, slang→formal). It's the same underlying skill, just applied broadly.
