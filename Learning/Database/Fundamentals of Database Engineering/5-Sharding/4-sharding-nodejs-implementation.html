Sharding — NodeJS Implementation

A working URL-shortener REST API that hashes each URL, picks a shard with a consistent-hash ring, and writes to the right server.

Project Setup

mkdir sharding && cd sharding
npm init -y
npm install express pg consistent-hash
# crypto is a Node built-in — no install needed

Building a tiny Express API with two routes: POST / shortens a URL and writes it to the right shard, GET / is a health check.

The Three Pieces

1

pg — three DB clients

One Client per shard port, keyed by port number in a plain object (5432, 5433, 5434) so a shard can be looked up by its port string later.

2

crypto — turn URL into a code

sha256 hash of the long URL, base64-encoded, then the first 5 characters become the short urlId. (Not a production-grade shortener — just enough to demonstrate sharding.)

3

hashring — pick the shard

A hash ring built with the hashring npm library, seeded with the 3 shard ports as nodes. Feed it the urlId, get back the port to connect to — same key always returns the same shard.

Library swap — bug found mid-build

The originally-used consistent-hash npm package turned out to be buggy — it returned a different server for the same key on repeated calls, defeating the entire point of consistent hashing. It also hadn't been updated in 4 years. Swapped it out for hashring, which is a correct implementation of the same idea: same key always returns the same shard. Only the import and instantiation changed — const HashRing = require("hashring"); const hr = new HashRing(); — the rest of the routing logic (hr.add(port), hr.get(key)) stayed identical.

Request Flow

Hash the URL → shrink to a 5-char urlId → feed that id to the hash ring → get a shard port → run the insert on that specific client → respond with { urlId, url, server }.

Full Code — index.js

const app = require("express")();
const { Client } = require("pg");
const crypto = require("crypto");
const HashRing = require("hashring"); // swapped from buggy "consistent-hash"

const hr = new HashRing();
hr.add("5432");
hr.add("5433");
hr.add("5434");

const clients = {
  5432: new Client({ host: "localhost", port: "5432", user: "postgres", password: "postgres", database: "postgres" }),
  5433: new Client({ host: "localhost", port: "5433", user: "postgres", password: "postgres", database: "postgres" }),
  5434: new Client({ host: "localhost", port: "5434", user: "postgres", password: "postgres", database: "postgres" }),
};

connect();
async function connect() {
  await clients["5432"].connect();
  await clients["5433"].connect();
  await clients["5434"].connect();
}

app.get("/", (req, res) => { res.send("ok"); });

app.post("/", async (req, res) => {
  const url = req.query.url;

  // hash the URL and shrink to a 5-char code
  const hash = crypto.createHash("sha256").update(url).digest("base64");
  const urlId = hash.substring(0, 5);

  // consistent hash ring picks the shard
  const server = hr.get(urlId);

  await clients[server].query(
    "INSERT INTO url_table (url, url_id) VALUES ($1, $2)",
    [url, urlId],
  );

  res.send({ urlId, url, server });
});

app.listen("8081", () => console.log("listening 8081"));
