# Excalidraw Data

## Text Elements
1. Data Consistency & Integrity

Define proper data types, constraints, and relationships
Prevents 3 anomalies:

Insertion — adding a record forces you to add unrelated data (e.g. can't add a product review without first having a product)
Update — changing one value breaks consistency elsewhere (e.g. updating a price in one row but not duplicates)
Delete — removing a record accidentally wipes related info (e.g. deleting a customer deletes their order history) ^pVSIH3Al

2. Maintainability & Ease of Use

Use consistent naming conventions
(e.g. don't mix id, Id, identifier across tables — pick one and stick to it) ^IQTQqcKU

3. Performance & Optimization

Design to speed up queries and reduce response time
Use indexing on frequently sorted/searched columns
(e.g. index the date column on a reviews table so "latest reviews first" loads fast)
Analogy: index = library card catalog — skip scanning every book, jump straight to location ^j0hM2z53

4. Data Security

Prevent unauthorized access/modification
Encrypt sensitive data
(e.g. never store credit card numbers as plain text — encrypt them so a breach doesn't expose everything) ^XTJTR2TQ

5. Scalability & Flexibility

Design to handle growth without sacrificing performance
Separate/normalize tables to keep them lean
Use caching for frequently accessed data (e.g. product info cached in RAM via Redis so the DB isn't hit on every page load) ^qQgH6eEC

Good Database Desgin ^0Z9qxRWM
