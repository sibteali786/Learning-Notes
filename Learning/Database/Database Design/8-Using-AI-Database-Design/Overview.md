### ⚠️ Trade-off to Consider

**Current approach** — separate `address` table linked via `address_id`
- ✅ No duplication, single place to update an address
- ✅ Enables regional queries across both dealers and customers in one table
- ❌ Extra `JOIN` needed on every query involving address fields

**Alternate** — keep address fields inline (previous approach)
- ✅ Simpler queries, no joins needed
- ❌ Duplication, harder to maintain consistency

> Also note: since multiple customers can share an address (per requirements), the shared `address` table handles that naturally — multiple `customer` rows can reference the same `address_id`. ^ioB6a4cu
