# Excalidraw Data

## Text Elements
All four data type groups are covered with the key decision rules, the tricky edge cases, and the final fully-typed schema from image 17.
Two things worth highlighting that the book emphasizes but are easy to miss:
The "store as string not integer" rule — card_number, expiry_date, and UPC code all look numeric but must be CHAR because integers silently strip leading zeros. This is a real-world bug source.
DECIMAL(13,2) on total_price vs DECIMAL(7,2) on individual prices — the higher precision on totals is intentional, anticipating larger accumulated values across many items. ^MDZ70ZWv
