npx expo install — Why Not yarn/npm?

Key Concept
yarn add / npm install
Installs latest version of the package. May be incompatible with your current Expo SDK + React Native version. Can crash your app silently.
npx expo install ✓
Checks known SDK-compatible versions first, then calls your package manager. Still uses yarn/npm/pnpm — detects which via your lockfile.
npx expo install @expo/vector-icons # output: "Installing 1 SDK 51 compatible native module using yarn" # → your lockfile = yarn.lock? uses yarn. pnpm-lock? uses pnpm. etc.
★ Real-world analogy: Like using pip install with a requirements.txt pinned version vs blindly installing latest. Expo SDK is a version contract — native modules must match.
💡 Expo Go bonus: Because Expo Go is a pre-built sandbox, @expo/vector-icons is already bundled inside it. No native rebuild required — install and it just works.

SVG on Mobile — Performance Gotcha

Warning
FormatWebReact NativeVerdict
SVG Ideal — scalable, tiny Expensive on Android especially. 1000 SVGs can crawl the app. Use sparingly
PNG (@2x/@3x) OK Preferred for general images — lightweight to render Default choice
Vector Icons Icon fonts Optimized for tab bars, icon buttons — fine at scale ✓ What we use
expo-image — Also renders SVGs — Expo's performant image component Alternative
⚠️ SVG ≠ free on native. Each SVG is a full render tree on Android. Coming from web, this surprises everyone. Use react-native-svg when you need SVG, but keep count low.

hitSlop — Bigger Tap Area for Small Icons

UX Tip
Problem

A 24px icon is hard to tap accurately on mobile. Users miss it and get frustrated — especially one-handed or on small screens.

hitSlop={20} ✓

Extends the pressable area by 20px on all sides without changing the visual size. The icon stays 24px but taps register in a ~64px area.

// number — same on all sides <TouchableOpacity hitSlop={20}> // object — fine-tune per side <TouchableOpacity hitSlop={{ top: 20, bottom: 20, left: 10, right: 10 }}>
★ Real-world rule: Apple HIG recommends minimum 44×44pt tap target. Google Material says 48×48dp. A 24px icon with hitSlop=20 gives you ~64px — safely above both.
