The Core Trick — Style Arrays

Key Concept

The style prop accepts either a single object or an array. Arrays merge left-to-right — later entries override earlier ones. undefined entries are silently skipped.

// ✓ single style style={styles.itemContainer} // ✓ array — last value wins on conflicts style={[styles.itemContainer, styles.completedContainer]} // ✓ conditional — undefined is safe, just ignored style={[styles.itemContainer, isCompleted ? styles.completedContainer : undefined]}
★ Real-world analogy: Like CSS specificity but explicit — base styles first, overrides second. Same pattern as Object.assign({}, defaults, overrides) in plain JS. No class selectors needed.

Boolean Prop Shorthand + Live Preview

JSX Tip

For boolean props, = true can be omitted:

// verbose — works but redundant <ShoppingListItem isCompleted={true} /> // shorthand — preferred ✓ <ShoppingListItem isCompleted /> // App.tsx usage <ShoppingListItem name="Coffee" /> // todo <ShoppingListItem name="Tea" isCompleted /> // done <ShoppingListItem name="Milk" isCompleted /> // done
⚠️ Only works for booleans = true. Can't use shorthand for false, strings, numbers, or objects — those always need ={value}.

Conditional Styling Pattern — Cheatsheet

Reference
style array

Pass an array to style. Merges objects, last wins. Replaces need for className concatenation from web.

undefined is safe

Falsy items in a style array are silently ignored. Enables clean condition ? style : undefined pattern.

3 elements, 1 prop

Apply isCompleted override to container, text, and button independently — each controls its own visual state.

★ Scalable pattern: Add more visual states (e.g. isUrgent, isSelected) without any conditional JSX branching — just extend the style array with another ternary. No duplicated markup.
