Run on Device

Step 2
npx expo start # or: yarn start / npm run start
🤖 Android

Open Expo Go → tap Scan QR Code button → point at terminal QR.

🍎 iOS

Open Camera app (not Expo Go) → scan QR → deep-links into Expo Go. First launch needs network permission prompt.

★ Debug menu shortcut: Shake phone or hold 3 fingers on screen (iOS). Use it to: Reload · Performance monitor · JS debugger · Toggle Fast Refresh.
⚠️ Fast Refresh accidentally disabled? If your app stops hot-reloading, open the debug menu and re-enable it — easy to toggle off by mistake.

Connection Troubleshooting

Common Pitfall
Problem Root Cause Fix
Expo Go can't load bundle Phone & laptop on different Wi-Fi Switch both to same network
Still failing (Windows) Firewall blocks LAN traffic on localhost --tunnel flag (ngrok)
Want to share build with teammate Teammate on different network --tunnel exposes bundler to internet
yarn start --tunnel # installs ngrok on first use; slower but universal
★ Real-world scenario: You're pair-programming remotely. Your colleague can scan your --tunnel QR from anywhere in the world and instantly run your local bundle on their phone — no deployment needed.
