Chapter 11

What & Why

Concept
What is haptic feedback

The physical vibration your phone produces in response to a touch. Native-only — no web equivalent. Part of the premium "this feels alive" quality of good mobile apps.

Use sparingly

A few well-placed vibrations feel polished. Haptics on every tap feels noisy and drains battery. Reserve for meaningful moments: deletes, completions, errors.

★ Real-world analogy: The click of a light switch vs a mushy button. Same function, completely different feel. Haptics are that click — they confirm an action happened at a physical level the screen alone can't convey.

expo-haptics API

Reference

FunctionTypes / ValuesFeelUse when
impactAsync() Light · Medium · Heavy · Rigid · Soft Button taps, list actions, toggles
notificationAsync() Success · Warning · Error double pulse on iOS Completing tasks, form success/fail
selectionAsync() — very light Picker wheels, segmented controls
⚠️ Can't test on simulator. Simulators have no vibration hardware. Always test haptics on a real device — iOS and Android feel noticeably different in intensity (Android tends stronger by default).

Where to Add — Two Files

Code

File 1: components/ShoppingListItem.tsx — on delete icon tap (before Alert)

+ import * as Haptics from "expo-haptics"; const handleDelete = () => { + Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium); Alert.alert(...); };

File 2: app/index.tsx — delete + toggle with conditional feedback

+ import * as Haptics from "expo-haptics"; // handleDelete: Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium); setShoppingList(newList); // handleToggleComplete — inside the map, when item.id matches: if (item.completedAtTimestamp) { // was completed → undoing it → lighter feedback + Haptics.impactAsync(Haptics.ImpactFeedbackStyle.Medium); } else { // completing it → success → strongest feedback + Haptics.notificationAsync(Haptics.NotificationFeedbackType.Success); }
Delete icon tap

Medium impact — light confirmation the delete flow has started (Alert still shown).

Mark complete

Success notification — double pulse on iOS, strongest feel. Rewards the "done" action.

Unmark complete

Medium impact — less celebratory than completing. Still provides tactile acknowledgement.

💡 Haptics are fire-and-forget async calls. No need to await them — they don't block the UI and you don't need to handle the result.
