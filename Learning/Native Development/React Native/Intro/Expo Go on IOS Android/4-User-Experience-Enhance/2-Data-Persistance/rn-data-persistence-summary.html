AsyncStorage — Mental Model

Concept
Problem — in-memory state

useState lives in RAM. Kill the app → RAM cleared → shopping list gone. Every app restart starts fresh.

Solution — AsyncStorage

Unencrypted key-value store on device storage. Survives app restarts. Scoped to the app — other apps cannot read it.

Web — localStorage

Synchronous. localStorage.getItem(key) → returns value immediately.

RN — AsyncStorage

Asynchronous. await AsyncStorage.getItem(key) → returns Promise. Must use async/await everywhere.

★ Community history: AsyncStorage was removed from React Native Core deliberately — Meta drew a hard line: "native community manages storage, we manage the framework." It's now @react-native-async-storage/async-storage.

utils/storage.ts

New File
import AsyncStorage from "@react-native-async-storage/async-storage"; export async function getFromStorage(key: string) { try { const data = await AsyncStorage.getItem(key); return data ? JSON.parse(data) : null; } catch { return null; // always catch — invalid JSON would crash otherwise } } export async function saveToStorage(key: string, data: object) { try { await AsyncStorage.setItem(key, JSON.stringify(data)); } catch {} // silent fail — app continues even if storage fails }
Strings only

AsyncStorage stores only strings. All objects must be JSON.stringify'd on save and JSON.parse'd on read.

Not serializable?

Date objects, functions, undefined cannot be JSON stringified. Use timestamps (numbers) instead — as we did for completedAtTimestamp.

Always try/catch

JSON.parse throws on malformed data. Without catch, a corrupted storage entry would crash the whole app on launch.

Load on Mount — useEffect Pattern

index.tsx
import { useEffect, useState } from "react"; import { getFromStorage, saveToStorage } from "../utils/storage"; const storageKey = "shopping-list"; // scoped key — unique per feature // inside App(): useEffect(() => { // useEffect is synchronous — can't be async directly // Solution: define async fn inside, call it immediately (fire-and-forget) const fetchInitial = async () => { const data = await getFromStorage(storageKey); if (data) setShoppingList(data); }; fetchInitial(); // called, not awaited }, []); // empty dep array = runs once on mount only
⚠️ useEffect can't be async. Making the callback async returns a Promise — React expects either nothing or a cleanup function. The inner async function pattern is the standard workaround.
💡 Empty array [] = "run once." No array = runs after every render. Array with values = runs when those values change. For initial data fetch, always use [].

Sync Storage on Every Mutation

index.tsx
