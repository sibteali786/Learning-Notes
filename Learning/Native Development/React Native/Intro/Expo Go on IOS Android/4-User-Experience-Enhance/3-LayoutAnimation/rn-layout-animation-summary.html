Chapter 10

What LayoutAnimation Does

Concept
Without LayoutAnimation

Items teleport between positions instantly. Completing an item snaps to the bottom. Deleting an item causes an abrupt gap. Jarring UX.

With LayoutAnimation

RN automatically interpolates the UI from its previous state to its next state. Items slide smoothly. Zero custom animation code.

★ The trade-off: You get beautiful animations for free but zero control over specifics — no custom duration, curves, or per-element choreography. What you see is a platform-appropriate ease animation. That's the deal.
💡 configureNext scope: It animates the next UI re-render — not the next line of code. React batches multiple setState calls into one render, so one configureNext covers the entire batch.

Usage — One Line Before Every setState

Code
+ import { ..., LayoutAnimation } from "react-native"; // Pattern: call configureNext BEFORE every setShoppingList call // ─── handleSubmit ──────────────────────────────────────────── LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut); setShoppingList(newShoppingList); saveToStorage(storageKey, newShoppingList); // ─── handleDelete ──────────────────────────────────────────── LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut); setShoppingList(newList); // ─── handleToggleComplete ──────────────────────────────────── LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut); setShoppingList(newList); // ─── useEffect initial load ────────────────────────────────── LayoutAnimation.configureNext(LayoutAnimation.Presets.easeInEaseOut); setShoppingList(data);

Built-in Presets

easeInEaseOut ★

Kadi's always-reach-for-this one. Smooth acceleration and deceleration. Platform-appropriate feel.

linear

Constant speed throughout. Less natural but predictable. Good for progress indicators.

spring

Bouncy overshoot effect. Fun for game UIs. Too playful for most production list apps.

RN Animation Landscape

Beyond LayoutAnimation
LayoutAnimation ✓

This chapter. Zero effort, automatic. No control over specifics. Best for list reordering.

Animated API

Built into RN core. Fine-grained control. Verbose. Good for simple custom animations (fade, scale, slide).

Reanimated

By Software Mansion. Hooks-based. Runs on the UI thread — smooth even on JS thread jank. Production standard.

Gesture Handler (bonus)

Also by Software Mansion. Works alongside Reanimated. Required for swipe-to-delete, drag-to-reorder, and other gesture-driven animations. The two libraries are designed to be used together.

💡 When to reach for Reanimated: Any animation that involves gestures, must be 60fps under JS thread load, or needs custom per-element choreography (enter/exit transitions, shared element transitions). Everything else — LayoutAnimation first.
