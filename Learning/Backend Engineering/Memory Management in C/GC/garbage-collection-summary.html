Garbage Collection

How languages reclaim memory without manual free()
Problem Statement

In C, you manage memory manually — error-prone. Rust's borrow checker figures out object lifetimes at compile time. Garbage-collected languages (Python, JS, Go) figure out is this value still alive? at runtime, automatically freeing memory that's no longer reachable ("live").

Where the Cost Goes

C Manual

  • Programmer calls free()
  • Cost paid at dev time
  • Easy to forget → leaks/bugs

Rust Borrow Checker

  • Compiler tracks lifetimes
  • Cost paid at compile time
  • No runtime GC pause

GC Langs Automatic

  • Runtime decides liveness
  • Cost paid at runtime
  • Convenient, but pauses happen
Algorithm 1 — Reference Counting

Every object has a hidden count field. Referencing it (assigning, adding to a list) increments the count; removing a reference decrements it. When count hits 0, memory is freed immediately.

Example: foo is created (count=1), then appended to a list (count=2). Pop it from the list → count=1. Function returns, last reference gone → count=0 → freed.

Downsides

  • Can't detect cycles (A → B → A never hits 0)
  • Expensive — every touch updates counts
Algorithm 2 — Mark & Sweep

Mark: start from "roots" (stack frame variables) and trace every reachable object. Sweep: anything not marked is unreachable → reclaim it. Runs periodically as a GC pause, not on every operation.

List X ↔ List Y form a cycle but are reachable from root → both kept. A lonely cyclic pair with no root reference gets swept.
Key win over ref counting: List A references List B, List B references List A (a cycle). Reference counts never hit zero, but if neither is reachable from any root, mark & sweep still frees both.
Key Distinctions

Ref Counting works incrementally, per-operation, misses cycles.
Mark & Sweep works in batches (GC pauses), handles cycles, costs more per pause but less per operation.

Real-World Note

CPython's garbage collector itself is written in C (a different language than the one it's managing memory for) — Python uses ref counting as primary, with a cycle-detecting mark-and-sweep-style collector as backup for exactly the cycle problem above.

Takeaway / Tip
GC is never free — the question is only when you pay: dev time (C), compile time (Rust), or runtime (Python/JS/Go). Language choice = choosing where that cost lands.
