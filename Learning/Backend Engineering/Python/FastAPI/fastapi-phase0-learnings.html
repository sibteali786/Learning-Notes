🏗️The app object concept

Everything attaches to one FastAPI() instance. Uvicorn runs it via main:app — module name, colon, variable name.

app = FastAPI(title="feed-engine-api")

@app.get("/feed")
async def get_feed():
    ...

Free bonus: /docs auto-generates interactive Swagger UI from your route signatures.

🔎Query params from the signature concept

No manual parsing. Type hints do validation for you.

region: str→required
limit: int = Query(20, ge=1, le=100)→optional + bounded

A bad type (?limit=abc) → automatic 422, no code needed.

📦Pydantic response models concept

response_model=list[FeedItem] defines the exact output shape and validates every response against it before it's serialized — a mismatch fails loudly instead of shipping malformed JSON.

🔌asyncpg connection pool concept

One pool opened at startup, reused for every request — never a connection per request.

lifespan()→ create_pool() before yield→ pool.close() after yield

pool.acquire() in an async with block borrows + auto-returns a connection. min_size/max_size bound how many real Postgres connections exist — the thing that saturates under load in Phase 1.

🧭Cursor pagination, not offset concept

article.id is BIGSERIAL — strictly increasing — so paging by it never drifts even if rows are inserted concurrently.

WHERE region = $1 AND id < $2   -- cursor = last id seen
ORDER BY id DESC
LIMIT $3

⚠️Gotchas that actually cost debugging time gotcha

asyncpg.Record ≠ dict, for Pydantic's purposes
Record supports record["id"] (mapping access) but not record.id (attribute access). Pydantic validates via attribute access by default → every field reported "missing" even though the data was right there. Fix: dict(r) or FeedItem(**r) before returning.
Postgres lowercases unquoted aliases
AS publisherName silently becomes publishername. Needed AS "publisherName" (quoted) to match the camelCase Pydantic field exactly.
Pydantic v2 won't coerce datetime → str
It'll happily parse a string into a datetime, but not the reverse — that direction isn't a guessable format. Fix: type the field as datetime, not str; Pydantic serializes it to ISO-8601 automatically in the JSON output.
LSP import errors ≠ real errors
nvim's Pyright was resolving against the system Python, not .venv, so it flagged fastapi/pydantic/asyncpg as unresolved even though the app ran fine. Fixed with a pyrightconfig.json pointing venvPath/venv at .venv.
