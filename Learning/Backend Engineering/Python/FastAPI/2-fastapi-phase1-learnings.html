🐳Dockerfile basics concept

Standard layered build: copy requirements.txt first and install deps before copying app code, so Docker's layer cache skips the (slow) pip install step on every code change.

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt
COPY main.py .

Uvicorn in the container must bind --host 0.0.0.0, not the default 127.0.0.1 — otherwise nothing outside the container can reach it. Also drop --reload; it's dev-only.

🔗Container-to-container networking concept

Inside a Compose network, services address each other by service name, not localhost. The API's DATABASE_URL changes from the host's localhost:5432 to postgres:5432 — Compose's built-in DNS resolves postgres to the right container.

depends_on: postgres→ condition: service_healthy

Plain depends_on only waits for the container to start, not for Postgres to actually accept connections. Gating on the existing pg_isready healthcheck avoids a race on first boot.

🔤Filename case matters on Linux gotcha

Created dockerfile (lowercase). Builds fine with an explicit -f, but Compose's build: . shorthand looks for Dockerfile by default on case-sensitive filesystems. Renamed to match convention rather than special-casing the compose file.

🌱Seeding 1M rows: COPY, not INSERT concept

Row-by-row INSERT for a million rows is painfully slow — each one is a separate round trip. COPY ... FROM STDIN streams a whole CSV buffer in one shot.

cur.copy_expert(
    "COPY article (title, url, publisher_id, category, region, published_at) "
    "FROM STDIN WITH (FORMAT csv)",
    buf,
)

📈k6: what it actually is concept

Not a Python/Node dependency — a standalone Go binary, installed once via the OS package manager, run from the CLI against a live server. Scripts happen to be written in JS purely as k6's config language; no JS runtime is added to the project. wrk (Lua-scripted) is the equivalent alternative.

ramping-vus→ 0 → 1000 VUs over 5 stages→ thresholds: p(99)<200ms

Ramping (not an instant spike) is what makes it possible to locate where latency starts climbing, not just confirm it eventually breaks.
