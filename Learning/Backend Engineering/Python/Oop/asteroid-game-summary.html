Collision Detection

def collides_with(self, other):
    distance = self.position.distance_to(other.position)
    return distance < self.radius + other.radius

# Two circles collide when distance between centers < sum of radii
#
#   (player●)─────────────(●asteroid)
#      r=20    distance      r=60
#   collide if distance < 20+60 = 80
Pygame · Groups

3. Sprite Groups — Managing Game Objects

Groups are like arrays of sprites with superpowers — bulk update, draw, and collision check.

updatable → Player, Asteroid, AsteroidField, Shot (call .update(dt) on all) drawable → Player, Asteroid, Shot (call .draw(screen) on all) asteroids → Asteroid only (collision checks vs player/shots) shots → Shot only (collision checks vs asteroids) 
# Setup — BEFORE instantiation
Player.containers = (updatable, drawable)
Asteroid.containers = (asteroids, updatable, drawable)
Shot.containers = (shots, updatable, drawable)

# Game loop
updatable.update(dt)          # calls update() on every sprite
for thing in drawable:
    thing.draw(screen)          # our custom draw(), not pygame's
⚠️ GOTCHA
drawable.draw(screen) — pygame's built-in needs a .image bitmap. Our sprites use custom draw(), so always loop manually.
Math · Vectors · Delta Time

4. Vectors, Movement & Delta Time

pygame.Vector2

A 2D direction arrow. Supports math operations natively.

# (0,1) = pointing DOWN in pygame
# Y increases downward ↓

forward = pygame.Vector2(0, 1).rotate(rotation)
# rotation=0°  → ▼ (down)
# rotation=180° → ▲ (up)
# rotation=90°  → ◄ (left)

Delta Time (dt)

Decouples speed from frame rate.

# ❌ CPU dependent
position.x += 5

# ✅ always 200px/sec
position += velocity * SPEED * dt

dt = clock.tick(60) / 1000
# normal: dt ≈ 0.016s
# slow:   dt ≈ 0.033s (compensates)

Player Movement — How the Triangle Points

# forward = nose direction (pure direction, length=1)
forward = pygame.Vector2(0, 1).rotate(self.rotation)

# right = wing offset (direction + distance baked in)
right = pygame.Vector2(0, 1).rotate(self.rotation + 90) * self.radius / 1.5

a = self.position + forward * self.radius        # NOSE (20px ahead)
b = self.position - forward * self.radius - right  # LEFT wing
c = self.position - forward * self.radius + right  # RIGHT wing
a ▲ ← nose (forward × radius = 20px ahead) /│\ / │ \ / * \ * = self.position (center) / │ \ b────┴────c ←right─┤ ├─right→ (13.3px each side)

Debugging · Common Mistakes

6. Bugs Caught Along the Way

Bug 1 — Object recreated every frame

❌ BUG — resets position every frame
while True:
    player = Player(x, y)   # ← spawns fresh player each iteration
✅ FIX — create once, outside loop
player = Player(x, y)
while True:
    player.update(dt)        # state persists between frames

Same as doing const state = {"{x: 0}"} inside React render instead of useState.

Bug 2 — Missing parentheses (function reference vs call)

❌ BUG
self.move      # just points to the function, doesn't run it
✅ FIX
self.move(-dt)  # actually calls it

Bug 3 — Typo in variable name (test failing)

❌ BUG — logger captures variable name as-is
updateable = pygame.sprite.Group()   # test expected "updatable"
✅ FIX
updatable = pygame.sprite.Group()

Bug 4 — Setting position instead of velocity on Shot

❌ BUG — teleports bullet, doesn't give it motion
new_shot.position += scaled_vector
✅ FIX
new_shot.velocity = scaled_vector   # update() moves it each frame
Architecture · Game Loop

7. The Game Loop — Final Architecture

while True:
    log_state()                         # snapshot once/sec for CLI tests

    for event in pygame.event.get():      # handle quit
        if event.type == pygame.QUIT: return

    screen.fill("black")                  # erase last frame
    updatable.update(dt)                 # move everything

    for asteroid in asteroids:            # collision: asteroid vs player
        if asteroid.collides_with(player):
            sys.exit()                   # game over
        for shot in shots:               # collision: shot vs asteroid
            if shot.collides_with(asteroid):
                shot.kill()
                asteroid.split()

    for thing in drawable:               # render everything
        thing.draw(screen)

    pygame.display.flip()               # push to monitor
    dt = clock.tick(60) / 1000          # cap 60fps, get delta time

OOP · Key Takeaways

8. OOP Lessons — The Big Picture

Inheritance

Share common code in a base class. Subclasses get everything for free and only implement what's different.

CircleShape → position, velocity, radius
Player      → overrides draw() with triangle
Asteroid    → overrides draw() with circle
Shot        → overrides update() to move straight

Override Pattern

Base defines the contract. Children fulfill it their own way.

# Base — placeholder
def draw(self, screen): pass

# Player — triangle
def draw(self, screen):
    pygame.draw.polygon(screen, ...)

# Asteroid/Shot — circle
def draw(self, screen):
    pygame.draw.circle(screen, ...)

Class vs Instance variables

# Class variable — shared across ALL instances
Player.containers = (updatable, drawable)

# Instance variable — unique per object
self.position = pygame.Vector2(x, y)
self.rotation = 0

Cooldown Timer Pattern

# Count DOWN each frame
self.shot_timer -= dt

# Only act when expired
if keys[K_SPACE] and self.shot_timer <= 0:
    self.shoot()
    self.shot_timer = 0.3  # reset

# Without this: 60 bullets/sec while held
