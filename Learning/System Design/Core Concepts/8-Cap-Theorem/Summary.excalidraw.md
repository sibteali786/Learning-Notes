## Text Elements
CAP vs ACID consistency — CAP asks "do all nodes agree?" (network problem). ACID asks "did this transaction leave the DB valid?" (rules problem). A single-node Postgres instance can be fully ACID-consistent while being completely CAP-inconsistent the moment you add a replica.
Partition tolerance example — the Pakistan/US cable cut scenario in the card is the clearest mental model: both nodes keep running, but they can't sync. The system's response to that situation (error vs stale data) is the C vs A choice. ^n0LGYs6d

Synchronous replication waits for confirmation from all replicas before completing writes, which fails during network partitions. Asynchronous replication allows writes to succeed immediately, maintaining availability at the cost of temporary inconsistency. ^EAekf8sa
