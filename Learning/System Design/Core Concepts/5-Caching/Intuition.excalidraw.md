Caching ^p3kDEWev

what is caching ^rp7ELSC2

temporary storage that keeps recently used data so we can access it much faster next time. ^yUqgMbee

Why we even need it ?  ^XN94ZC8p

- The idea is when we access a data from database it takes on average ~1ms to ge it from SSD ( or even worse from HDD ).

-  The same access takes about ~1ns from cache ( Memory / RAM / sometimes different).

- This difference becomes large when we are processing millions of entries / second ^mhPYzI6w
