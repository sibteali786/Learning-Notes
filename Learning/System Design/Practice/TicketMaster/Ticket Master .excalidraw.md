## Text Elements
Functional Requirements ^pWl2RSNf

- Users should be able to view events
- Users should be able to search for events
- Users should be able to book tickets to events

Below the Line

- ... their booked events.
- Admin / event coordinators should be able to add events.
- Popular events should have dynamic pricing. ^qwj90oWE

Non Functional Requirements ^C02LEAEd

- System should be strongly consistent so that if two users A and B book same ticket at same instant 
one of them should be rejected.
- System should be highly avaialble for seaching and viewing events
- System should be scalable to handle high throuput in case of popular events (  10m users one event )
- Low latency search ( < 500m )
- Read heavy so High Read throughput should be there ( 100 : 1 )

Below the line (out of scope):

- The system should protect user data and adhere to GDPR
- The system should be fault tolerant
- The system should provide secure transactions for purchases
- The system should be well tested and easy to deploy (CI/CD pipelines)
- The system should have regular backups
 ^zSqVhQel
