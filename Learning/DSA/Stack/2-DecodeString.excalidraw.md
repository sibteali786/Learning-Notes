Time Complexity — O(N * K) or O(S)
The outer loop runs O(N) where N = input length. But the inner loop inside ] repeats strings — in the worst case like 300[abcdefg...], you're copying characters K times.
So total time = O(N × K) where K is the max repeat number, or more precisely O(S) where S = the length of the final decoded output string (up to 10^5).

The inner loop is NOT negligible — it's actually where most of the work happens. ^j6mu0US6

Space Complexity — O(N) or O(D)
The stack is NOT constant. At peak for 2[2[2[a]]]:
stack = [ "2", "", "2", "", "2", "" ]  ← 2 items per nesting level
So stack grows with nesting depth D. Worst case every character opens a new bracket → O(N). ^iG6QRXBo

/**
 * @param {string} s
 * @return {string}

var decodeString = function(s) {
    const stack = []
    let currentNumber = 0
    let currentString = ""
    for (const char of s) {
        if (char === "[") {
            stack.push(currentNumber);
            stack.push(currentString);
            currentString = ""
            currentNumber = 0
        }else if(char == "]"){
            let prevStr = stack.pop()
            let k = stack.pop()
            let repeated = currentString.repeat(k)
            currentString = prevStr + repeated
        }else if(/\d/.test(char)) {
            currentNumber = currentNumber * 10 + parseInt(char)
        }else {
            currentString += char
        }
    }
    return currentString
}; ^XEllVVNQ
