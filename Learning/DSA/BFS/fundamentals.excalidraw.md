BFS explores all nodes at the current level before moving to the next level. This makes BFS the go-to algorithm when you need shortest paths or level-order processing.

- The queue ensures nodes are processed in the order they were discovered, creating this breadth-first behavior ^6HPdcj9Q

Space Complexity
- at best the lowest level of tree can hold most values 
which are almost N/2
N = 7, last level has 4 nodes ~ 7/2 = 3.5

Time Complexity
O(N) where N = total nodes ( visited exactly once) ^TVhSlit8

function bfs(root):
    if (!root) return
    
    result = [] 
    queue = [root]
    
    while queue.length > 0:
        currNode = queue.shift()
        
        result.push(currNode.val)
        
        if currNode.left:
            queue.push(currNode.left)
        if currNode.right:
            queue.push(currNode.right)

    return result

function levelOrder(root):
    if (!root) return []
    
    result = []
    queue = [root]
    
    while queue.length > 0:
        levelSize = queue.length;
        currLevel = []
        
        for i = 0 to levelSize - 1:
            currNode = queue.shift()
            currLevel.push(currNode.val)
            
            if currNode.left:
                queue.push(currNode.left)
            if currNode.right:
                queue.push(currNode.right)

        result.push(currLevel)

    return result ^Qg1w8ynC
