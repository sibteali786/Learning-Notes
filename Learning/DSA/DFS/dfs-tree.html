DFS & Binary Trees

Complexity rules · Tree types · Patterns · Formulas · When to use what

Core DFS Pattern
On a Binary Tree
dfs(node):
  if node == null → return   ← base case

  visit(node)               ← pre-order
  dfs(node.left)
  dfs(node.right)
1
Hit null → return (base case)
2
Go as deep left as possible
3
Backtrack → explore right subtree
On a Graph (with cycles)
dfs(node, visited):
  if node in visited → return

  visited.add(node)

  for neighbor in node.neighbors:
    dfs(neighbor, visited)
!
Trees have no cycles — no visited set needed
Graphs need visited to prevent infinite loops
Traversal Orders
Pre-order
visit(node)
dfs(node.left)
dfs(node.right)
Root → Left → Right
Use: copy/serialize tree
In-order
dfs(node.left)
visit(node)
dfs(node.right)
Left → Root → Right
Use: sorted output from BST
Post-order
dfs(node.left)
dfs(node.right)
visit(node)
Left → Right → Root
Use: delete tree, compute size

Complexity Formulas — The Full Set
Time Complexity
FormulaWhat it meansExample
O(N) Work per node × N nodes = O(1) × N Standard DFS traversal
O(N·k) O(k) work per node × N nodes DFS + string copy of length k per node
O(N log N) O(log N) work per node × N nodes DFS + binary search at each node
O(N²) O(N) work per node × N nodes DFS on skewed tree with inner loop
Rule: find work per recursive call → multiply by number of calls (N)
Space Complexity
Tree TypeHeight HStack Space
Balanced / Complete log₂(N) O(log N)
Degenerate (skewed) N - 1 O(N)
Space = call stack depth = tree height H
Always state: auxiliary space vs total space
Height & Node Count
H = log₂(N)   ← balanced
H = N - 1    ← skewed
N = 2^(H+1) - 1  ← perfect tree
call stack = H + 1 ← include root
leaves = 2^H     ← perfect tree
max nodes at level L = 2^L
Example: N=7, balanced → H = log₂(7) ≈ 2 edges → call stack = 3 frames
Call Stack — How Backtracking Works
Max depth on a 7-node balanced tree
dfs(root)       ← frame 1
dfs(root.left)  ← frame 2
dfs(leaf)       ← frame 3 (deepest)
↑ top of stack
When frame 3 returns → pops → back to frame 2
That's backtracking.
The Rule
// When a recursive call RETURNS:
✓ All nodes in left subtree visited
✓ All nodes in right subtree visited
✓ Frame popped off call stack
✓ Return VALUE is now available
  to parent frame
This is how you aggregate info up the tree — return values bubble up from children to parent.
Grid DFS — Two Key Patterns
Count Connected Components (Islands)
directions = [UP, DOWN, LEFT, RIGHT]
           = [[-1,0],[1,0],[0,-1],[0,1]]

for each cell (r, c):
  if cell == 1 AND not visited:
    dfs(r, c)     ← flood fill island
    count++       ← only fires once!
Outer loop = detective (finds new island)
DFS = flood fill (consumes entire island)
Boundary DFS
// Flip the question:
// NOT "can cell reach border?"
// BUT "what can border reach?"

for each cell on the border:
  if cell == 1:
    dfs(r, c)  ← mark all reachable
Used in: Surrounded Regions, Pacific Atlantic Water Flow.
Key insight: start from border, work inward.

DFS vs BFS — When to Use Which
Use DFS ✓

Use BFS instead ✗
shortest path (unweighted)
