A linked list is a data structure of sequence of nodes, where each node contains a value and link/reference to next node in the sequence ^oFHOtFm3

// Definition of a ListNode
class ListNode {
  constructor(val = 0, next = null) {
    this.val = val;
    this.next = next;
  }
} ^4tFIXaxi

- We can visualize a linked list as a sequence of nodes connected by arrows that point to the next node in the sequence. 

- The first node in a linked list is referred to as the head, and the last node is referred to as the tail. The next field of the tail node is None.

- unless the linked list contains a cycle which indicates the end of the linked list. ^QKRN76eu

1. Traversing a Linked List ^W8o3fvv2

- We can traverse a linked list using a while loop
- use a variable `current` and point it to head of linked list
- then loop until `curren === null` in JS or `None in python`    ^8NBwP6tA

function findLength(head) {
    let current = head
    let length = 0
    while ( current !== null ) {
        length += 1
        current = current.next
    }
    return length
} ^u9SzKHIi

Time Complexity: The time complexity of this algorithm is O(n) where n is the number of nodes in the linked list. The algorithm iterates through each node in the linked list once.

Space Complexity: The space complexity of this algorithm is O(1) since we only use one pointer to traverse the linked list regardless of the number of nodes in the linked list. ^uQVsWoIk

2. Deleting a Node With a Given Target ^KV4HIZ2e

function deleteNode(head, target) {
    if (head.val == target) {
        return head.next
    }
    let current = head
    let prev = null
    while ( current !== null ) {
        if (current.val == target) {
            prev.next = current.next
            break
        }
        prev = current
        current = current.next
    }
    return head
} ^6Ku1EY5J

1. Fast and Slow Pointers ^ekKx2Fy7

function fastAndSlow(head) {
    let slow = head
    let fast = head
    while ( fast !== null && fast.next !== null) {
        slow = slow.next
        fast = fast.next.next
    }
    return slow
} ^a4mEWQIv

Time Complexity: The time complexity of this algorithm is O(n) where n is the number of nodes in the linked list. The algorithm terminates when the fast pointer reaches the end. Since fast advances two nodes per iteration, the loop runs approximately n/2 times, which is O(n). ^K84TO159

Space Complexity: The space complexity of this algorithm is O(1) since we only use two pointers to traverse the linked list regardless of the number of nodes in the linked list. ^yfVPC19c
