📌 Why This Matters

DFS isn't just for trees — it's a core tool for graph traversal too. Interviewers expect you to write graph DFS on both representations quickly and without bugs:

  • Adjacency List
  • Matrix (2D grid)
Key difference from trees: graphs can have cycles, so you must track visited nodes — otherwise DFS loops forever.

🧩 Core Building Blocks

Node + Edge
Nodes (vertices) connected by edges
Neighbors
Nodes 0, 2, 3, 4 are neighbors of node 1
Cycle
Path starts & ends at the same node → cycle
Directed vs Undirected
Most interview graphs are undirected

⚖️ Key Distinctions

ConceptMeaning
Connected graphPath exists between every pair of nodes
TreeConnected graph with no cycles (special case of a graph)
Disconnected graphAt least 2 nodes have no path between them
Connected componentA cluster of nodes all reachable from each other
Directed graphEdges go one way only
Undirected graphEdges go both ways
4 nodes connected (component 1) + 1 isolated node (component 2) → disconnected graph

🌍 Real-World Examples

Social network: people = nodes, friendships = undirected edges. Mutual friend groups = connected components.
Twitter follow graph: directed edges (A follows B ≠ B follows A).
Road map: intersections = nodes, roads = edges; one-way streets = directed edges, cycles = round trips possible.
Course prerequisites: directed graph — a cycle means an impossible schedule (classic "Course Schedule" problem).

🎯 Interview / Practical Tips

✅ Always maintain a visited set/array in graph DFS — trees don't need this, graphs do (cycles).

✅ Know both representations cold: adjacency list (dict of lists) and matrix (2D grid, common in "Number of Islands"-style problems).

✅ Most interview graphs = undirected unless stated otherwise (e.g. course prerequisites, dependency graphs → directed).

✅ "Is this a valid tree?" question = check: connected + exactly n-1 edges + no cycle.

✅ Disconnected graph → you may need to loop through all nodes and run DFS from each unvisited one to cover every component.
