Finding Valence Electrons from Position

AP Chemistry · Atomic Structure · Reference / Quick Recall

Problem Given any main-group element, find its valence config fast

For s-block and p-block elements you never need to write the full electron configuration to get valence electrons — row = shell number, group = valence electron count. Two lookups, done.

Rule 1 Row Number → Outermost Shell (n)

The period (row) an element sits in is its outermost shell number.
RowOutermost shell (n)
1n = 1
2n = 2
3n = 3
4n = 4
5n = 5
6n = 6
7n = 7

Why ns² always comes first
Within any shell, s fills before p (lower energy). So the first 2 valence electrons always go into ns²; anything beyond 2 spills into np.

Worked Example Bismuth (Bi)

Bi → row 6, group 15.
Row 6 → n = 6
Group 15 → 5 valence electrons
Split: 6s² (2) + 6p³ (3) = 5 ✓
Common wrong answers to watch for
  • Including core electrons like 4f¹⁴ 5d¹⁰ — those are inner-shell, not valence.
  • Writing only 6p³ and dropping 6s² — both subshells of the outer shell count.
  • Writing 6s² 6p⁶ (8 electrons) — that's a full octet, i.e. the next noble gas, not Bi itself.

Key Distinctions

TermWhat it includes
Full electron configurationEvery electron, core + valence
Valence electron configurationOnly electrons in the outermost shell (all subshells of that shell)

Practical Tips

  • This shortcut (row = n, group = valence count) only works cleanly for s-block and p-block elements — skip it for transition metals (d-block electrons behave differently).
  • Quick sanity check: valence electron count should never exceed 8 (except He, capped at 2).
  • To split valence count into subshells: first 2 always go to ns, the rest go to np.
  • If a question shows options with f or d subshells for a p-block element, that option is describing core electrons — it's a trap, not the answer.
