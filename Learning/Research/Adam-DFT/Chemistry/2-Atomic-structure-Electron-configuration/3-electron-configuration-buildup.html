Problem Where exactly does each electron go?

We know electrons fill orbitals from lowest to highest energy. This video walks the actual build-up process element by element (H → C) so you can write electron configurations confidently — plus a shortcut notation for larger atoms.

Walkthrough Building Configurations, Element by Element

H  (1 e⁻) → 1s¹
He (2 e⁻) → 1s²  — 1s subshell now full
Li (3 e⁻) → 1s² 2s¹  — 3rd electron starts new shell
Be (4 e⁻) → 1s² 2s²  — 2s subshell now full
B  (5 e⁻) → 1s² 2s² 2p¹  — 2p subshell starts filling
C  (6 e⁻) → 1s² 2s² 2p²  — 2nd electron enters 2p
The pattern
Electrons always fill the lowest-energy available slot first: 1s fills completely (2 e⁻) before 2s starts; 2s fills completely (2 e⁻) before 2p starts. Superscripts must sum to the atom's total electron count — a quick way to self-check your work.

Shortcut Noble Gas Notation

As atoms get bigger, writing out the full configuration gets unwieldy. Instead, use the preceding noble gas (group 18) as shorthand for its "core" electrons, then list only the remaining ("valence") electrons explicitly.
Worked example: Carbon
Full configuration: 1s² 2s² 2p²
Helium (the noble gas right before carbon) is 1s² — exactly matching carbon's first shell.
So carbon can be written as: [He] 2s² 2p²
Same information, shorter notation — especially useful once you get to elements with dozens of electrons.

Practical Tips

  • Check your work: superscripts should add up to the element's atomic number (= electron count for neutral atoms).
  • Find the noble gas notation shortcut by locating the previous noble gas (group 18) on the periodic table, one row up.
  • Noble gas notation instantly shows valence electrons — everything outside the brackets — which is exactly what determines reactivity.
  • Filling order to memorize for early rows: 1s → 2s → 2p → 3s → 3p...
  • Boron is the first element where p orbitals start filling — a common place mistakes happen.
