Electron Configuration of Ions

AP Chemistry · Atomic Structure · Source: Khan Academy (video)

Problem What changes when an atom becomes an ion?

Neutral atoms gain or lose electrons to become ions — charged atoms. Anions (negative) have gained electrons; cations (positive) have lost them. The electron configuration shifts accordingly, and the rule is simple: add electrons to the highest-energy available subshell, remove electrons from the highest-energy occupied subshell.

Worked Example Fluorine → Fluoride (anion)

F  (neutral, 9 e⁻) → 1s² 2s² 2p⁵
F⁻ (10 e⁻, gained 1) → 1s² 2s² 2p⁶
Where does the extra electron go?
The 2p subshell had room for one more (max capacity 6, fluorine only had 5). The gained electron simply completes it — fluoride ends up with a full outer shell, same configuration as neon. That's exactly why F⁻ is so stable.

Worked Example Calcium → Ca²⁺ (cation)

Ca  (neutral, 20 e⁻) → [Ar] 4s²
Ca²⁺ (18 e⁻, lost 2) → [Ar]
Which electrons leave first?
The 2 electrons removed come from the highest-energy occupied subshell — here, 4s. After losing them, Ca²⁺ has exactly the same electron configuration as neutral argon. This is the same underlying idea as before: the ion settles into a full, stable shell.

Rule General Method for Any Ion

Ion typeWhat happensWhere electrons go/come from
Anion (X⁻, X²⁻...)Gains electronsAdded to the next available spot in the outermost (valence) subshell
Cation (X⁺, X²⁺...)Loses electronsRemoved from the highest-energy occupied subshell
Quick method
Write the neutral atom's configuration first (noble gas notation is fastest), then simply add or remove electrons at the outer edge. You rarely need to rebuild the whole configuration from scratch.

Practical Tips

  • Anions add electrons to the valence subshell; cations remove them from the valence subshell — never touch core electrons unless specifically asked about highly charged/unusual ions.
  • A useful sanity check: many common ions end up isoelectronic with (matching the configuration of) the nearest noble gas.
  • Superscripts must still sum correctly: total electrons = atomic number ∓ ion charge.
  • Use noble gas notation for cations especially — losing electrons often reduces the configuration to exactly [NobleGas], as with Ca²⁺ → [Ar].
  • Practice tip from the video: pick any element, imagine gaining or losing an electron, and write out the resulting configuration — it's the fastest way to build intuition.
