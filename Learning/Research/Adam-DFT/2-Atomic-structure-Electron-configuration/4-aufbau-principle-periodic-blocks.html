Aufbau Principle & Periodic Table Blocks

AP Chemistry · Atomic Structure · Source: Khan Academy (video)

Problem Filling order stops being obvious past calcium

Up through argon, filling order is predictable: 1s → 2s → 2p → 3s → 3p. But at potassium/calcium, the "obvious" next subshell (3d) is skipped in favor of 4s. The Aufbau principle ("building-up principle," German) is the diagonal-filling diagram that predicts this correctly for electron configuration purposes.

Diagram The Aufbau Filling Order

How to read it
Draw diagonal arrows through the grid of subshells. The order you cross them = the fill order. Notice 4s is crossed before 3d — that's the surprising part.

Walkthrough Ne → Ar → Ca → Sc

Ne (10 e⁻) → 1s² 2s² 2p⁶
Ar (18 e⁻) → [Ne] 3s² 3p⁶
Ca (20 e⁻) → [Ar] 4s²  — NOT 3d², despite 3d existing
Sc (21 e⁻) → [Ar] 3d¹ 4s²  — now 3d starts filling
The catch at calcium
Even though the 3d subshell technically exists, calcium's extra 2 electrons go into 4s instead — 4s is lower energy at this point on the periodic table. This is exactly what the Aufbau diagonal predicts.

Nuance Aufbau Is a Useful Model, Not Perfect Truth

The Aufbau principle is taught in virtually every intro chemistry course and is correct for writing electron configurations. But it implies you fill 4s completely before touching 3d when "building" an atom electron by electron — which isn't literally how ionization/removal works.
Real nuance: building a scandium ion
If you start from a bare Sc nucleus and add electrons one at a time to build up to neutral scandium, the very first electron added (on a Sc¹⁸⁺-like core) actually goes into 3d, not 4s — contrary to what the simple diagram suggests. For AP-level electron configuration writing, though, the standard Aufbau order still gives the correct final answer.

Pattern The Periodic Table as Blocks

Each region of the periodic table corresponds to which subshell is being filled:
Block Subshell being filled Location
s-block s Groups 1–2 (+ He, by config)
p-block p Groups 13–18
d-block d Groups 3–12 (transition metals, incl. Sc)
f-block f Lanthanides / actinides (bottom rows)
Why helium sits with the s-block
Even though helium is drawn in group 18 on the standard table (matching its noble-gas chemistry), by electron configuration (1s²) it belongs with the s-block — it's filling an s subshell, same as H, Li, Be, etc.

Key Distinctions

Concept What it tells you
Row (period) Roughly which shell is active
Block (s/p/d/f) Which subshell type is currently filling
Aufbau diagonal The actual fill order across shells/subshells

Practical Tips

  • Memorize the Aufbau order through at least: 1s 2s 2p 3s 3p 4s 3d 4p 5s.
  • Watch for the 4s-before-3d trap — it's a very common exam point.
  • Use noble gas notation to skip repetitive core electrons: e.g. Sc → [Ar] 3d¹ 4s².
  • To identify a block quickly: locate the element on the table, then check which column-type region it's in (s/p/d/f) — that tells you the last subshell being filled.
  • Know that this is a simplified model — exceptions and ion-formation order can deviate, but for AP Chem electron configuration questions, standard Aufbau order is the expected answer.
