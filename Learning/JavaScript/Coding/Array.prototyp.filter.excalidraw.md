Sparse Arrays ^ngWr2wI7

Those arrays which have `empty slots` in them like 
const arr = [1, 2, , , 5]; // Create a sparse array ^wSCLRI3A

Array.prototype.filter Specs ^xdlXGwWO

filter(callbackFn)
filter(callbackFn, thisArg) ^2LFU3DMj

Parameters
callbackFn
- A function to execute for each element in the array. It should return a truthy value to keep the element in the resulting array, and a falsy value otherwise. The function is called with the following arguments:
   
element
- The current element being processed in the array.

index
- The index of the current element being processed in the array.
    
array
- The array filter() was called upon.

thisArg Optional
- A value to use as this when executing callbackFn. See iterative methods.
 ^2bThx0O3

It returns a shallow copy of given array containing just elements that pass the test ^Y3VhFgzC

callbackFn is invoked only for array indexes which have assigned values. It is not invoked for empty slots in sparse arrays. ^2baJkXs7

Array.prototype.myFilter = function (callbackFn, thisArg) {
    newArr = []
    originalArr = this
    for i = 0 to originalArr.lenght - 1 {
        if ( i in originalArr ) {
            // `in` operator return true or false if property key ( index ) exists in object
            if ( callbackFn.call(thisArg, originalArr[i], i, originalArr) ) {
                newArr.push(originalArr[i])
            }
        }
    }
    
    return newArr;
} ^CUG70PXR

Inricacies ^wMy10O3R

in vs Object.hasOwn
jsconst arr = [1, 2, 3];
arr.__proto__.customProp = 'inherited';

0 in arr              // ✅ true (own)
'customProp' in arr   // ✅ true (inherited — DANGER!)

Object.hasOwn(arr, 0)             // ✅ true
Object.hasOwn(arr, 'customProp')  // ❌ false (ignores inherited)

in checks the entire prototype chain, Object.hasOwn checks only own properties. For filter, you only want own indices — so Object.hasOwn is safer. ^zQ3C1c50

Attempt 2 ^RzuQlhfs

Mutation behavior (follows TC39 spec):

Array length is "snapshotted" before iteration starts
Elements added during filter → not visited
Elements changed during filter → visited with their new value
Elements deleted during filter → not visited ^RVACJqxf

Array.prototype.myFilter = function (callbackFn, thisArg) {
    if ( typeof callbackFn !== 'function' ) throw new TypeError(`${callbackFn} is not a function`)
    newArr = []
    originalArr = this
    len = this.length
    for i = 0 to len - 1 {
        if ( Object.hasOwn(originalArr, i) ) {
            // `in` operator return true or false if property key ( index ) exists in object
            if ( callbackFn.call(thisArg, originalArr[i], i, originalArr) ) {
                newArr.push(originalArr[i])
            }
        }
    }
    
    return newArr;
} ^FUduup28
