Inricacies ^wMy10O3R

in vs Object.hasOwn
jsconst arr = [1, 2, 3];
arr.__proto__.customProp = 'inherited';

0 in arr              // ✅ true (own)
'customProp' in arr   // ✅ true (inherited — DANGER!)

Object.hasOwn(arr, 0)             // ✅ true
Object.hasOwn(arr, 'customProp')  // ❌ false (ignores inherited)

in checks the entire prototype chain, Object.hasOwn checks only own properties. For filter, you only want own indices — so Object.hasOwn is safer. ^zQ3C1c50

Attempt 2 ^RzuQlhfs

Mutation behavior (follows TC39 spec):

Array length is "snapshotted" before iteration starts
Elements added during filter → not visited
Elements changed during filter → visited with their new value
Elements deleted during filter → not visited ^RVACJqxf

Array.prototype.myFilter = function (callbackFn, thisArg) {
    if ( typeof callbackFn !== 'function' ) throw new TypeError(`${callbackFn} is not a function`)
    newArr = []
    originalArr = this
    len = this.length

/**
 * @template T, U
 * @param {(previousValue: U, currentValue: T, currentIndex: number, array: T[]) => U} callbackFn
 * @param {U} [initialValue]
 * @return {U}
 */
Array.prototype.myReduce = function (callbackFn, initialValue) {
  if (typeof callbackFn !== "function") {
    throw new TypeError(`${callbackFn} is not a function`);
  }
  if (this.length === 0) {
    if (initialValue !== undefined) {
      return initialValue;
    } else {
      throw new TypeError(`inlvaid reduce call`);
    }
  }
  let accumulator;
  let currentIndex;
  if (initialValue === undefined) {
    accumulator = this[0];
    currentIndex = 1;
  } else {
    accumulator = initialValue;
    currentIndex = 0;
  }

  const len = this.length;
  const originalArr = this;
  let currentValue;

  for (let i = currentIndex; i < len; i++) {
    currentValue = originalArr[i];
    if (Object.hasOwn(originalArr, i)) {
      accumulator = callbackFn(accumulator, currentValue, i, originalArr);
    }
  }

  return accumulator;
};
 ^B32Kp6Ar

1. **Non-function callback** → throw `TypeError`

2. **Empty array + `initialValue`** → return `initialValue` directly

3. **Empty array + no `initialValue`** → throw `TypeError`

4. **`initialValue` presence** → use `=== undefined` not `!initialValue` (handles falsy values like `0`, `false`, `""`)

5. **Start index** → `initialValue` provided = start at `0`, not provided = use `this[0]` as accumulator and start at `1`

6. **Sparse arrays** → `Object.hasOwn` skips empty slots

7. **Length snapshotting** → `len = this.length` before loop prevents visiting appended elements ^KUYBzRx7
