Event Capturing vs Bubbling

DOM event propagation — three phases, one event.
CAPTURING

Root → Target

Event starts at the document root and travels down through ancestors to the target. Off by default — opt in with true or {capture:true} as the 3rd arg to addEventListener.

BUBBLING

Target → Root

Event starts at the target and travels back up through ancestors. On by default — this is what most click/input/change handlers use.

⚠️ stopPropagation() called during capture kills the entire rest of the flow — target and bubble phases both never run. It's not "stop at this ancestor," it's "stop everywhere downstream."
Where capture phase earns its keep

1. Delegating non-bubbling events

focus, blur, scroll, mouseenter/mouseleave don't bubble — but ancestors still see them during capture. Attaching form.addEventListener('focus', fn, true) gives you one delegated focus handler for every input, instead of wiring each input individually.

2. Pre-empting child handlers (analytics / feature gates)

A capture listener on a container fires before any inner component's bubble handler runs — useful for logging every click region-wide, or killing an action with stopPropagation() before component code ever sees it.

3. Modal "click outside to close"

Modals often listen on document with capture:true. If they used the bubble phase instead, an inner button's stopPropagation() could accidentally prevent the modal from ever hearing the click and closing.

Where bubbling is used — event delegation

Real-world case: a 5,000-row table

One listener on the <tbody>, checking event.target.closest('tr'), replaces 5,000 individual row listeners. New rows added later work automatically — no rebinding. This is only possible because click bubbles up from the row to the table.

const outer = document.createElement('div'); const inner = document.createElement('button'); outer.appendChild(inner); outer.addEventListener('click', (e) => { console.log('outer capture: stop'); e.stopPropagation(); }, true); inner.addEventListener('click', () => console.log('inner target')); outer.addEventListener('click', () => console.log('outer bubble')); inner.click(); // Output: "outer capture: stop" — target and bubble handlers never fire
