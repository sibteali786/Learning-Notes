Section 01
All 3 Forms — Behaviour & Timeline
Form 1
No dependency array
Runs after every render
useEffect(() => { console.log('Hello') setCounter(1) }) ← no array
Component mounts
Effect runs → Hello (1)
setCounter(1) → triggers re-render
Re-render (state changed)
Effect runs → Hello (2)
setCounter(1) same value → bailout
React bails out 🛑
Object.is(1, 1) → same value → no re-render
Stops ✅
🖨 'Hello' logs: 2 times
Form 2
Empty array []
Runs on mount only
useEffect(() => { console.log('Hello') setCounter(1) }, []) ← empty array
Component mounts
Effect runs → Hello (1)
setCounter(1) → triggers re-render
Re-render (state changed)
Effect does NOT run again ✅
[] means no deps to watch — never re-runs
🖨 'Hello' logs: 1 time
Form 3
With dependency
Runs on mount + when dep changes
useEffect(() => { console.log('Hello') setCounter(1) }, [props.visible])
Component mounts
Effect runs → Hello (1)
setCounter(1) re-renders but props.visible unchanged
Re-render (state changed)
Effect skipped ✅
props.visible didn't change → no re-run
props.visible changes → Hello (2)
dependency changed → effect re-runs
🖨 'Hello' logs: 1 + 1 per dep change
Section 02 · The Hidden Behaviour
React's Object.is Bailout — Why Form 1 Logs 2 Not Infinite
🛑
What is a bailout?

React uses Object.is(prevState, newState) to compare state values. If they're the same, React skips re-rendering after the second attempt — but NOT after the first.

⚠️
The "after first" rule

React may still re-render once before bailing out, but won't go deeper. This is why you see 2 logs not infinite — the bailout kicks in on the second setCounter(1) call.

// setCounter(1) called with same value repeatedly // Render 1 (mount) setCounter(1) // was 0 → now 1 → re-renders // Render 2 (after state change) setCounter(1) // was 1 → still 1 // Object.is(1, 1) = true → BAIL OUT // No Render 3 — React stops here ✅ // So useEffect ran exactly 2 times: // once on mount, once after first re-render
💡
Object.is vs ===

Almost the same but handles two edge cases: Object.is(NaN, NaN) → true (=== gives false). Object.is(+0, -0) → false (=== gives true).
