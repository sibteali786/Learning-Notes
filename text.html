Screen notes
Inbox: service & account switcher + multilayer search
Service switch (Gmail / Twilio) lives top-left as a segmented control. Stacked avatars show the connected accounts for the selected service — clicking Add account opens the Add Account drawer (drawer mockup below), which runs the passport OAuth flow in a new window. The pill-based filter row lets users stack filters like chips; each filter is removable. Quick actions per row: Reply, Add as Activity (records thread against the linked client), and Compose.

Screen notes
Email tab: clients / contacts with multi-select
Two entity tabs (Clients / Contacts) at top. The service selector picks which connected account will send. Each row has a Send button (opens Compose drawer pre-filled with recipient). Multi-select exposes the top-bar Email selected CTA which opens the same drawer with N recipients and template picker visible. All sends record an activity on the linked client automatically.

Screen notes
Bulk Email: list picker as cards
Lists render as selectable cards (rather than a dense row table) because users are typically picking one to send to. Each card shows name, description, count, owner, and 3 avatar previews. Select one (or multiple) then hit the top-right Send bulk to selected — opens the Bulk Compose drawer where you choose service account, template/newsletter, and any overrides.

Screen notes
Bulk jobs: live status & retry
Auto-refreshing via websocket/polling. Four KPI cards up top. Job rows show a slim progress bar with live counts and color-state (purple running, green done, red failed, gradient partial). Failure reasons appear as a tooltip on the red chip. Retry appears contextually — retries only the failed portion of a partial job, or the full batch for a failed job.

Screen notes
Templates: cards with live previews
Templates and newsletters share one grid, filtered by type. Each card shows a real thumbnail preview (rendered from the HTML) so users recognize at a glance. Usage count + format badge help find what works. Clicking the dashed Create new tile opens the Template Builder drawer, which supports HTML paste, file upload (HTML/PDF/PPT/JPEG → auto-converted to HTML), or a simple subject/body editor.
