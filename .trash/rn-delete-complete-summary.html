ShoppingListItemType — Final Shape

Data Model
type ShoppingListItemType = { id: string; // ISO timestamp — unique per ms name: string; completedAtTimestamp?: number; // undefined = todo, Date.now() = done lastUpdatedTimestamp: number; // set on add AND toggle — drives sort order };
★ Why number not boolean for completedAt? A number timestamp doubles as both a boolean flag (Boolean(ts) = isCompleted) AND as sort key for ordering completed items by recency — one field, two jobs.

Delete — filter() Pattern

Feature 1

ShoppingListItem.tsx — add prop:

type Props = { name: string; isCompleted?: boolean; + onDelete: () => void; // mandatory }; // swap console.log with prop call - onPress: () => console.log("Ok, deleting."), + onPress: () => onDelete(),

index.tsx — handler:

const handleDelete = (id: string) => { const newList = shoppingList .filter((item) => item.id !== id); setShoppingList(newList); }; // in renderItem — pass ID before component onDelete={() => handleDelete(item.id)}
💡 ID pre-binding pattern: onDelete={() => handleDelete(item.id)} — the component doesn't know its own ID, the parent closes over it. Clean separation.

Toggle Complete — map() + Pressable Pattern

Feature 2

ShoppingListItem.tsx — swap View → Pressable:

// add to Props type + onToggleComplete: () => void; // outer container - <View style={[styles.itemContainer, ...]} > + <Pressable + style={[styles.itemContainer, ...]} + onPress={onToggleComplete} + >

index.tsx — toggle handler:

const handleToggleComplete = (id: string) => { const newList = shoppingList.map((item) => { if (item.id === id) { return { ...item, completedAtTimestamp: item.completedAtTimestamp ? undefined // already done → undo : Date.now(), // not done → mark done lastUpdatedTimestamp: Date.now(), }; } return item; }); setShoppingList(newList); }; // in renderItem onToggleComplete={() => handleToggleComplete(item.id)} isCompleted={Boolean(item.completedAtTimestamp)}
⚠️ Use map() not filter() for toggle. You want to keep all items and mutate one — filter() removes items, map() transforms them. Return the item unchanged for all non-matching IDs.

orderShoppingList() — Sort Logic

Feature 3

4 ordering rules, evaluated in priority:

📋 Incomplete (top)
☐ Milk newest first
☐ Sugar lastUpdated desc
☐ Coffee
✓ Complete (bottom)
✓ Tea completedAt desc
✓ Bread
function orderShoppingList(list) { return list.sort((a, b) => { // both done → most recently completed first if (a.completedAtTimestamp && b.completedAtTimestamp) return b.completedAtTimestamp - a.completedAtTimestamp; // a done, b not → a goes below (positive = a after b) if (a.completedAtTimestamp && !b.completedAtTimestamp) return 1; // a not done, b done → a goes above (negative = a before b) if (!a.completedAtTimestamp && b.completedAtTimestamp) return -1; // both incomplete → most recently updated first if (!a.completedAtTimestamp && !b.completedAtTimestamp) return b.lastUpdatedTimestamp - a.lastUpdatedTimestamp; return 0; }); } // pass result directly to FlatList data={orderShoppingList(shoppingList)}
★ sort() return value rule: positive number → a after b. Negative → a before b. Zero → equal. Subtracting two timestamps gives this naturally — b - a = newest first (descending), a - b = oldest first.
